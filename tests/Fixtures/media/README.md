# 본문 미디어 실측·시험용 동영상

| 파일 | 형식 | 크기 | 내용 |
|---|---|---|---|
| `sample-1s.mp4` | MP4(H.264), 160×90, 약 1초 | 4,903 B | 색이 바뀌는 단색 화면 + 「G7 n」 글자 |
| `sample-1s.webm` | WebM(VP8), 160×90, 약 1초 | 6,312 B | 같음 |

외부 파일을 받지 않고 브라우저(Chrome)의 canvas `captureStream` + `MediaRecorder` 로 직접 만든 파일이다 — 제3자 저작물이 없고
이 저장소의 라이선스를 따른다. 본문 미디어 서빙(Range 206·416·inline)과 동영상 재생 실측에 쓴다.
