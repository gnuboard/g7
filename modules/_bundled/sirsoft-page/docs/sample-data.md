# 페이지 샘플 데이터

`php artisan module:seed sirsoft-page` 와 `--sample` 이 만드는 데이터를 정리합니다.

## 설치 시더 (항상 실행)

`PageSeeder` 가 기본 페이지 6개를 만듭니다 — 이용약관(`terms`), 개인정보처리방침(`privacy`), 취소·반품·교환 정책(`refund`), 그누보드7 소개(`about`), 자주 묻는 질문(`faq`), 문의하기(`contact`). 모두 발행 상태, 버전 1 입니다. 같은 slug 가 있으면 건너뜁니다. 활성 언어팩이 기본 페이지 번역을 제공하면 그 언어의 제목·본문을 함께 넣습니다.

## 샘플 시더 (`--sample`)

| 시더 | 만드는 것 |
| --- | --- |
| `PageSampleSeeder` | 시연 페이지 3개 — 미발행 초안(`sample-draft`), 버전 3개 중 버전 2 로 복원된 페이지(`sample-history`), 이미지 첨부가 있는 페이지(`sample-attachment`) |
| `ActivityLogSampleSeeder` | 이번 실행에서 새로 만든 페이지·첨부를 따라간 활동 로그 — 생성, 발행·발행 취소, 수정(버전), 복원, 첨부 업로드 |

시연 페이지는 같은 slug 가 있으면 건너뜁니다. 활동 로그는 실제 페이지 활동과 같은 이름으로 남고, 조회 기록은 만들지 않습니다.

## 다시 실행할 때

활동 로그는 이번 실행에서 새로 만든 페이지에만 만듭니다 — 운영자가 만든 페이지나 이미 있던 기본 페이지에는 만들지 않으므로, 다시 실행해도 로그가 겹치지 않습니다. 활동 로그는 지우지 않습니다. 이전 버전의 샘플 데이터가 만든 활동 로그는 표시가 없어 운영 로그와 구분할 수 없으므로 그대로 남습니다.
