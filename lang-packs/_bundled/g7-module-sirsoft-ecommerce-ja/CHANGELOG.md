# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.1.2] - 2026-08-22

### Added

- 이미 사용된 쿠폰으로 주문을 시도했을 때의 안내(`exceptions.coupon_already_used`)의 일본어 번역을 추가했습니다.

## [1.1.1] - 2026-08-19

### Added

- 리뷰 작성 불가 안내의 사유 라벨(`messages.reviews.reasons.*` — 주문 내역 없음·본인 주문 아님·구매확정 전·기한 경과·중복 작성) 일본어 번역을 추가했습니다.
- 확정 불가 상태의 주문 옵션 구매확정 시도 안내(`exceptions.order_option_not_confirmable`)의 일본어 번역을 추가했습니다.
- 이미 답변된 상품 문의에 답변을 재등록할 때의 거절 안내(`inquiries.reply_already_exists`) 일본어 번역을 추가했습니다. (#106 @Tuwasduliebst 님께서 제보해주셨습니다.)
- 이용할 수 없는 결제수단 선택 시의 주문 거절 안내 일본어 번역을 추가했습니다 (`validation.order.payment_method_unavailable`). (#111 @Tuwasduliebst 님께서 제보해주셨습니다.)
- 관리자 주문설정 결제수단 목록의 「지정 PG 삭제됨」 배지 일본어 번역을 추가했습니다. (#111 @Tuwasduliebst 님께서 제보해주셨습니다.)
- 배송지 변경 처리 중 서버 오류가 발생했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다. (#104 @Tuwasduliebst 님께서 제보해주셨습니다.)
- 배송정책 구간 설정의 새 검증 안내(구간 미등록, 중간 구간 종료값 누락, 수량 구간의 정수 제한, 단위값·무료배송 기준금액 누락, 도서산간 우편번호 형식) 일본어 번역을 추가했습니다.
- 배송정책 편집 화면에서 구간 입력 오류를 안내하는 문구(중간 구간 종료값 누락, 배송비 미입력, 수량 구간 정수 제한, 단위값·무료배송 기준금액 미입력) 일본어 번역을 추가했습니다.
- 배송비 요약에 표시되는 구간 단위(개/kg/L)와 구간 입력란의 단위 라벨 일본어 번역을 추가했습니다.
- 이커머스 설정 기본 정보 탭의 "공개 자산 스토리지" 설정 문구 일본어 번역을 추가했습니다. (#100 @lyg-kaban 님께서 건의해주셨습니다.)
- 공개 자산 디스크에 사용할 수 없는 값을 저장할 때 나오는 오류 안내와 필드명의 일본어 번역을 추가했습니다. (#100 @lyg-kaban 님께서 건의해주셨습니다.)

### Changed

- 도서산간 추가배송비의 "중복 부과" 안내를 배송 단위 기준으로 정정했습니다. 이전 문구는 건수 기준으로 읽혀 실제 부과 방식과 달랐습니다.

### Removed

- 화면에서 더 이상 쓰이지 않는 배송비 요약 접두 단위 문구와 배송정책 통화 선택 안내 문구를 제거했습니다.

## [1.1.0] - 2026-08-10

### Added

- 리뷰 작성·답글·일괄처리, 장바구니 선택 항목, 주문서 쿠폰 적용, 클레임 사유 관리, 배송비 검색 조건의 안내 문구 일본어 번역을 추가했습니다. 지금까지 일본어 로케일에서 안내 대신 내부 식별자가 그대로 보이던 화면들이 정상 표시됩니다.
- 택배사·상품 공통정보·주문 취소 관련 오류 안내와 상품 문의 답변 상태, 기본 배송 그룹 표시명의 일본어 번역을 추가했습니다.
- 장바구니 수량 상한 초과, 정률 적립률 상한 초과, 판매가·가격 하한 안내 문구 일본어 번역 추가.
- 쇼핑몰 환경설정·카테고리 이미지·결제 설정 안내 문구 일본어 번역 추가 — 저장/조회 결과 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 검색 프리셋·브랜드·배송사·배송정책 목록 안내 문구 일본어 번역 추가.
- 카테고리를 자기 자신이나 하위 카테고리 아래로 옮기려 할 때, 주문에 속하지 않은 옵션을 변경하려 할 때, 상품에 속하지 않은 이미지를 대표로 지정하려 할 때 나오는 안내 문구 일본어 번역 추가.
- 상품 문의 처리가 실패했을 때 그 사유를 그대로 보여주는 안내 문구의 일본어 번역을 추가했습니다.
- 관리자 상품 목록에서 행을 펼칠 때 나오는 옵션 불러오기 문구(불러오는 중·실패·재시도·등록된 옵션 없음)의 일본어 번역 추가.
- 옵션 일괄 변경 확인 화면에서 펼치지 않은 상품을 개수로 묶어 보여주는 문구와 실패 안내의 일본어 번역 추가.
- 상품 옵션 조회 요청 값(상품 ID 목록, 옵션 포함 여부) 검증 안내 문구 일본어 번역 추가.
- 무통장입금 자동취소 기한을 비운 채 저장할 때 나오는 안내 문구 일본어 번역 추가.
- 유효기간이 설정되지 않은 쿠폰을 발급할 때 나오는 안내 문구 일본어 번역 추가.
- 마일리지 설정의 통화별 적립 절사 기준(단위·방식) 항목명과 선택지, 허용값 위반 안내 문구 일본어 번역 추가.
- 현금영수증 관련 문구(`cash_receipt.*` — 발급 용도, 식별번호 종류, 발급/취소 이력 상태, 배송비 과세 방식, 오류 안내) 일본어 번역 추가 — 현금영수증 발급 화면과 이커머스 환경설정이 일본어 로케일에서 자연스럽게 표시됩니다.
- 현금영수증 발급 요청의 입력 항목명·검증 안내·처리 결과 문구(`cash_receipt.attributes.*`, `cash_receipt.validation.*`, `cash_receipt.messages.*`)와 발급 불가 사유 안내(`cash_receipt.errors.*`) 일본어 번역 추가 — 잘못된 식별번호를 입력했을 때의 안내와 발급·취소 결과 메시지가 일본어 로케일에서 자연스럽게 표시됩니다.
- 주문서의 현금영수증 신청 폼 문구(`checkout.cash_receipt.*` — 신청 여부, 발급 용도, 발급 수단, 입력 안내) 일본어 번역 추가 — 무통장입금으로 주문할 때 현금영수증을 신청하는 화면이 일본어 로케일에서 자연스럽게 표시됩니다.
- 주문 상세의 현금영수증 카드 문구(발급 상태 안내, 발급·발급취소·재발급 버튼, 발급 이력 표) 일본어 번역 추가 — 구매자와 관리자가 보는 현금영수증 영역이 일본어 로케일에서 자연스럽게 표시됩니다.
- 환불 계좌 입력 안내와 검증 문구(`validation.order.refund_bank_*`) 일본어 번역 추가 — 주문서와 관리자 취소 화면의 환불 계좌 입력란이 일본어 로케일에서 자연스럽게 표시됩니다.
- 현금영수증 자진발급 설정의 국세청 의무발행 업종 안내 링크 문구(`order_settings.cash_receipt.self_issue_mandatory_link`) 일본어 번역 추가 — 자진발급을 켤지 판단할 때 참고하는 국세청 안내 링크가 일본어 로케일에서 자연스럽게 표시됩니다.
- 카테고리 이미지 처리 결과 안내 문구(`category_images.*` — 업로드·삭제·순서 변경·이미지 없음) 일본어 번역 추가 — 관리자가 카테고리 이미지를 등록·삭제·정렬할 때의 안내가 일본어 로케일에서 자연스럽게 표시됩니다.

### Fixed

- 마일리지 사용 한도 초과 안내에 사용 가능한 최대 금액이 함께 표시되도록 일본어 문구를 갱신했습니다.
- 주문 관리자 메모 글자 수 안내가 실제 입력 한도(2000자)와 다른 "1000자"로 표시되던 문제를 수정했습니다.
- 자동취소 기한 안내가 실제 입력 하한(1일)과 다른 "0일 이상"으로 표시되던 일본어 문구를 수정했습니다.
- 금액 표시에서 통화 단위(円) 고정 표기를 제거했습니다 — 마일리지·주문 금액·일괄 변경 요약 등이 상점에 설정된 기준 통화의 단위로 표시됩니다.

### Removed

- 더 이상 사용하지 않는 장바구니 옵션 조합 검증 문구의 일본어 번역을 정리했습니다.
- 어디에서도 사용하지 않는 안내 문구 11건의 일본어 번역을 정리했습니다. 한국어 원본이 실제 화면에 쓰이지 않는 위치에 있어 번역만 남아 있던 항목입니다.

## [1.0.0] - 2026-07-01

### Added

- 주문 상태 전이 차단 안내 메시지(`validation.orders.status_transition.invalid` / `.bulk_invalid`) 일본어 번역 추가 — 허용되지 않는 주문 상태 변경(단건·일괄·상품옵션 일괄) 시 차단 사유가 일본어 로케일에서 자연스럽게 표시됩니다.
- 관리자 상품 목록 필터 검증 메시지(`validation.list.*` — 카테고리/카테고리 미등록/날짜 유형/판매상태/전시상태/브랜드/브랜드 미등록/과세여부/가격 유형/가격·재고 범위/배송정책) 일본어 번역 추가 — 상품 목록 필터 검증 실패 시 안내 메시지가 일본어 로케일에서 자연스럽게 표시됩니다.
- 배송정책 국가별 설정 검증 메시지(`shipping_policy.country_settings.*` — 국가/배송방법/통화/부과정책/기본배송비/무료배송기준/구간값/계산 API 주소·필수·참고필드) 및 구간별 배송비 음수·필수 안내, 리뷰 설정·배송 계산 API 참고필드 라벨, 상품정보제공고시 활성 상태 변경·이커머스 설정 저장 활동로그, 상품 배송정책 비활성 안내 일본어 번역 추가.
- 쿠폰 1인 사용 횟수 제한 초과 안내(`messages.coupon.per_user_limit_exceeded`)와 관리자 주문설정의 결제수단별 마일리지 차감 시점 라벨·비활성 안내(`admin.settings.payment_methods.mileage_deduction_timing`, `..._disabled_hint`) 일본어 번역 추가 — 쿠폰 사용 한도 초과 안내와 결제수단별 마일리지 차감 시점 설정이 일본어 로케일에서 자연스럽게 표시됩니다.
- 상품 폼·목록·설정의 신규 안내 일본어 번역 추가 — 상품 이미지 개수 상한 초과 안내(`exceptions.product_image_limit_exceeded`), 추가옵션 전체 삭제 확인·외화 자동 표시 안내, 기타정보 라벨 추가·할당 해제·삭제·등록/수정·기간 입력 라벨, 일괄변경 빈 항목·실패 안내, 통화 표시 기호 라벨이 일본어 로케일에서 자연스럽게 표시됩니다.
- 추가옵션 직접입력·검증 안내 일본어 번역 추가 — 추가옵션 직접입력 필수 안내(`exceptions.additional_option_custom_text_required`), 추가옵션 선택 오류·필수 선택 안내(`exceptions.additional_option_invalid`, `additional_option_required`), 추가옵션 그룹·선택지 등록 검증 메시지(그룹명/선택지 최소·최대·필수, 선택지명, 추가금 안내), 관리자 상품 폼의 선택지명·추가료·기본·사용·직접입력 허용 라벨이 일본어 로케일에서 자연스럽게 표시됩니다.
- 통화별 기준 단위(base_unit) 설정 안내·검증 메시지와 미지원 결제 통화 차단 안내(`exceptions.unsupported_payment_currency`) 일본어 번역 추가 — 환율·통화 설정 화면의 "기준 단위" 라벨·안내·검증 실패 메시지와 지원하지 않는 결제 통화 차단 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 회원 기본 배송국 설정·국제 배송 주소·배송 가능 여부 안내 일본어 번역 추가 — 회원 배송국 조회/변경 안내와 검증·활동로그(`messages.user_shipping_country.*`, `validation.user_shipping_country.*`, `activity_log.action.user_shipping_country_change`), 배송 불가 상품 안내(`exceptions.country_not_shippable`), 관리자 주문 폼의 국제 주소 입력 안내(주소·도시·도/주·우편번호 placeholder, 휴대폰/전화 필수 안내), 통화·배송국 라벨이 일본어 로케일에서 자연스럽게 표시됩니다.
- 통화별 사용 언어 설정 검증 라벨(`validation.attributes.language_currency.currencies.*.locales`) 일본어 번역 추가 — 환율·통화 설정 화면에서 통화별 "사용 언어" 항목 입력값 검증 실패 시 친화 필드명이 일본어 로케일에서 자연스럽게 표시됩니다.
- 배송정책 통화 고정 안내 문구(`shipping_policy.form.currency_code_fixed_hint`) 일본어 번역 추가 — 배송정책 등록·수정 화면에서 통화가 상점 기본 통화로 자동 적용된다는 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 관리자 주문 상세의 결제 통화 청구 안내(`order_detail.payment_currency`, `order_detail.charged_in_payment_currency`) 일본어 번역 추가 — 기본 통화와 다른 통화로 결제한 주문의 청구 통화·금액이 일본어 로케일에서 표시됩니다.
- 레이아웃 편집기 결제(PG) 진입 동작 라벨(`editor.action.request_pg_payment.*`, `editor.action_chip.response_pg_*`) 일본어 번역 추가 — 편집기 동작 추가 목록의 "결제 진입"과 결제 핸들러·데이터 입력 라벨, 결제 응답 데이터 칩 후보 명칭이 일본어 로케일에서 자연스럽게 표시됩니다.

### Changed

- 통화 표기 일본어 번역의 한자 표기를 정정 — 일부 안내에서 중국어 간체 "货" 로 표기되던 "通貨" 를 일본어 정자로 바로잡아 통화 관련 안내(기본/결제 통화 설정·검증·잠금 안내)가 올바르게 표시됩니다.
- 부분취소 차단 안내 메시지(`exceptions.cancel_refund_negative`) 일본어 번역을 쿠폰 단정 없이 일반화된 문구로 갱신 — 할인 조건 변경으로 결제금액이 늘어 취소 불가한 상황이 일본어 로케일에서 정확히 표시됩니다.
- 위안화(CNY) 가격 접두 기호(`messages.currency.prefix.CNY`)를 ¥ 에서 元 로 변경 — 엔화(¥)와 위안화가 같은 기호로 표시되어 혼동되던 문제를 해소해, 장바구니·상품·주문 화면에서 두 통화가 일본어 로케일에서도 구분되어 표시됩니다.
