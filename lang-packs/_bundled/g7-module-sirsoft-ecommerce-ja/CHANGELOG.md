# Changelog

## [1.2.0] - 2026-09-07

### Added

- 관리자 클레임 상세의 "접수 시점 주문금액 비교" 표 일본어 번역을 추가했습니다 — 정산 카드와 취소 정보 카드가 함께 쓰는 표의 유형별 전/후 열 이름, 금액 행 전체, 교환 옵션 치환 행, 스냅샷이 없는 구형 신청서 안내가 포함됩니다.
- 활동 로그의 "상태 자동 동기화" 액션 이름과 "주문 상태 자동 변경 — 상품 상태에 맞춰" 설명 문구의 일본어 번역을 추가했습니다 — 상품 상태 변경으로 주문 상태가 따라 바뀐 이력이 일본어 로케일에서도 원문 키가 아닌 문장으로 표시됩니다.
- 관리자 클레임 상세의 환불 금액 라벨과 진행 중인 다른 신청서의 환불 예정액 안내를 바뀐 한국어 문구에 맞춰 일본어도 갱신했습니다 — 금액 칸은 계좌이체 환불에도 함께 쓰이므로 "현금 환불액", 예정액 줄은 한도를 깎지 않는 참고 값임을 밝히는 문구로 바뀌었습니다.
- 환불 신청서의 상품 줄에 붙는 "환불철회" 상태 이름의 일본어 번역을 추가했습니다 — 구매자가 직접 취하한 신청이 종전에는 "환불반려"(판매자 거절)로 표시됐습니다.
- 설정 화면에서 추가 폼을 열어 둔 채 저장할 때, 어느 폼을 닫아야 하는지 직접 지목하는 안내 문구의 일본어 번역을 추가했습니다 — 종전에는 사유·배송사·배송유형 세 가지만 고정으로 말해, 배송가능국가 폼만 열어 둔 운영자가 열려 있지도 않은 폼을 확정하라는 안내를 받았습니다.
- 기존 배송유형끼리 코드를 서로 맞바꾸는 저장을 거절하는 안내 문구의 일본어 번역을 추가했습니다 — 배송사에만 있던 안내가 배송유형에도 생겼습니다.
- 설정 클레임 탭의 사유 추가 폼이 코드 길이 초과와 이미 있는 코드를 미리 알려 주고, 저장이 거절된 행의 코드를 표와 모바일 카드에서 붉게 지목하는 문구를 추가했습니다. 사유·배송사·배송유형 추가 폼을 연 채 저장할 때의 경고와, 기존 배송사끼리 코드를 맞바꾸는 저장을 거절하는 안내 문구도 추가했습니다.
- 설정 클레임 탭에서 사유 코드를 서로 맞바꾸려 할 때와, 코드 형식(영문 소문자·숫자·밑줄)에 맞지 않는 코드를 추가하려 할 때 표시되는 안내 문구의 일본어 번역을 추가했습니다.
- 업그레이드로 설치된 상점에도 기본 교환·반품 사유의 일본어 이름이 함께 심깁니다 — 그동안 업그레이드 경로로 추가된 기본 사유는 일본어 상점에서 한국어 이름으로 표시됐습니다.
- 관리자 클레임 상세의 결제 정보 탭 일본어 번역을 추가했습니다 — 결제수단 카드(결제 요청일·결제일·입금 기한·결제 통화)와 금액 행(주문금액·배송비·할인·마일리지·예치금·최종 결제금액·누적 취소와 환불·과세와 부가세·적립예정), 결제 건이 없는 주문의 안내가 포함됩니다.
- 관리자 클레임 상세의 '이 클레임의 정산' 블록 일본어 번역을 추가했습니다 — 배송비와 청구 방식 수정, 총 청구액과 미수납액, 추가결제 건 목록, 완료 시 환불 예정액과 접수 불가 사유 두 가지가 포함됩니다.
- 관리자 클레임 상세의 취소 정보 카드(취소 구분·환불 상태·환불 금액·취소 일시)와 취소 신청서 메모 불가 안내의 일본어 번역을 추가했습니다. 주문 상세 클레임 내역의 '클레임 신청서 조회하기' 문구는 신청번호 자체가 링크가 되어 삭제되었습니다.
- 관리자 클레임 상세의 환불 실행 탭 일본어 번역을 추가했습니다 — 취소 가능 금액 산정의 세 축과 한도 사유, 수단별 잔여 한도, 환불 금액 수정과 환불 수단 선택, 환불 실행 확인 안내가 포함됩니다.
- 클레임 배송비가 왜 그 금액인지 알리는 안내 문구의 일본어 번역을 추가했습니다 — 배송정책을 해석하지 못해 0원으로 처리한 경우, 외부 요금 API 를 쓰는 상점이라 기본 배송비로 산정한 경우, 주문 시점 스냅샷이 없어 현재 요금표로 산정한 경우 세 가지가 포함됩니다.
- 수단별 잔여 한도에 표시되는 마일리지 항목 이름의 일본어 번역을 추가했습니다.
- 환불 금액 입력 옆에 결제수단별 남은 환불 가능액을 함께 보여 주는 안내 문구의 일본어 번역을 추가했습니다.
- 주문의 결제 통화 정보를 확인할 수 없어 클레임 추가결제를 진행할 수 없을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다.
- 관리자 클레임(취소/반품/교환) 관리에서 쓰는 안내 문구의 일본어 번역을 추가했습니다 — 상태 변경·추가결제 요청·일괄 처리·상품 단위 처리·송장 저장·첨부 일괄 삭제 안내와, 미수납 청구가 남은 신청서의 승인 거절 안내가 포함됩니다.
- 관리자 클레임 목록·전이 입력 검증 안내(상태·귀책·청구 방식 필터, 검색 항목, 회원구분, 지정 불가 상태, 반려 사유·관리자 메모 길이, 일괄 대상 목록, 완료 처리 옵션, 송장 입력, 다른 신청서 상품 차단)의 일본어 번역을 추가했습니다.
- 검색 프리셋 대상 화면에 '취소/반품/교환 목록' 라벨의 일본어 번역을 추가했습니다.
- 관리자 클레임 금액 수정·취소 가능 금액 산정·환불 실행·완료 처리 미리보기·환불신청서 수동 접수에서 쓰는 안내 문구의 일본어 번역을 추가했습니다 — 종결 신청서 수정 불가, 취소 발 환불의 실행 불가, 환불 재실행 안내, 취소 가능 금액 초과, 비회원 마일리지 환불 불가와 금액·환불 수단·미리보기 대상 입력 검증 안내가 포함됩니다.
- 취소 가능 금액 조회에서 환불신청서 기준과 상품 선택 기준을 함께 지정했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다.
- 관리자 주문 목록의 클레임 기준 필터 입력 검증 안내(클레임 유무·유형별 상태·귀책·신청일 범위)의 일본어 번역을 추가했습니다.
- 배송정책 클레임 설정(교환·반품 회수지, 국가별 클레임 배송비)의 저장·조회 안내와 입력 검증 안내의 일본어 번역을 추가했습니다.
- 활동 로그의 클레임(교환·반품·환불) 항목 일본어 번역을 추가했습니다 — 신청 접수·상태 변경·금액 수정·환불 실행·추가결제 완료와 환급·첨부 업로드와 삭제의 이력 문구, 그리고 금액 수정 이력에 표시되는 항목 이름(클레임 배송비·총 청구 금액·청구 방식·환불 금액·환불 마일리지·환불 수단)이 포함됩니다.
- 활동 로그의 클레임 상품 단위 상태 변경과 추가결제 대기 취소 항목 일본어 번역을 추가했습니다.
- 관리자 클레임(취소/반품/교환) 목록 화면의 필터에서 쓰는 상태·유형·귀책·청구 방식 라벨의 일본어 번역을 추가했습니다 — 교환 14종·반품 11종·환불 7종·취소 2종의 상태 이름과 검색 프리셋 대상 화면 이름이 포함됩니다.
- 관리자 클레임 목록 화면의 제목·필터 이름·검색 항목·프리셋 관리 문구의 일본어 번역을 추가했습니다 — 신청일·상태·귀책·청구·사유·회원 구분 필터와 클레임번호/주문번호/신청자/상품명 검색, 프리셋 저장·수정·삭제 안내, 목록 컬럼 이름이 포함됩니다.
- 관리자 클레임 목록의 금액 범위·통화·청구 결제수단 필터 문구와 그 입력 검증 안내의 일본어 번역을 추가했습니다.
- 레이아웃 편집기에서 관리자 클레임 목록 화면을 열었을 때 데이터 소스 목록에 표시되는 이름('취소/반품/교환 목록'·'취소/반품/교환 사유')의 일본어 번역을 추가했습니다.
- 관리자 클레임 목록 본체의 일본어 번역을 추가했습니다 — 총 건수·목록 비어 있음 안내·상세 보기와, 신청상품 요약(외 N건·수량)·비회원 표시·미수납 잔액 표기가 포함됩니다.
- 관리자 클레임 목록의 일괄 상태 변경 문구의 일본어 번역을 추가했습니다 — 선택 건수·변경할 상태·확인 창의 유형과 대상 건수, 처리 결과 요약(성공·결제 요청·건너뜀)과 건너뛴 건 안내가 포함됩니다.
- 완료 처리 창(반품완료·교환완료)의 일본어 번역을 추가했습니다 — 대상 표의 신청번호·상품·환불 예정·재고 복구 항목과 전체 복구·폐기 안내, 환불신청서를 지금 접수할지 고르는 두 선택지와 그 설명, 함께 실행되는 처리 요약(상태 전이·재고·적립 차감·쿠폰 복원), 접수 불가 사유 안내가 포함됩니다.
- 완료 처리 창의 '함께 실행되는 처리' 요약에 회수배송비 차감 문구의 일본어 번역을 추가했습니다. 교환·반품이 아닌 대상에 창이 열렸을 때 쓰는 일반 제목도 함께 추가했습니다.
- 관리자 클레임(취소/반품/교환) 상세 화면의 일본어 번역을 추가했습니다 — 화면 제목과 헤더(클레임번호·유형·신청일·신청자·원 주문 보기), 섹션 탭 이름(신청 정보·배송 정보·활동 로그), 진행 단계 제목이 포함됩니다.
- 상세 화면의 신청상품 표와 상품 단위 일괄 변경 문구의 일본어 번역을 추가했습니다 — 상품·수량·금액·상태 컬럼 이름, 차액 표기, 선택·상태 미지정 안내와 처리 결과 안내가 포함됩니다.
- 상세 화면의 배송 정보(회수·재발송) 문구의 일본어 번역을 추가했습니다 — 회수지·재발송지 표기, '배송지 다름'·'고객이 수정함' 표시, 회수·재발송 완료 시각, 택배사·송장번호 입력과 저장·배송조회, 송장 한쪽만 입력했을 때의 안내가 포함됩니다.
- 상세 화면의 신청 사유·관리자 메모 문구의 일본어 번역을 추가했습니다 — 사유·귀책·반려 사유 표기, 상세 사유가 없을 때의 안내, 첨부 이미지 제목, 메모 입력·저장 안내와 환불신청서에는 메모를 저장할 수 없다는 안내가 포함됩니다.
- 상세 화면의 활동 로그 문구의 일본어 번역을 추가했습니다 — 정렬·표시 개수 선택, 일시·작업자·내용 컬럼, 변경 내역의 항목·이전·이후 표기, 회원 정보 보기 메뉴가 포함됩니다.
- 상세 화면의 완료 처리 안내 문구의 일본어 번역을 추가했습니다.
- 활동 로그 조회 완료 안내 문구의 일본어 번역을 추가했습니다.
- 레이아웃 편집기의 데이터 소스 목록에 클레임 상세·클레임 활동 로그 이름의 일본어 번역을 추가했습니다.
- 관리자 주문상세의 '클레임 내역' 섹션 일본어 번역을 추가했습니다 — 탭 이름과 교환·반품·취소·환불 서브탭, 신청번호·상품·수량·금액·상태 컬럼, 원상품과 교환상품 표기, 왕복 배송비·총 청구액, 반려 사유, 조회 전용 표시, 그리고 [클레임 신청서 확인하기] 가 포함됩니다.
- 클레임 내역에서 접수된 건이 없을 때와 내역 자체를 불러오지 못했을 때의 안내 문구를 서로 구분해 일본어로 추가했습니다.

- 레이아웃 편집기 결제(PG) 진입 동작 라벨(`editor.action.request_pg_payment.*`, `editor.action_chip.response_pg_*`) 일본어 번역 추가 — 편집기 동작 추가 목록의 "결제 진입"과 결제 핸들러·데이터 입력 라벨, 결제 응답 데이터 칩 후보 명칭이 일본어 로케일에서 자연스럽게 표시됩니다.

### Changed

- 통화 표기 일본어 번역의 한자 표기를 정정 — 일부 안내에서 중국어 간체 "货" 로 표기되던 "通貨" 를 일본어 정자로 바로잡아 통화 관련 안내(기본/결제 통화 설정·검증·잠금 안내)가 올바르게 표시됩니다.
- 부분취소 차단 안내 메시지(`exceptions.cancel_refund_negative`) 일본어 번역을 쿠폰 단정 없이 일반화된 문구로 갱신 — 할인 조건 변경으로 결제금액이 늘어 취소 불가한 상황이 일본어 로케일에서 정확히 표시됩니다.
- 위안화(CNY) 가격 접두 기호(`messages.currency.prefix.CNY`)를 ¥ 에서 元 로 변경 — 엔화(¥)와 위안화가 같은 기호로 표시되어 혼동되던 문제를 해소해, 장바구니·상품·주문 화면에서 두 통화가 일본어 로케일에서도 구분되어 표시됩니다.
