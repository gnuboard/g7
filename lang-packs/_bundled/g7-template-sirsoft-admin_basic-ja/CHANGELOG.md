# Changelog

## [1.0.10] - 2026-09-11

### Added

- 레이아웃 편집기 「화면 상태」 고르개의 「개인정보 보유기간 탭」 항목 이름(`editor.state.tab.privacy_retention`, 「個人情報の保有期間タブ」)의 일본어 번역을 추가했습니다.
- 환경설정 > 개인정보 탭의 「지금 실행」 버튼(탈퇴 회원 잔여정보 파기·휴면 4단계)과 직권 실행 확인 창(대상 건수·처리 방식·대기기간 생략 체크·되돌릴 수 없음 경고)·진행 상태 줄 문구(`admin.settings.privacy.manual_run.*`), 편집기 데이터 소스 이름의 일본어 번역을 추가했습니다. 조치 대상을 단계마다 한 줄로 정리하면서 줄 이름(`admin.settings.privacy.targets.rows.*`, 「休眠転換事前通知」 등)과 공용 「対象を表示」(`targets.view`)를 더하고, 쓰지 않게 된 단계별 보기 버튼·합산 배지 문구는 뺐습니다.
- 환경설정 > 개인정보 탭의 「대상 보기」 버튼과 조치 대상 명단 창 문구를 일본어로 번역했습니다 — 탈퇴 회원 잔여정보 파기와 휴면 4단계(사전 안내·전환·탈퇴 예고·자동 탈퇴)별 버튼과 창 제목, 안내·합계·빈 목록·불러오는 중·닫기(`settings.privacy.targets.*`), 레이아웃 편집기의 데이터 소스 이름(`editor.data_source.privacyTargets`)입니다. 휴면은 같은 화면의 다른 문구와 같은 「休眠」으로 적었습니다.
- 관리자 로그인에서 휴면이 풀렸을 때 뜨는 안내 문구를 일본어로 번역했습니다
  (`dormancy_restored`). 관리자 계정도 휴면 전환 대상이라 이 화면으로 돌아옵니다. 같은 문구를
  이미 쓰고 있는 사용자 템플릿 팩(`g7-template-sirsoft-basic-ja`)과 표기를 맞췄습니다 — 두
  화면이 다른 말을 하면 같은 사건이 다른 일처럼 읽힙니다.
- 알림 설정 화면의 휴면 알림 3종 제목을 일본어로 번역했습니다 — 「休眠転換事前通知」·「休眠転換完了」·
  「休眠アカウント退会予定通知」(`settings.notification_definitions.types.dormant_*`). 없으면 일본어
  로케일의 알림 설정 목록에서 이 세 줄만 제목 자리에 내부 키 문자열이 그대로 보입니다.
  생성기(`build-language-pack.cjs`)가 아니라 직접 적었습니다(번역 API 키 부재) — 코어 알림 정의의
  일본어 이름(`g7-core-ja/seed/notifications.json`)과 같은 표기를 씁니다.
- 「휴면 후 자동 탈퇴」 옆 처리 대상 건수 뱃지 문구를 일본어로 번역했습니다
  (`settings.privacy.dormant.withdraw_stage_counts`). 없으면 일본어 로케일에서 그 뱃지만 한국어로 남습니다.
- 환경설정의 「개인정보」 탭 문구를 일본어로 번역했습니다 — 탭 이름, 켜기 전 처리방침 선행 고지, 탈퇴 회원 잔여정보 파기 카드와 휴면 계정 카드의 제목·설명·토글·기간 입력 안내, 되돌릴 수 없다는 경고, 처리 대상 건수 뱃지 문구입니다(`settings.tabs.privacy`·`settings.privacy.*`). 회원 상세의 「휴면 전환일」과 회원 수정 폼의 상태 항목 「휴면」·「가입대기」도 함께 넣었습니다. 레이아웃 편집기의 개인정보 미리보기 데이터 이름(`editor.data_source.privacyPreview`)도 추가했습니다. 없으면 일본어 로케일의 개인정보 탭에 한국어가 섞여 보입니다.
- 환경설정 > 보안의 「IP 접근 제한」 카드와 규칙 편집 창 문구를 일본어로 번역했습니다 — 카드 제목·설명, 신뢰 프록시 경고, 현재 접속 IP 뱃지와 「현재 IP 추가」, 허용 IP 입력 안내, 규칙 표의 열 이름과 빈 목록 안내, 외부 콜백 주의와 서버 해제 안내, 그리고 규칙 창의 입력 라벨·도움말·오류 문구입니다(`settings.security.ip_restriction.*`·`modal_label.admin_settings.ip_restriction_rule_form_modal`). 편집기 상태 목록의 「보안 탭 — IP 접근 제한」 미리보기 이름(`editor.state.settings_security_ip_restriction`)도 함께 넣었습니다. 없으면 일본어 로케일의 보안 탭에 한국어가 섞여 보입니다.
- 관리자 로그인의 인증 앱(OTP) 단계와 환경설정 > 보안의 2단계 인증 적용 범위 문구를 일본어로 번역했습니다 — 앱 코드 입력 안내·라벨·입력 예시·백업 코드 안내(`login.two_factor.*`)와 범위 선택 항목(`settings.security.two_factor_scope*`) 입니다. 없으면 일본어 로케일의 관리자 로그인 화면과 보안 설정에 한국어가 섞여 보입니다.
- 확장 목록을 새 카드 그리드로 바꾸면서 생긴 편집기 속성 라벨 5종(보기 방식·카드 최소 폭·
  최대 열 수·페이지네이션·컴포넌트 이름)의 일본어 번역을 추가했습니다.
- 拡張管理画面のギャラリー／一覧表示切り替えとアイコン関連の文言を追加しました。
- 권한이 없는 관리자 화면에 뜨는 안내 문구 「権限がありません。」(`auth.permission_denied`)의 일본어 번역을 추가했습니다. 한국어·영어에는 있었으나 일본어에만 빠져 있어, 일본어 로케일에서는 그 자리에 키가 그대로 노출됐습니다. 회원 알림함을 비롯해 이 문구를 쓰는 관리자 화면 5벌에 함께 적용됩니다.

- 미저장 탭 닫기 3지선다 창(제목·질문·「保存して閉じる」·「保存せずに閉じる」·「キャンセル」·저장 중 안내)과 충돌 안내의 「差分を見る」 창(제목·범례·닫기) 문구 10종의 일본어 번역을 추가했습니다. 생성기(`build-language-pack.cjs`)가 아니라 직접 적었습니다(번역 API 키 부재) — 키로 재생성하면 덮어써도 됩니다.

- 라우트가 걸린 파일의 삭제 확인 2단계 버튼 「それでも削除」(`file.delete_anyway`)와 글자 크기 단축키 도움말 「文字を大きく」·「文字を小さく」(`shortcuts.font_size_up`·`font_size_down`) 3종의 일본어 번역을 추가했습니다. 생성기가 아니라 직접 적었습니다(번역 API 키 부재) — 키로 재생성하면 덮어써도 됩니다.

- 없어진 파일의 편집분을 다루는 새 문구 6종의 일본어 번역을 추가했습니다 — 「このファイルが見つかりません」(안내 제목·토스트), 탭의 「存在しないファイル」 표시, 읽기 전용 안내문, 그리고 [新しい名前で保存]·[破棄] 버튼입니다. 생성기(`build-language-pack.cjs`)가 아니라 직접 적었습니다(번역 API 키 부재).

- 레이아웃 코드 편집기 개편에 따른 새 문구의 일본어 번역을 추가했습니다 — 파일 목록이 평면 목록에서 **폴더 트리**로 바뀌고, **열린 파일 탭**과 **파일 생성·삭제·이름변경**, **파일명·내용 검색**, **단축키**가 들어오면서 생긴 문구입니다. 트리(목록 이름표·미저장 표시와 개수·빈 폴더·「편집 가능한 레이아웃이 없습니다」·폭 조절), 탭(목록 이름표·닫기), 검색(입력 안내·결과 요약·결과 없음·지우기·해당 줄로 이동), 파일 조작(새 파일·새 폴더·이름변경·삭제와 각 확인 문구, 그리고 모듈 원본이거나 다른 화면이 참조 중이라 막혔을 때의 사유 안내), 단축키 20종의 이름과 도움말 제목, 미저장 초안 복원 배너(복원·버리기·이탈 경고·판본 되돌리기 전 경고), 서버 본문이 더 새로울 때의 충돌 바(「내 것 유지」·「서버 것으로」), 자동 줄바꿈 토글, 그리고 새 모달 2종(파일 만들기·이름변경, 삭제 확인)의 제목을 포함합니다.

- 레이아웃 코드 편집기의 HTML(`.g7.html`) 기본화에 따른 새 문구(HTML/JSON 서브탭, JSON 읽기 전용 안내와 「오래됨」 배지, 컴파일 오류·경고 패널 제목, 설치본 편집 안내, `.g7.html` 내려받기·복사 버튼과 결과 알림, 조각 식별자 라벨)의 일본어 번역을 추가했습니다.

- 파일명·내용 검색이 쓰는 데이터 소스 이름표(`data_source.layout_search`)의 일본어 번역을 추가했습니다.
- 회원 알림함 관리 화면의 일본어 번역 50건을 추가했습니다. 목록 제목과 설명, 읽음/안읽음 필터와 검색 대상(수신자·제목·본문), 표 머리글, 알림 상세 펼침의 본문·링크·종류 라벨, 삭제와 일괄 삭제 확인 모달이 일본어로 표시됩니다. 회원 상세의 알림 탭(전체·안읽음 건수, 알림함으로 이동)도 함께 번역했습니다.
- 레이아웃 편집기의 데이터소스 목록에 「회원 알림함」(`data_source.memberNotifications`) 이름을 추가했습니다.
- 레이아웃 편집기 「화면 상태」 고르개의 새 항목 이름 41건을 일본어로 번역했습니다 — 비즈뿌리오 탭·템플릿 작성 창, 수출입은행 설정·이력 탭, GDPR 정책 이력·쿠키 분류 펼침, CKEditor5 업로드 선택·삭제 확인, 마케팅 채널 창, 인증 앱 등록 단계, 우편번호 표시 방식, 페이지 버전 미리보기, 그리고 공통 항목인 「창 내용 채움」·「화면 상태 채움」(`editor.state.*`) 입니다. 없으면 일본어 로케일의 편집기 상태 목록에 한국어가 섞여 보입니다.

### Changed

- 휴면을 가리키는 일본어 낱말을 「休眠」 하나로 맞췄습니다 — 환경설정 > 개인정보 탭의 휴면 카드 문구 전부와 회원 상태 「휴면」·회원 상세의 「휴면 전환일」(`settings.privacy.dormant.*`·`users.*`)이 「休止」였습니다. 같은 화면 묶음 안에서 알림 설정 목록은 「休眠転換完了」인데 바로 옆 개인정보 탭은 「休止アカウント転換」이라, 운영자가 두 기능을 다른 것으로 읽을 수 있었습니다. 휴면이 풀렸을 때의 안내(`auth.dormancy_restored`)도 함께 맞췄습니다.

## [1.0.8] - 2026-09-06

### Added

- 확장 제거 시 표시되는 「운영자 파일 사본 보관」 안내 제목·설명의 일본어 번역을 추가했습니다 — 모듈·플러그인·템플릿 제거 결과 화면에서 보관 경로 안내가 일본어 로케일로 표시됩니다.

- 환경설정 > 고급의 리버스 프록시 진단 항목(라벨·상태·안내 문구)의 일본어 번역을 추가했습니다.

- 환경설정 화면의 `.env` 우선 모드 안내와 「`.env` 고정」 배지 문구의 일본어 번역을 추가했습니다.
- 환경설정 > 일반의 「초기 화면 정적 파일」 카드 전체(제목·설명, 게시됨·미게시·비활성·개발 모드 상태 배지, 버전·파일 수·마지막 게시 시각·실행 계정·실패 사유 행, 「지금 다시 만들기」 버튼과 확인 모달)의 일본어 번역을 추가했습니다.
- 레이아웃 편집기의 「초기 화면 정적 파일 상태」 데이터 항목 이름을 일본어로 추가했습니다.

- 레이아웃 편집기 신규 컴포넌트 속성 컨트롤·컴포넌트 라벨 일본어 번역 추가 (`editor.control.{as_*,af_*,tt_*,nc_*,cs_*,sh_*}` + `editor.component.section_header` + `layout_editor.*.section_header`) — 관리자 사이드바·푸터·테마 토글·알림 센터·컬럼 선택기·섹션 헤더 컴포넌트의 속성 편집 컨트롤과 팔레트 컴포넌트명·섹션 헤더 기본 문구가 일본어 로케일에서 자연스럽게 표시됩니다.

### Changed

- 본인인증 정책 편집 안내 문구(`declared_policy_notice`)의 일본어 번역을 호스트 템플릿 변경에 맞춰 정정 — 편집 가능 범위가 "키·강제 시점·강제 위치만 변경 불가, 그 외 자유 편집"으로 갱신됨에 따라 일본어 안내도 동일하게 반영
- 관리자 대시보드 게시판 영역이 게시판 모듈로 이전됨에 따라 옛 게시판 라벨(상단 빠른 진입 버튼·통계 카드)을 정리하고, 다른 영역의 일본어 번역도 호스트 템플릿 기준으로 재동기화

### Removed

- 템플릿 관리 화면의 위지윅 편집 버튼 라벨 번역 제거 (코어에서 MVP 위지윅 편집기 제거에 동기화).
- 대시보드에서 제거된 "시스템 리소스" 데이터 소스 라벨(`data_source.dashboard_resources`·`dashboard_resources_ws`)의 일본어 번역을 정리했습니다.
