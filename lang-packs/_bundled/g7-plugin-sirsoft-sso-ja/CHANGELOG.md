## [1.0.0] - 2026-10-22

### Added

- SSO 연동 플러그인 일본어 언어팩 최초 릴리즈. 코어 7.2.0 이상이 필요합니다.
- 로그인 화면과 관리자 로그인 화면의 회사 계정 버튼, 이메일을 먼저 입력할 때의 회사 계정 안내, 가입 동의와 기존 계정 연결 확인 창, 마이페이지 「연결된 회사 계정」 카드, 회사 계정으로 다시 확인하는 본인 재확인 문구를 일본어로 제공합니다.
- 관리자 설정 화면(IdP 목록과 편집 8개 탭, 정책, 보존 기간), 「회원 연결」 화면과 CSV 가져오기, 「이력」 화면, 회원 상세 「SSO」 탭과 회원 목록 IdP 필터, 부서와 직급 열의 문구를 일본어로 제공합니다.
- 서버가 돌려주는 안내와 오류 문구(SAML 응답과 붙여 넣은 메타데이터 XML 검사, OpenID Connect, LDAP, SCIM 포함), 검증 항목 이름, 활동 로그, 알림 7종의 제목과 본문, 권한, 역할, 관리자 메뉴, 스케줄 이름을 일본어로 제공합니다.
- 이 판의 번역문은 자동 번역 도구를 쓰지 않고 개발 과정에서 직접 번역했으며, 다른 번들 일본어 언어팩과 같은 용어집을 따릅니다.
- 회원 목록 「SSO 연결 없음」 필터, 진단의 IdP 응답 요약, 정책 화면의 비활성화 경고, 역할 동기화 건너뜀 활동 로그, 도메인 중복 소유 거절 문구를 일본어로 번역했습니다.
