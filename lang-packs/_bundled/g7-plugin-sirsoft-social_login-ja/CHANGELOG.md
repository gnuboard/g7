## [1.0.0] - 2026-11-20

### Added

- 소셜 로그인 플러그인 일본어 언어팩 최초 릴리즈. 코어 7.2.0 이상이 필요합니다.
- 회원 알림 시드에 문자(SMS)와 알림톡 채널 본문을 일본어로 추가했습니다.
- 로그인과 가입 화면의 제공자 버튼, 이메일 제공을 거절해 가입하지 못한 회원의 재동의 안내와 단추, 가입 모달(이메일 확인, 같은 이메일의 기존 계정 연결), 마이페이지 「연결된 소셜 계정」 카드, 소셜 계정으로 다시 확인하는 본인 재확인 문구를 일본어로 제공합니다.
- 관리자 설정 화면(제공자 카드 — 카카오 콘솔 위치와 이메일 동의 항목이 없는 앱의 재동의 한계 안내 포함, 연결 테스트 결과, 끄기 전 영향 확인, 일반 OIDC 추가, 정책 탭, 알림 5종의 사용 여부와 발송 수단과 템플릿을 다루는 알림 탭과 그 편집, 미리보기, 기본값 복원 창), 진단과 통계 화면, 회원 상세 「소셜 로그인」 탭과 회원 목록 가입경로 필터 문구를 일본어로 제공합니다.
- 사이트가 일반 회원가입을 받지 않을 때 처음 보는 소셜 계정에 보이는 「지금은 회원가입을 받지 않습니다」 안내를 일본어로 제공합니다.
- 서버가 돌려주는 안내와 오류 문구, 검증 항목 이름, 활동 로그, 알림 5종의 제목과 본문, 알림 편집 화면의 「사용 가능한 변수」 설명, 권한과 관리자 메뉴 이름, 내장 제공자 4종의 표시 이름, 관리자 스케줄 관리에 보이는 보존 기간 정리 예약 작업의 이름과 설명을 일본어로 제공합니다.
