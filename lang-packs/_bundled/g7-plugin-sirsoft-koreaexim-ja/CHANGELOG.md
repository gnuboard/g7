# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.0] - 2026-09-14

### Added

- 환율 갱신 실패 알림 템플릿 편집 창 「사용 가능한 변수」 설명(`messages.notification_variables.*`)의 일본어 번역을 제공합니다.
- 수출입은행 환율 플러그인 일본어 언어팩 최초 릴리즈. 환경설정(인증키, 갱신 정책), 갱신 이력, 갱신 실패 알림, 권한과 역할 이름을 일본어로 제공합니다.
- 알림 수단 이름은 코어가 제공하는 이름을 쓰도록 바뀌어 플러그인 자체 번역을 두지 않습니다.
- 발송 수단 복수 지정 화면의 일본어 번역을 추가했습니다.
- 환율 이력 조회에서 종료일이 시작일보다 앞설 때의 안내(`date_range_invalid`) 일본어 번역을 추가했습니다.
- 이력 조회 검증 오류 문구에 쓰는 칸 이름(`validation.attributes`) 일본어 번역을 추가했습니다.
