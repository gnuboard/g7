# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.4] - 2026-10-10

### Added

- 클레임 추가결제(취소/반품/교환 시 추가 결제) 안내·오류 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 클레임 결제 승인·환급 실패 안내가 한국어로 보이던 공백이 해소됩니다.
- 결제창을 열어 둔 사이 청구액이 바뀌어 결제를 다시 시작해야 할 때의 안내 문구도 함께 번역했습니다.
- 레이아웃 편집기에 쓰이는 입금통보 웹훅 URL 데이터 소스 이름(`editor.data_source.webhook_info`)의 일본어 번역을 추가했습니다.
- 승인 금액을 확인하지 못해 결제를 자동 취소할 때 토스페이먼츠에 남기는 취소 사유(`errors.approval_verification_cancel_reason`)의 일본어 번역을 추가했습니다.
- 설정 화면의 결제 후 이동 주소(성공·실패) 형식 오류 안내(`settings.redirect_url_format`)의 일본어 번역을 추가했습니다.
- 주문 상세 가상계좌 입금 안내 문구(제목·은행·계좌번호·예금주·입금 금액·입금 기한·자동 취소 경고)를 일본어로 제공합니다.
- 플러그인 설정 읽기 전용 안내의 일본어 번역을 추가했습니다.

### Changed

- 설정 화면의 웹훅 URL 안내(`settings.webhook_url_hint`)를 「경로 앞에 도메인을 붙이라」에서 「위 주소를 그대로 복사해 등록」으로 바꿨습니다 — 화면이 이제 전체 주소를 보여 주고 복사합니다.
- 설정 「웹훅 secret 검증」 안내(`settings.webhook_secret_verify_hint`)에 「끄면 입금 없이 결제완료로 만들 수 있고, 끈 동안의 보안 사고는 운영자 책임」 문장의 일본어 번역을 추가했습니다.

## [1.0.3] - 2026-09-06

### Added

- 결제 모듈 주소를 확인하지 못했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 한국어 안내가 보이던 문제가 해소됩니다.

## [1.0.2] - 2026-08-19

### Added

- 결제 처리 실패 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 결제가 실패했을 때 한국어 안내가 보이던 문제가 해소됩니다.

## [1.0.1] - 2026-08-10

### Changed

- 결제 성공·실패 리다이렉트 주소 안내 문구를 갱신했습니다 — 상점 주소 설정을 따라 자동으로 채워지는 `{shopBase}` 자리표시자 설명으로 바뀌었습니다.

## [1.0.0] - 2026-07-13

### Added

- 현금영수증 발급·취소 안내와 오류 메시지 일본어 번역 추가 — 일본어 로케일에서 현금영수증 발급 결과와 실패 사유가 일본어로 표시됩니다.
- 환불 관련 안내(에스크로 부분취소 불가·환불 계좌 누락) 일본어 번역 추가.
- 결제 화면 프론트엔드 텍스트 일본어 번역 추가 — 결제 관련 화면이 일본어 로케일에서 자연스럽게 표시됩니다.
- 주문서형 결제수단(카드·가상계좌·계좌이체·휴대폰·간편결제 9종)의 이름과 설명 일본어 번역 추가 — 일본어 로케일 주문서에서 결제수단이 일본어로 표시됩니다.
- 관리자 설정 화면의 결제 방식·가상계좌·에스크로 항목과 입력값 오류 안내 일본어 번역 추가.
