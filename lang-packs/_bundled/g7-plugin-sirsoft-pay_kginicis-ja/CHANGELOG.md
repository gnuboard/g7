# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.2.0] - 2026-10-10

### Added

- 결제 정보의 간편결제 표기(사용자 `user.easy_pay_label`, 관리자 `admin.easy_pay_provider`)의 일본어 번역을 추가했습니다.
- 가상계좌 입금 안내의 입금 금액·자동 취소 안내 문구(`user.vbank_amount` 「入金金額」·`user.vbank_notice`)의 일본어 번역을 추가했습니다.
- 영수증 버튼을 누른 뒤 조회 중에 보이는 「로딩 중...」 문구의 일본어 번역을 추가했습니다.
- 에스크로 배송 등록의 택배사 「기타」와 구매거절 「일시」의 일본어 번역을 추가했습니다.
- 클레임 추가결제(취소/반품/교환 시 추가 결제) 안내·오류 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 클레임 결제 승인·환급 실패 안내가 한국어로 보이던 공백이 해소됩니다.
- 클레임 추가결제 금액·주문번호 불일치 안내 문구의 일본어 번역을 추가했습니다.
- 로그인하지 않은 상태로 에스크로 구매확정 창을 열었을 때 보이는 안내 문구의 일본어 번역을 추가했습니다.
- 영수증 조회 버튼, 일본 결제 확인서(제목·안내·항목 이름·입금 상태·결제수단·간편결제 이름), 가상계좌·편의점 입금 안내와
  확인서 인쇄 버튼의 일본어 번역을 추가했습니다 — 일본어 로케일에서 이 글자들이 한국어로 보이던 공백이 해소됩니다.
- 설정 화면의 결제 후 이동 주소(성공·실패) 형식 오류 안내(`settings.redirect_url_format`)의 일본어 번역을 추가했습니다.
- 에스크로 구매확정 창(PC·모바일)의 제목·준비 중 안내, 관리자 취소·현금영수증 발행 취소의 기본 사유 문구의 일본어 번역을 추가했습니다.
- 플러그인 설정 읽기 전용 안내의 일본어 번역을 추가했습니다.

### Removed

- 한국어 원본에서 사라진 현금영수증 발급 화면 문구 14건(`admin.cash_receipt_*`)을 팩에서 함께 정리했습니다. 쓰이지 않는 번역만 빠지며 화면 동작은 달라지지 않습니다.

## [1.1.2] - 2026-09-06

### Added

- 결제 모듈 주소를 확인하지 못했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 한국어 안내가 보이던 문제가 해소됩니다.

## [1.1.1] - 2026-08-19

### Added

- 에스크로 배송등록·구매거절확인 검증 안내 문구(운송장번호·택배사·기본 확인자명)의 일본어 번역을 추가했습니다.
- 결제 처리 실패 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 결제가 실패했을 때 한국어 안내가 보이던 문제가 해소됩니다.

## [1.1.0] - 2026-08-10

### Added

- 해외결제(CBT) 연결 진단 결과 안내의 일본어 번역을 추가했습니다. 일본어 로케일에서 안내 대신 내부 식별자가 보이던 문제가 해소됩니다.
- 해외결제(CBT) 편의점·가상계좌 입금 시뮬레이션 안내 문구 일본어 번역 추가.
- 현금영수증 발급사 이름(`cash_receipt.provider_name`) 일본어 번역 추가.

### Changed

- 결제 성공·실패 리다이렉트 주소 안내 문구를 갱신했습니다 — 상점 주소 설정을 따라 자동으로 채워지는 `{shopBase}` 자리표시자 설명으로 바뀌었습니다.

### Fixed

- 환불 금액 안내에서 통화 단위(円) 고정 표기를 제거했습니다 — 결제 통화의 단위로 표시됩니다.

### Removed

- KG이니시스 전용 현금영수증 발행 화면이 제거되면서 함께 쓰이지 않게 된 발행 오류 안내 3종의 번역을 정리했습니다.

## [1.0.1] - 2026-07-16

### Added

- 주문 설정 화면의 KG 이니시스 테스트모드 경고(`kginicis_test_mode_status`, `test_mode_settings_warning_*`) 일본어 번역 추가 — 테스트결제 상태 안내와 실결제 설정 이동 버튼이 일본어 로케일에서 자연스럽게 표시됩니다.

## [1.0.0] - 2026-07-01

### Added

- 라이브 일본 결제(CBT) 설정 검증 안내(`settings_validation.*` — 일본 CBT 해시키·MID·가맹점명·연락처 입력 필수 안내와 샘플 값 교체 안내) 일본어 번역 추가 — 라이브 모드 일본 결제 설정 입력 검증 실패 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
