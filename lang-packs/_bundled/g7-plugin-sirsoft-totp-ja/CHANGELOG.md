# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,

## [1.0.0] - 2026-10-10

### Added

- 인증 앱(TOTP) 2단계 인증 플러그인 일본어 언어팩 최초 릴리즈. 코어 7.1.0 이상이 필요합니다.
- 등록 화면의 안내와 버튼, 백업 코드 1회 노출 경고, 인증 실패·중복 등록 안내, 회원 상세의
  「인증 앱」 탭 문구를 일본어로 제공합니다.
- 관리자 강제 해제 활동 로그의 액션 이름과 설명 문구를 일본어로 제공합니다. 없으면 일본어
  로케일의 활동 로그 목록에 이 항목만 번역 키가 그대로 노출됩니다.
- 백업 코드 「전체 복사」 버튼과 복사 완료 안내를 일본어로 제공합니다.
- 플러그인 설정의 「사이트 설정」 카드(인증 앱에 표시할 사이트 이름, 미등록 회원의 이메일 인증번호
  허용 여부와 끌 때의 경고, 저장 버튼·안내)와 레이아웃 편집기의 「인증 앱 운영 설정」 데이터 소스
  이름을 일본어로 제공합니다.
- 관리자가 인증 앱을 등록하지 않은 회원의 등록 해제를 눌렀을 때의 「해제할 것이 없음」 안내를 일본어로 제공합니다.
- 회원 상세 「인증 앱」 카드의 등록 여부 표시(「登録状態」·「登録済み」·「未登録」), 미등록 회원 안내, 등록 여부를 볼 권한이 없을 때의 안내를 일본어로 제공합니다.
- 플러그인 설정 읽기 전용 안내의 일본어 번역을 추가했습니다.
