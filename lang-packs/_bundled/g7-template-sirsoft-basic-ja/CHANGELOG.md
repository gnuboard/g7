# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.2.0] - 2026-10-10

### Added

#### 공통 화면 요소
- 선택 상자 검색 결과 없음 문구(`common.no_results`, 「検索結果がありません」)의 일본어 번역을 추가했습니다.
- 휴대폰 폭 머리글의 장바구니 단추와 메뉴 드로어 닫기 단추에 붙은 새 이름(`nav.cart_with_count` — 「カート（商品 N 点）」, `nav.close_menu` — 「メニューを閉じる」)의 일본어 번역을 추가했습니다. 없으면 일본어 화면에서 화면 읽기 프로그램이 이 두 단추를 한국어로 읽습니다.
- 머리글 테마 전환 단추와 알림 삭제 단추에 붙은 새 이름(`common.theme_select` — 「画面テーマ」, `common.delete_notification` — 「通知を削除」)의 일본어 번역을 추가했습니다. 없으면 일본어 화면에서 화면 읽기 프로그램이 이 두 단추를 한국어로 읽습니다.
- 파일 업로더의 0바이트 파일 안내(`attachment.empty_file`), 회원가입 필수 동의 체크박스 이름(`auth.agree_terms_label`·`agree_privacy_label`), 프로필 사진 미리보기 대체 글(`mypage.profile.avatar_preview`)의 일본어를 추가했습니다.
- 마이페이지 문의 목록 펼침 단추 이름(`common.expand`·`common.collapse`)과 프로필 사진 업로더의 형식 거부·삭제 실패 안내(`attachment.invalid_file_type`·`attachment.delete_failed`)의 일본어를 추가했습니다.
- 수량 칸·+/- 버튼, 모바일 메뉴 닫기 버튼, 페이지 전환·로딩 표시의 읽기 이름(`common.quantity`·`common.quantity_decrease`·`common.quantity_increase`·`common.close_menu`·`common.page_transitioning`·`common.page_loading`)의 일본어 번역을 추가했습니다.
- 장바구니 상품 줄 삭제 버튼의 읽기 이름(`shop.cart.delete_item` — 「상품 삭제」)의 일본어 번역을 추가했습니다.
- 리뷰 별점 단추 이름과 파일 고르개(파일 선택) 문구의 일본어 번역을 추가했습니다.
- 알림 읽음·삭제 권한 없음 안내의 일본어 번역을 추가했습니다.

#### 로그인·회원
- 본인인증 메일 링크를 연 화면(본인 확인 결과 안내)의 일본어 문구를 추가했습니다.
- 로그인 비밀번호 변경 단계·비밀번호 규칙 안내·마이페이지 비밀번호 상태 문구(`auth.password_change.*`·`auth.password_rules.*`·`mypage.profile.password_status.*`)를 일본어로 번역했습니다.
- 휴면이 풀린 로그인에 뜨는 안내 문구를 일본어로 번역했습니다(`auth.dormancy_restored`). 없으면 일본어 로케일의 회원이 자기 계정이 잠겼다 풀린 사실을 한국어 안내로만 보게 됩니다.
- 회원 로그인의 인증 앱(OTP) 단계 문구를 일본어로 번역했습니다 — 앱 코드 입력 안내·라벨·입력 예시·백업 코드 안내(`two_factor.*`) 입니다. 없으면 일본어 로케일의 로그인 화면에 한국어가 섞여 보입니다.
- 내 정보 수정의 **언어 선택**에 일본어 항목 라벨을 추가했습니다(`日本語 (Japan)`) — 종전에는 선택지로 제시되면서도 내부 이름이 그대로 보였습니다.

#### 게시판·스크랩·반응
- 권한이 없어 내용이 가려진 비밀 댓글 자리에 뜨는 안내 문구(`board.comment.secret_comment` — 「비밀 댓글입니다.」)의 일본어 번역을 추가했습니다. 없으면 일본어 로케일에서 이 안내만 한국어로 보입니다.
- 게시글 스크랩(북마크) 기능의 일본어 번역을 추가했습니다. 게시글 상세의 스크랩 버튼, 마이페이지 스크랩 탭·목록·빈 목록 안내, 스크랩 해제 확인 모달 문구가 일본어 로케일에서 자연스럽게 표시됩니다.
  - 스크랩 목록이 표 형태로 개편되면서 추가된 컬럼 제목(게시판·제목·작성자·댓글·스크랩일·관리)과 게시글 제목 검색 입력란 안내 문구(`mypage.scrap.search_placeholder`)도 함께 번역했습니다.
  - 원글이 삭제된 스크랩은 "삭제됨" 표시로 구분되며, 목록 상단에는 원글이 삭제돼도 스크랩 기록이 남아있다는 안내가 표시됩니다.
  - 일괄 해제 버튼(`mypage.scrap.bulk_delete`)은 확인 창·토스트와 같은 「選択解除」로 적었습니다.
- 마이페이지 스크랩 화면이 표 형태로 개편되면서 늘어난 문구와, 게시글 검색 대상(제목·내용·제목+내용) 라벨의 일본어 번역을 추가했습니다. 스크랩 일괄 해제 확인 모달 이름도 함께 번역했습니다.
- 마이페이지 「내 반응」·「내 신고」 화면의 일본어 번역을 추가했습니다.
  - 서브탭 이름, 목록 컬럼(게시판·대상·반응·일시·관리), 반응 유형과 대상 구분 필터, 단건·선택 해제 확인 모달
  - 신고 상태 배지(접수·검토·처리·반려)와 대기 중 신고 취소 확인 문구, 원글이 지워졌거나 게시판에서 반응을 끈 행에 붙는 배지 문구
  - 게시글·댓글 반응 버튼의 안내 문구(로그인 필요·처리 실패·본인 글·본인 댓글)도 함께 번역했습니다.
- 「내 신고」의 찾을 곳 선택에 붙는 「신고 사유」 라벨을 일본어(`通報理由`)로 추가했습니다. 같은 화면의 다른 찾을 곳(제목+내용·제목·내용)과 나란히 표시됩니다.

#### 쇼핑·주문
- 주문완료 화면에서 같은 이름의 배송지가 이미 있어 저장하지 않았다는 안내(`shop.order_complete.address_name_exists`)의 일본어 번역을 추가했습니다.
- 내 정보·내 정보 수정의 배송국가 칸에 저장한 나라가 지금 배송할 수 없어 적용되지 않는다는 안내(`mypage.shipping_country_settings.saved_not_applied` — 「保存された配送国 {{saved}} は現在配送できない国のため適用されません。現在適用中の配送国: {{applied}}」)의 일본어 번역을 추가했습니다.
- 주문서 결제 금액 상자의 마일리지 차감 전 금액 행 라벨(`shop.checkout.amount_before_points` — 「マイレージ差引前の金額」)의 일본어 번역을 추가했습니다.
- 구매할 수 있는 옵션이 없는 상품 안내(`product.no_purchasable_option`)의 일본어 번역을 추가했습니다.
- 주문 상세의 배송지 변경에서 저장된 배송지를 고르지 않았을 때의 안내(`mypage.order_detail.select_saved_address_required`)와, 주문서에 선택할 결제 방법이 없을 때의 안내(`shop.checkout.no_payment_methods`) 일본어 번역을 추가했습니다.
- 주문서에서 고른 배송지를 그 자리에서 고쳤을 때 뜨는 「저장된 배송지 갱신」 체크박스 문구의 일본어 번역을 추가했습니다.

#### 취소·반품·교환
- 해외 주문의 교환 신청 화면 재발송지 [변경] 폼에 새로 생긴 도시·주 칸 라벨(`claim.apply.city`·`claim.apply.state` — 「都市」「州/道」)의 일본어 번역을 추가했습니다. 체크아웃 해외 주소 칸과 같은 표현입니다.
- 사용 마일리지를 차감하지 않은 주문의 반품·취소 신청 화면 반환액 표기(`claim.apply.comparison.refund_points_not_deducted` — 「0円（差し引かれていないマイレージ）」)의 일본어 번역을 추가했습니다.
- 취소·환불 신청 화면에서 즉시 처리되는 분기의 배지와 안내 문구를 새 규칙에 맞춰 일본어도 갱신했습니다 — 접수와 동시에 환불이 진행되지만 계좌로 송금해야 하는 환불은 판매자 확인 뒤에 보낸다는 사실이 함께 드러납니다.
- 클레임 신청서와 신청서 상세의 "주문금액 비교" 표 일본어 번역을 추가했습니다.
  - 유형별 전/후 열 이름(취소·환불·반품·교환), 정가·판매가·쿠폰·배송비·포인트·과세·부가세·실결제·적립 행
  - 교환 옵션 치환 행과 접수 시점 비교표가 없는 구형 신청서 안내
  - 최종 환불 예정액 네 줄과 복원 쿠폰 안내, 환불 우선순위(PG 우선·마일리지 우선) 선택지
- 신청서 상세의 "진행 단계" 카드 제목과 레이아웃 편집기의 그 카드 이름 일본어 번역을 추가했습니다.
- 비회원 취소·반품·교환 화면 문구 일본어 번역 추가 — 비회원 신청서 상세와 신청·수정 화면의 제목과 설명, 주문 상세로 돌아가는 링크, 주문 상세 아래 "이 주문의 취소·반품·교환" 목록 제목, 추가결제를 마치고 돌아온 뒤 주문을 다시 조회하라는 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 교환·반품·취소·환불 신청서 화면 문구 일본어 번역 추가 — 신청 상품 선택, 재발송지, 신청 사유와 첨부, 신청 요약(금액·청구 방식·결제 수단), 교환상품 변경 창의 안내와 오류 문구가 일본어 로케일에서 자연스럽게 표시됩니다.
- 주문 상세 화면의 신청 버튼과 클레임 추가결제 합계 표기, 신청 가능 상품 안내 문구 일본어 번역 추가.
- 반품·취소·환불 신청서의 유형별 문구 일본어 번역 추가.
  - 즉시 취소와 환불 신청이 갈리는 안내와 배지, 반품 요약의 환불 예정액·회수 배송비 차감·최종 환불액 세 줄
  - 환불 계좌 입력란, 신청 취하 확인 창, 추가결제 결과(성공·실패·취소) 안내와 실패 코드 표기
- 마이페이지 화면 편집기의 환불 계좌·신청 취하 창 라벨 일본어 번역 추가.
- 취소·반품·교환 신청 내역 화면 문구 일본어 번역 추가.
  - 마이페이지 탭과 유형별 목록(신청일·주문번호·상품·사유·송장·금액·빈 목록 안내)
  - 신청서 상세(신청 상품과 교환 대상, 회수·재발송 배송 정보, 원 주문과의 대비표, 추가결제와 환불 정보, 사유·귀책·첨부 사진)
  - 신청서 수정 화면(수정 범위 안내, 청구 차액 안내, 환불 계좌 안내, 저장 결과)
- 신청 내역 상세의 미수납 추가결제 결제 버튼과 결제 수단·진행·성공·실패 안내 문구 일본어 번역 추가.
- 마이페이지 화면 편집기의 신청 내역 목록·상세 데이터 소스와 상세 화면 영역 라벨 일본어 번역 추가.
- 구매자 클레임 화면의 **상품별 운송장·선교환 반송 안내·판매자 접수 안내**의 일본어 번역을 추가했습니다.
- 환불 신청서에서 **환불받을 계좌를 채우라고 안내하는 문구**의 일본어 번역을 추가했습니다
  (`claim.apply.refund_account_required_to_submit`). 계좌로 환불되는 주문에서 세 칸이 비면
  [환불 신청하기]가 잠기는데, 종전에는 그 이유를 알리는 자리가 일본어 로케일에 없었습니다.
- 사진 첨부 일부 실패를 **몇 장 중 몇 장**으로 알리는 문구(`claim.image.upload_partial_failed`)와,
  교환 옵션에서 **지금 교환받을 수 없는 조합**을 골랐을 때의 안내(`claim.change_product.unavailable`)의
  일본어 번역을 추가했습니다.
- 승인된 신청서의 수정 주소로 들어왔을 때의 안내(`claim.edit.not_editable`) 일본어 번역을 추가했습니다.
- 사진 첨부의 용량·형식 거절 안내(`attachment.file_too_large` · `attachment.file_type_not_allowed` ·
  `attachment.upload_failed` · `attachment.upload_response_invalid`)와 주문 목록 추가옵션 요약 「他N件」
  (`mypage.orders.additional_options_more`)의 일본어 번역을 추가했습니다. 종전에는 일본어 화면에도 한국어 문구가 떴습니다.
- 환불 계좌 칸이 가린 등록 계좌로 채워졌을 때의 안내(`claim.apply.refund_account_masked_hint`) 일본어 번역을 추가했습니다.
- 회원 주문·클레임 상세의 「마일리지로 환불」 금액과 유효기간 안내 문구(「マイレージで返金」·「マイレージで付与」)를 추가했습니다.
- 회원 클레임 상세의 「교환 차액 환급」 줄 문구를 추가했습니다.
- 회원·비회원 신청서 상세의 「환불 진행」 칸 문구(`claim.detail.linked_title`·`linked_source`·`linked_empty`)를 추가했습니다.
- 7.1.0 권한 정비에 맞춘 안내 문구의 일본어 번역을 추가했습니다 — 신청 권한이 없거나 주문 취소 권한이 없을 때 취소·반품·교환 신청 화면의 안내(`claim.apply.no_request_permission`·`no_cancel_permission`)와 주문 권한이 없을 때의 주문 거절 안내(`shop.order_permission_denied`)입니다. 없으면 일본어 화면에서 이 안내가 한국어로 보입니다.
