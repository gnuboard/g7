## [1.0.0] - 2026-11-20

### Added

- 히어로섹션 플러그인 일본어 언어팩 최초 릴리즈. 코어 7.2.0 이상이 필요합니다.

#### 관리자 화면

- 관리자 「히어로섹션 관리」 화면(위치 탭, 노출 중 배너 미리보기, 위치별 슬라이더 설정, 상태 필터·검색, 일괄 노출·비노출·삭제, [순서 변경] 창)과 배너 등록·수정 화면(언어별 문구, 문구 표시·색·정렬, PC·모바일 이미지와 권장 크기 안내, 링크, 노출 기간, 미리보기) 문구를 일본어로 제공합니다.
- 게시판 목록·상품 상세·카테고리 목록 위치 이름, 대상 고르기(찾기·먼저 고르기 안내·없는 대상)·「등록되지 않은 위치」 안내, 등록·수정 화면의 대상 칸과 저장 잠김 이유, 위치·대상 검증과 활동 로그 문구(목록 한 줄의 위치 이름·대상 이름 포함)를 일본어로 추가했습니다.
- 동적 위치의 대상 목록(배너가 있는 대상·전체/노출 중 건수·관리·쪽 넘김·대상 목록으로·받지 못했을 때 다시 받기)과 그 데이터 소스 이름, 위치 정보를 받는 중·받지 못함·없는 위치 안내와 그때의 저장 잠김 이유를 일본어로 추가했습니다.
- 다른 확장이 더한 위치에서 히어로가 사이트 자리를 직접 채울 수 없을 때의 관리자 안내와, 그 자리의 편집기 데이터 소스 이름을 일본어로 추가했습니다.
- 배너 머리글(제목 위 한 줄)·문구 위치(9칸 빠른 선택·가로/세로·PC/휴대폰)·문구 상자 폭·등장 효과 8종과 속도·시작 지연·배너 바탕 밝기·미리보기 끌기 안내·효과 다시 보기, 위치 설정의 「메뉴 겹치기」와 안내, 충돌 비교의 머리글·문구 자리·미디어 항목과 옛 영상 안내, 저장 연타 때 「이미 저장됨」 안내, 머리글·메뉴 겹치기 검증·활동 로그 문구를 일본어로 추가했습니다.
- 배너 미디어 종류(이미지·영상 파일)와 PC·모바일 영상 칸, 대표 이미지 안내, 저장 잠김 이유, 목록의 미디어 표시, 환경설정의 영상 최대 용량, 사이트 슬라이더의 배너 일시정지 단추 이름, 영상 검증 오류와 영상 교체·삭제 활동 로그 문구를 일본어로 추가했습니다.
- 위치별 슬라이더 설정의 「표시 폭」(본문 폭·화면 전체)과 그 안내 문구를 일본어로 추가했습니다.
- 위치별 슬라이더 설정의 「최대 높이」(PC·태블릿·휴대폰)와 그 안내·입력 범위 오류·메뉴 겹치기 안내 문구, 최대 높이 검증·활동 로그 문구를 일본어로 추가했습니다.
- 동적 위치의 「이 대상 설정」 카드(항목별 「이 대상만 따로」·출처·제한 없음·저장·위치 기본값으로 되돌리기·불러오는 중·없는 대상 안내)와 대상 목록의 「대상 설정 있음」 표식·바뀐 목록 제목, 그 데이터 소스 이름, 대상 설정 저장·되돌리기 메시지와 활동 로그·검증 항목 이름, 배너 구성(배경형·프로모션형·바탕색·추천값과 그 안내), PC·휴대폰 문구 폭, 순차 등장·그림 등장 효과, 적용될 슬라이더 설정 요약 문구를 일본어로 추가했습니다.
- 전환 효과 4종(큐브·뒤집기·커버플로·겹쳐 넘기기)과 점 표시 단추 이름을 일본어로 추가했습니다.
- 배너 등록·수정 화면의 저장 잠김 이유·버튼과 링크 안내, 목록의 제작 상태 표시·「사이트에서 보기」·빈 상태 안내 문구를 일본어로 추가했습니다.
- 배너 편집의 업로드 상태·콘텐츠 언어 미리보기·확대·이미지 초점·문구 배경·사이트 시간대·수정 충돌 안내를 일본어로 추가했습니다.
- 위치 설정의 「페이징 모양」(점·진행 막대 점·배너 이름 탭·번호·알약 번호)과 그 안내, 검증 항목 이름·활동 로그 항목 이름을 일본어로 추가했습니다.
- 수정 충돌 뒤 「최신본과 내 변경 비교」 창(항목별 변경 주체·선택·적용·재시도)과 미리보기의 문구 넘침·글자 대비(추정) 안내를 일본어로 추가했습니다. 같은 판에서 전체를 다시 번역해 「문구」 번역어를 文言 으로 통일했습니다.
- 대상 슬라이더 설정 조회 실패와 입력 보존·다시 받기 안내를 일본어로 추가했습니다.
- 노출 중 배너 미리보기를 그리지 못했을 때의 안내 문구를 일본어로 추가했습니다.

#### 사용자 화면

- 사용자 화면 배너 슬라이더의 이전·다음·일시정지 단추 이름, 환경설정 화면(이미지 최대 용량·캐시 시간·서버 업로드 한도 안내) 문구를 일본어로 제공합니다.
- 사이트 화면 슬라이더의 「관리자에서 수정」 단추 문구를 번역했습니다.
- 사이트 슬라이더의 캐러셀·슬라이드 역할 이름, 「3개 중 1번째」 장 번호, 긴 문구 영역 이름, 슬라이더 모양을 불러오지 못했을 때의 알림 이름을 일본어로 추가했습니다.

#### 환경설정

- 환경설정 「공개 자산 디스크」 칸(이름·안내·「코어 설정 따름」·쓸 수 없게 된 디스크 안내)과 바뀐 설정 화면 설명을 일본어로 추가했습니다.
- 환경설정 업로드 탭 「썸네일 규격」 표에 보이는 관리 목록 규격 이름(「배너 목록」)을 일본어로 추가했습니다.
- 환경설정 업로드 탭 「기존 이미지 썸네일 만들기」 창에서 고르는 원본 종류 중 배너 이미지 이름(「ヒーローセクションのバナー画像」)을 일본어로 추가했습니다.

#### 서버 문구와 활동 로그

- 서버가 돌려주는 안내와 오류 문구, 검증 항목 이름, 활동 로그, 권한과 관리자 메뉴 이름, 임시 이미지 정리 예약 작업 이름을 일본어로 제공합니다.
- 배너 수정 화면에서 바꾼 이미지를 저장할 때의 안내·오류 문구와 이미지 교체·삭제 활동 로그를 일본어로 제공합니다.
- 활동 로그의 이미지·영상 교체·삭제 문구에 들어가는 기기 이름(`activity_log.devices.*` 「PC」·「モバイル」)을 일본어로 추가했습니다.
