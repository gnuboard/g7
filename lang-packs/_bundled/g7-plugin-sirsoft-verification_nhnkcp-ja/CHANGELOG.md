## [1.0.0] - 2026-08-10

### Added

- NHN KCP 휴대폰 본인확인 플러그인(sirsoft-verification_nhnkcp)의 일본어 번들 언어팩 초기 제공
- 본인확인 안내 창 문구(시작 안내·진행 중 안내·모바일 페이지 이동 안내·팝업 차단 안내)의 일본어 번역
- 실패 안내 문구(취소·성인 인증 필요·중복 가입·인증기관 통신 실패·인증 정보 불완전·인증 세션 만료·저장 실패)의 일본어 번역
- 관리자 환경설정 문구(테스트 모드·운영 인증 정보·사이트 코드·암호화 키·웹사이트 ID·중복 가입 차단 기준)의 일본어 번역
- 마이페이지 본인확인 카드 문구(이름·생년월일·휴대폰·인증 일시·성인 여부, 생년월일 미제공·성인 여부 확인 불가 안내 포함)의 일본어 번역
- 레이아웃 편집기 상태 변종 라벨(본인확인 완료 / 생년월일 미제공 / 내역 없음)의 일본어 번역
- 본인확인 결과 중계 페이지 제목의 일본어 번역 — 인증 창에서 결과를 전달하는 중계 페이지의 제목이 일본어 로케일로 표시됩니다.
