## [1.0.0] - 2026-11-20

### Added

- 팝업 플러그인(sirsoft-popup) 1.0.0 의 일본어 번역을 처음 제공합니다 — 관리자 화면(팝업 관리 목록(「지금 노출 중」 항목의 수정 링크 이름·「더 보기」/「접기」 포함)·행 메뉴 노출 전환·등록/수정(이미지 권장 비율 안내, 저장할 수 없는 이유 안내, 실제 크기 미리보기·빈 미리보기 안내, 이미지 위 글 상자 편집기(대비 안내·미리 볼 바탕 포함) 포함)·환경설정과 그 경로 표시), 사용자 팝업 레이어 문구(닫기·보지 않기(여러 장일 때 「모두」 문구 포함)·이전/다음·대체 텍스트 없는 링크 이름), 서버 안내·검증·활동 로그·예외(팝업 이미지 복사 실패) 문구(이미지 저장 실패 안내, 다른 관리자가 올린 임시 이미지 삭제 거부 안내, 허용하지 않는 내용만 있어 비게 되는 본문 안내, 이미지 밖으로 나간 글 상자 안내 포함), 관리자 메뉴·권한·예약 작업 이름.
- 활동 로그의 이미지 교체·삭제 문구에 들어가는 기기 이름(`activity_log.devices.*` 「PC」·「モバイル」)을 일본어로 추가했습니다.
- 환경설정 「저장소」 카드와 「공개 자산 디스크」 칸(이름·안내·「코어 설정 따름」·쓸 수 없게 된 디스크 안내)을 일본어로 추가했습니다.
- 표시 내용이 없는 본문을 안내하는 검증 메시지를 갱신했습니다.
- 글 상자 바탕 색·바탕 진하기의 검증 항목 이름이 일본어로 나오도록 키 이름을 원본 플러그인과 맞췄습니다.
- 코어 7.2.0 이상이 필요합니다(`g7_version >=7.2.0`).
- 환경설정 업로드 탭 「기존 이미지 썸네일 만들기」 창에서 고르는 원본 종류 중 팝업 이미지 이름(「ポップアップ画像」)을 일본어로 추가했습니다.
