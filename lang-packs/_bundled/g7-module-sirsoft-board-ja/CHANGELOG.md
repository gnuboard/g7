# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.5] - 2026-09-12

### Added

- 관리자 게시글 상세에서 비밀글 조회 권한이 없는 관리자에게 비밀 댓글 자리에 뜨는 안내(`admin/posts.detail.secret_comment_notice` — 「非公開コメントです」)의 일본어 번역을 추가했습니다. 없으면 일본어 로케일에서 이 안내만 한국어로 보입니다.
- 관리자 게시글·답변 카드의 첨부파일 내려받기 실패 안내(`admin/posts.detail.download_failed`)의 일본어 번역을 추가했습니다.
- 상품 문의 연동 실패 문구(문의·답변 수정·삭제 실패, 답변 없음, 게시판 설정 변경으로 글을 찾을 수 없음)와 활동 이력의 비밀글 표기 일본어 번역을 추가했습니다.
- 레이아웃 편집기에 쓰이는 개인정보 보유기간 대상·직권 실행 창 이름(`privacy_retention.targets.editor_label`·`manual_run.editor_label`)의 일본어 번역을 추가했습니다.
- 게시판 사용자 권한 「공지 등록」(`posts.write-notice`)의 일본어 번역을 추가했습니다 — 권한 설정 화면의 권한 이름·설명(「お知らせ登録」), 게시판 기본 권한 표와 저장 검증의 항목 이름, 권한 없이 공지로 지정할 때의 거부 메시지(`permission.notice_denied`)입니다.
- 게시판 환경설정 「개인정보 보유기간」 카드(작성 IP·비회원 글)의 「지금 실행」 버튼과 직권 실행 확인 창·진행 상태 줄 문구(`admin/settings.privacy_retention.manual_run.*`)와 편집기 데이터 소스 이름의 일본어 번역을 추가했습니다. 두 축을 한 줄씩 정리하면서 줄 이름·대상 건수·공용 「対象を表示」(`privacy_retention.targets.row_ip`·`row_guest`·`count`·`view`)를 더하고, 쓰지 않게 된 축별 건수·보기 문구는 뺐습니다.
- 게시판 환경설정 「개인정보 보유기간」 카드의 대상 건수(작성 IP·비회원 글)와 「대상 보기」 명단 창 문구(`admin/settings.privacy_retention.targets.*`), 명단 열 이름과 글·댓글 구분(`messages.privacy_retention.target_columns.*`·`target_kinds.*`), 레이아웃 편집기의 데이터 소스 이름(`editor.data_source.privacyTargets`)의 일본어 번역을 추가했습니다.
- 게시판 대시보드 권한 2건(`sirsoft-board.dashboard`·`sirsoft-board.dashboard.view`)의 일본어 번역을 추가했습니다 — 모듈 설치 시 함께 만들어지는 고정 권한인데 시드에 빠져 있어 일본어 로케일의 역할 수정 화면에서 한국어로 남아 있었습니다.
- 게시글 스크랩(북마크) 기능의 일본어 번역을 추가했습니다. 스크랩 활동 로그 문구, 스크랩 처리 안내 메시지, 게시판 설정 화면의 스크랩 사용 토글 라벨이 일본어 로케일에서 자연스럽게 표시됩니다.
- 관리자 스크랩 관리 화면의 일본어 번역을 추가했습니다(`admin/scraps.json` 46건). 목록 제목·검색 대상(제목·내용·게시판·회원·작성자)·게시판과 기간 필터·스크랩 해제 확인 모달, 그리고 원글이 지워졌거나 게시판에서 스크랩을 끈 행에 붙는 배지 문구가 일본어로 표시됩니다. 좌측 메뉴 「스크랩 관리」와 권한 3종(`sirsoft-board.scraps`·`.view`·`.manage`)도 함께 번역했습니다.
- 관리자 게시글 목록의 일괄 처리(삭제·블라인드·복구) 문구 16건을 추가했습니다. 선택 건수 표시, 세 가지 확인 모달, 블라인드 사유 입력 라벨, 답글이 함께 지워진다는 안내가 일본어로 표시됩니다. 제목·내용을 갈라 찾는 검색 대상 라벨과 그에 딸린 입력 검증 문구도 함께 번역했습니다.
- 회원 상세의 스크랩 탭 문구 7건을 추가했습니다 — 탭 이름, 스크랩 수와 단위, 마지막 스크랩 시각, 스크랩이 없을 때의 안내, 목록으로 이동하는 링크입니다.
- 게시글·댓글 반응 관리 권한 3종(`sirsoft-board.reactions`·`.view`·`.manage`)과 좌측 메뉴 「반응 관리」의 일본어 번역을 시드에 추가했습니다 — 모듈 설치·갱신 시 함께 만들어지는 고정 권한과 메뉴인데 시드에 빠져 있어 일본어 로케일의 역할 수정 화면과 관리자 메뉴에 한국어로 남아 있었습니다.
- 게시판 환경설정 「개인정보 보유기간」 탭 문구의 일본어 번역을 추가했습니다 — 탭 이름(`tabs.privacy_retention`), 기능 켜기, 작성 IP·비회원 작성자 정보 보유기간, 비회원 글 처리 방식(익명화·삭제)과 삭제 경고, 대상 건수 뱃지, 탈퇴 회원 글 안내, 저장 검증의 항목 이름입니다.
- 게시판 환경설정 「관리자·스텝 일괄 지정」(「管理者・スタッフ一括指定」) 카드·확인 창·결과 문구(`admin/settings.bulk_members.*`, 탭 라벨 `board_settings_tabs.bulk_members`)와 처리 결과 안내(`messages.boards.bulk_members_*`), 요청 검증 항목명(`validation.attributes.bulk_members.*`)의 일본어 번역을 추가했습니다.
- 관리자 게시글 일괄 처리에서 건너뛴 글을 사유와 함께 보여 주는 「スキップされた投稿」 창의 제목·안내(`admin/posts.bulk.skipped.*`)와, 글마다 붙는 건너뛴 사유 6종(`messages.posts_bulk.skip_reasons.*` — 「既に削除された投稿」·「返信が付いた投稿（返信削除ポリシーにより削除不可）」 등)의 일본어 번역을 추가했습니다.
- 알림 수신자 규칙 「관련 사용자」의 관계 이름 네 가지(`messages.notification_relations.*`, 「投稿者」·「元コメントの投稿者」·「元投稿の投稿者」·「掲示板管理者」)를 일본어로 번역했습니다.

### Removed

- 어디서도 쓰지 않던 「IP 주소는 필수입니다」 검증 문구(`validation.comment.ip_address.required`, 백엔드·프론트 각 1건)를 원본 모듈과 함께 지웠습니다 — 게시글 작성 IP 가 개인정보 보유기간 처리로 비워질 수 있게 되면서 뜻도 틀리게 되었습니다.
- ko 원본에서 지운 관리자 설정 문구의 **일본어 번역이 남아 있던 것**(반응 유형 2건)을 정리했습니다. 화면에는 쓰이지 않던 문구입니다.

## [1.0.4] - 2026-09-06

### Added

- 게시판 환경설정 > 일괄 적용 확인 창의 「금지어」 항목 이름 일본어 번역을 추가했습니다 (`admin/settings.bulk_apply.field_labels.blocked_keywords`).
- 열람 권한이 없는 비밀글에 댓글·답글을 작성하려 할 때 표시되는 안내 문구의 일본어 번역을 추가했습니다 (`messages.comment.post_secret`, `validation.comment.post_id.secret`, `validation.post.parent_id.secret`).

## [1.0.3] - 2026-08-19

### Added

- 답글 삭제 정책(reply_delete_policy) 설정 라벨·옵션·차단 안내 문구의 일본어 번역을 추가했습니다.
- 게시판 유형 삭제 등 관리 작업이 서버 오류로 실패했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다.
- 비공개(비밀) 게시글 목록 마스킹 시 표시되는 제목 플레이스홀더(`secret_post_title`)의 일본어 번역을 추가했습니다.
- 첨부 영구 정리 설정의 라벨·도움말과 검증 항목명 일본어 번역을 추가했습니다 (`admin/settings.attachment_purge_*`, `validation.attributes.attachment_settings.*`) — 게시판 환경설정 > 기본 설정의 새 항목과 저장 시 오류 안내가 일본어 로케일에서 표시됩니다.

### Changed

- 신고 반려 누적 제한 안내 문구의 일본어 번역을 실제 동작(설정 건수 도달 시 차단)에 맞게 정정했습니다.

## [1.0.2] - 2026-08-10

### Added

- 첨부파일 개수 상한 초과 안내 문구 일본어 번역 추가.
- 게시판 대시보드 조회 안내 문구 일본어 번역 추가.
- 관리자 게시글 작성·수정 화면의 첨부 안내 문구 일본어 번역 추가 — 게시판에 설정된 첨부 개수·용량이 일본어 로케일에서도 그대로 표시됩니다.
- 게시판 환경설정 일괄 적용 화면의 "선택한 게시판" 안내 문구 일본어 번역 추가.
- 게시판 환경설정의 조회·저장·일괄적용·캐시 초기화 안내 문구 일본어 번역 추가 (`messages.settings.*`) — 저장에 실패했을 때의 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 댓글 비밀번호 확인, 댓글 목록 조회, 게시판 목록·폼 조회 실패, 비밀글 사용 불가 안내 문구의 일본어 번역 추가 — 지금까지 일본어 로케일에서 안내 문구 대신 내부 식별자가 그대로 보이던 화면들이 정상 표시됩니다.
- 게시판 설정 일괄 적용 화면의 입력 항목명과 검증 안내 문구, 신고 상태 변경 불가 안내, 권한 모드 선택 안내의 일본어 번역 추가.

### Removed

- 화면에서 쓰이지 않던 첨부 안내(고정 5개·10MB)와 답변글 깊이 안내(1~5) 번역을 제거했습니다. 실제 상한과 다른 값이라 남겨 둘 이유가 없습니다.

### Fixed

- 게시판 유형 "기본형"의 일본어 표기가 화면마다 달랐던 문제를 수정했습니다. 게시판 유형 목록과 목록 필터에서 서로 다른 한자로 표시되던 것을 하나로 통일했습니다.

## [1.0.1] - 2026-07-08

### Added

- 관리자 게시글 목록의 "사용자 화면 보기" 링크 라벨(`view_user_page`) 일본어 번역 추가 — 관리자에서 해당 게시글의 사용자 화면으로 이동하는 링크가 일본어 로케일에서 자연스럽게 표시됩니다.

## [1.0.0] - 2026-07-01

### Added

- 게시판 첨부파일 다운로드 활동이력의 신규 다국어 키(다운로드 액션 라벨·설명)에 대응하는 일본어 번역 추가
- 게시판 모듈 1.0.0-beta.6 의 신규 다국어 키(상대 시간 표현, 관리자 대시보드 게시판 영역 라벨)에 대응하는 일본어 번역 추가
- 레이아웃 편집기 데이터 소스 라벨 일본어 번역 추가 (`editor.data_source.*`) — 편집기에서 게시판 데이터 소스의 표시 명칭이 일본어 로케일에서 자연스럽게 표시됩니다.
- 레이아웃 편집기 검색엔진 설정의 게시글 SEO 자동값 연결 칩 라벨 일본어 번역 추가 (`seo.auto_value.*`) — 게시글 제목·대표 이미지 등 확장이 제공하는 SEO 데이터의 출처 이름이 일본어 로케일에서 자연스럽게 표시됩니다.
- 게시판 복사 안내 창의 신규 안내 문구(복사 대상·제외 항목·새 슬러그 확인)와 "관리자 메뉴에 표시" 필드 라벨의 일본어 번역 추가 — 게시판 복사·검증 화면이 일본어 로케일에서 자연스럽게 표시됩니다.
- 게시판 분류 검증 메시지(분류 최대 개수 초과·빈 분류명)의 일본어 번역 추가 — 분류 추가 제한 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 게시판 권한 설정의 "비밀글 조회"(`posts.read-secret`) 권한 이름 일본어 번역 추가 — 권한 안내 메시지에서 권한 이름이 일본어 로케일로 자연스럽게 표시됩니다.
- 게시판 설정 일괄 적용 중단(전체 롤백) 안내 문구와 활동 이력 라벨의 일본어 번역 추가 — 일괄 적용 실패 시 롤백 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 첨부 허용 확장자 검증 메시지(최소 1개 필수)의 일본어 번역 추가와 허용 확장자 안내 문구의 일본어 번역 갱신 — 빈 값 저장 차단 정책 변경에 맞춰 일본어 로케일에서 자연스럽게 표시됩니다.

### Changed

- 게시판 금지어(blocked_keywords) 관련 라벨·안내 문구의 일본어 번역을 "禁止ワード" 로 통일 — 게시판 설정·검증 화면의 금지어 용어가 일본어 로케일에서 일관되게 표시됩니다.
- 회원 알림 설정 탭 라벨의 일본어 번역을 "掲示板通知設定" 로 명확화 — 관리자 회원 상세·수정 화면에서 게시판 알림 설정 영역의 명칭이 일본어 로케일에서 다른 알림 영역과 구분되어 표시됩니다.

## [1.0.0-beta.1] - 2026-05-11

### Added

- 게시판 모듈의 일본어 번들 언어팩 초기 제공
