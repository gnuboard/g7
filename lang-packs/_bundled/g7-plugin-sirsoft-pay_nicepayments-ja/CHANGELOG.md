# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.5] - 2026-10-10

### Added

- 주문 완료 화면 영수증 버튼(「영수증 조회」·「로딩 중...」), 결제 실패 알림 2건, 영수증 행의 간편결제 이름표 8건의 일본어 번역을 추가했습니다.
- 마이페이지 주문 상세 영수증 행의 「매출전표 보기」 링크 문구의 일본어 번역을 추가했습니다.
- 클레임 추가결제(취소/반품/교환 시 추가 결제) 안내·오류 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 클레임 결제 승인·환급 실패 안내가 한국어로 보이던 공백이 해소됩니다.
- 클레임 추가결제 금액·주문번호 불일치 안내와 자동 취소 사유 문구의 일본어 번역을 추가했습니다.
- 설정 화면의 결제 후 이동 주소(성공·실패) 형식 오류 안내(`settings.redirect_url_format`)의 일본어 번역을 추가했습니다.
- 플러그인 설정 읽기 전용 안내의 일본어 번역을 추가했습니다.

### Changed

- 주문 상세 가상계좌 안내 제목을 다른 결제대행사와 같은 「仮想口座入金案内」로 맞췄습니다.

## [1.0.4] - 2026-09-06

### Added

- 결제 모듈 주소를 확인하지 못했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 한국어 안내가 보이던 문제가 해소됩니다.

## [1.0.3] - 2026-08-19

### Added

- 가상계좌 환불 입력 필드 표시명(거래 ID·주문번호·취소 금액·취소 사유·환불 계좌번호·은행코드·예금주)의 일본어 번역을 추가했습니다.

### Removed

- 원본 플러그인에서 삭제된 가상계좌 환불 필수값 안내 문구(`errors.vbank_refund_required_fields`)를 함께 정리했습니다 — 개별 필드 검증 메시지로 대체되었습니다.

## [1.0.2] - 2026-08-10

### Changed

- 결제 성공·실패 리다이렉트 주소 안내 문구를 갱신했습니다 — 상점 주소 설정을 따라 자동으로 채워지는 `{shopBase}` 자리표시자 설명으로 바뀌었습니다.

### Fixed

- 환불 금액 안내에서 통화 단위(円) 고정 표기를 제거했습니다 — 결제 통화의 단위로 표시됩니다.

## [1.0.1] - 2026-07-16

### Added

- 가상계좌 환불 검증 안내(`errors.vbank_refund_*` — 환불 대상 주문 없음·환불 불가 결제·환불 금액 불일치·환불 처리 진행 중) 일본어 번역 추가 — 관리자 가상계좌 환불 요청 검증 실패 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 주문 설정 화면의 나이스페이먼츠 테스트모드 경고(`nicepay_test_mode_status`, `test_mode_settings_warning_*`) 일본어 번역 추가 — 테스트결제 상태 안내와 실결제 설정 이동 버튼이 일본어 로케일에서 자연스럽게 표시됩니다.
