# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.1.0] - 2026-10-10

### Added

#### 결제 안내·오류
- 관리자 결제 결과의 「간편결제」 항목(`admin.result_easy_pay`), 결제수단 정보가 없을 때의 결제 오류 안내(`payment.error.method_missing`), 레이아웃 편집기의 모의입금 데이터 소스 이름(`editor.data_source.nhnkcp_mock_deposit`)의 일본어 번역을 추가했습니다.
- 결제 안내·오류 문구(KRW 외 통화 안내·애플페이 iOS 전용 안내·모바일 승인키 실패·KCP 오류)의 일본어 번역을 추가했습니다.
- 영수증 조회 버튼의 불러오는 중 표시와 가상계좌 입금 안내의 「입금 금액」 일본어 번역을 추가했습니다.
- 입금이 끝난 가상계좌 결제의 환불을 계좌 환불로 안내하는 문구의 일본어 번역을 추가했습니다.
- 가상계좌 발급 정보가 없어 결제를 마치지 못했을 때 보이는 안내 문구의 일본어 번역을 추가했습니다.

#### 시스템 점검·설정
- 플러그인 설정의 시스템 점검 카드 문구 18건과 에스크로 택배사 「기타」의 일본어 번역을 추가했습니다.
- 시스템 점검 카드의 항목 줄(항목 이름·검사 결과·조치 안내)과 결제서버 IP 출처 문구(`messages.health.*`)의 일본어 번역을 추가했습니다.
- 시스템 점검을 마쳤을 때의 응답 안내 「システム点検が完了しました。」(`messages.health.checked`)의 일본어 번역을 추가했습니다.
- 설정 화면의 결제 후 이동 주소(성공·실패) 형식 오류 안내(`settings.redirect_url_format`)의 일본어 번역을 추가했습니다.
- 플러그인 설정 읽기 전용 안내, 시스템 점검 권한 없음 안내, 권한이 없어 실행 권한 자동 복구를 하지 않았을 때의 안내(`messages.health.cli.not_executable_no_permission`)의 일본어 번역을 추가했습니다.

#### 클레임 추가결제
- 클레임 추가결제(취소/반품/교환 시 추가 결제) 안내·오류 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 클레임 결제 승인·환급 실패 안내가 한국어로 보이던 공백이 해소됩니다.
- 클레임 추가결제 금액 불일치 안내 문구의 일본어 번역을 추가했습니다.

#### 테스트 모드
- 테스트 모드 가상계좌 모의입금 도구(제목·입력 이름·「입금통보 테스트」 버튼·관리자 안내)의 일본어 번역을 추가했습니다.

### Changed

- 플러그인 설정 「입금 유효기간」의 일본어 이름·안내를 「사용 안 함」 표시와 「가상계좌 입금 기한은 쇼핑몰 「주문 자동취소」 기한을 따른다」는 안내로 바꿨습니다(본체 1.1.0 의 기한 단일화와 함께).
- 「バーチャル口座」「バーチャルアカウント」로 섞여 있던 가상계좌 표기를 「仮想口座」로 통일했습니다.

### Removed

- 레이아웃 편집기의 데이터소스 목록에서 다른 결제사(나이스페이먼츠) 테스트 결제 맵의 라벨을 제거했습니다 — 이 플러그인이 그 데이터소스를 더는 쓰지 않아 목록에만 남아 있던 항목입니다. 편집기에서 고를 수는 있으나 아무 데도 연결되지 않는 항목이 사라집니다.
- 제거된 간편결제 표시 맵 데이터 소스 이름(`editor.data_source.nhnkcp_easy_pay_display_map`)과 이 플러그인 소관이 아닌 `editor.data_source.nicepay_test_map` 번역을 정리했습니다.

## [1.0.4] - 2026-09-06

### Added

- 결제 모듈 주소를 확인하지 못했을 때 표시되는 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 한국어 안내가 보이던 문제가 해소됩니다.

## [1.0.3] - 2026-08-19

### Added

- 에스크로 배송등록 검증 안내 문구(운송장번호·택배사)의 일본어 번역을 추가했습니다.
- 결제 처리 실패 안내 문구의 일본어 번역을 추가했습니다 — 일본어 로케일에서 결제가 실패했을 때 한국어 안내가 보이던 문제가 해소됩니다.
- 결제 취소에 필요한 서버 IP 등록 안내의 일본어 번역을 추가했습니다 — 등록이 필요한 이유, 상점 관리자에서의 등록 경로, 등록할 IP 확인·복사 안내가 일본어로 표시됩니다.
- 관리자 결제 상세의 결제 상태·취소 금액·취소 일시·환불 상태·환불 번호 항목명과, 취소 완료·부분 취소 상태 표시의 일본어 번역을 추가했습니다.
- 가상계좌 입금 통보 주소의 등록 경로 안내와 간편결제 표시 설정 항목명의 일본어 번역을 추가했습니다.

## [1.0.2] - 2026-08-10

### Changed

- 결제 성공·실패 리다이렉트 주소 안내 문구를 갱신했습니다 — 상점 주소 설정을 따라 자동으로 채워지는 `{shopBase}` 자리표시자 설명으로 바뀌었습니다.

### Fixed

- 환불 금액 안내에서 통화 단위(円) 고정 표기를 제거했습니다 — 결제 통화의 단위로 표시됩니다.

## [1.0.1] - 2026-07-16

### Added

- 환불 진행 중 안내(`refund.in_progress`)와 KCP CLI 바이너리 누락·실행 권한 부족 안내(`errors.cli_binary_missing`, `errors.cli_binary_not_executable`) 일본어 번역 추가 — 환불 중복 요청·CLI 실행 환경 오류 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
- 주문 설정 화면의 NHN KCP 테스트모드 경고(`nhnkcp_test_mode_status`, `test_mode_settings_warning_*`) 일본어 번역 추가 — 테스트결제 상태 안내와 실결제 설정 이동 버튼이 일본어 로케일에서 자연스럽게 표시됩니다.
