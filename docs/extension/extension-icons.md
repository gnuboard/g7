# 확장 아이콘

> 확장과 언어팩이 자기 아이콘을 담는 방법과 규격입니다.

---

## TL;DR (5초 요약)

```text
1. 패키지 루트에 assets/icon.svg 를 두면 끝입니다 (png·webp 도 됩니다)
2. 다른 경로를 쓰려면 설정 파일에 "icon": "assets/brand/mark.svg" 를 적습니다
3. 정사각 · 100KB 이하 · 스크립트 없는 SVG — 어기면 표시되지 않고 기본 그림이 나옵니다
4. 아이콘을 넣지 않아도 됩니다. 종류별 기본 그림으로 표시됩니다
5. 언어팩은 대상 확장의 아이콘에 언어 표시를 얹어 자동으로 만들어집니다
```

---

## 어디에 나오나

확장 아이콘은 운영자가 확장을 **한눈에 가려내는** 자리에 나옵니다.

| 자리 | 크기 | 비고 |
| --- | --- | --- |
| 관리자 모듈·플러그인·템플릿·언어팩 관리 목록 카드 | 갤러리 보기 56px · 목록 보기 48px | 보기 방식에 따라 다릅니다 |
| 확장 상세 창 | 40px | 이름·식별자와 나란히 |
| 설치·업데이트·삭제 확인 창 | 24px | 확인 문장 앞 |
| 설치 마법사(웹 인스톨러) Step 4 카드 | 44px | 설치 전이라 패키지에서 직접 읽습니다 |
| 수동 설치 미리보기 | — | 그림 대신 규격 검사 결과를 글로 알립니다 |

아이콘이 없거나 규격을 어긴 확장은 **종류별 기본 그림**(모듈·플러그인·템플릿·언어팩)으로
표시됩니다. 설치가 막히지는 않습니다.

---

## 파일을 두는 두 가지 방법

### 1. 파일 관례 (권장)

패키지 루트 기준으로 다음 순서로 **처음 있는 파일**을 씁니다.

```text
assets/icon.svg   ← 권장
assets/icon.png
assets/icon.webp
```

설정 파일에 아무것도 적지 않아도 됩니다.

언어팩도 같은 관례를 씁니다 — 언어팩 패키지 루트의 `assets/icon.svg`(`.png`·`.webp`)입니다.
언어팩은 파일을 넣지 않는 것이 기본이며, 그때는 대상 확장(또는 코어)의 아이콘에 로케일 표시를
얹어 자동으로 합성합니다.

```text
my-plugin/
├── plugin.json
├── plugin.php
└── assets/
    └── icon.svg     ← 이 자리
```

> 관례 후보는 **처음 있는 파일 하나만** 검사합니다. `assets/icon.svg` 가 있는데 규격을
> 어겼다면 `assets/icon.png` 로 넘어가지 않고 그대로 실패합니다 — 고쳐야 할 파일이
> 무엇인지 분명해야 하기 때문입니다.

### 2. 설정 파일에 경로 적기

다른 자리에 두고 싶으면 매니페스트에 적습니다. 적으면 관례보다 **우선**합니다.

```json
{
  "identifier": "sirsoft-example",
  "version": "1.0.0",
  "icon": "assets/brand/mark.svg"
}
```

`module.json` · `plugin.json` · `template.json` · `language-pack.json` 모두 같습니다.

경로 규칙:

| 규칙 | 예 |
| --- | --- |
| 패키지 루트 기준 **상대경로**만 | ✅ `assets/brand/mark.svg` |
| 절대경로·URL 금지 | ❌ `/var/www/icon.svg` · ❌ `https://example.com/icon.svg` |
| 상위 폴더 탈출 금지 | ❌ `../../shared/icon.svg` |
| 역슬래시 금지 | ❌ `assets\icon.svg` |
| 확장자는 svg·png·webp 만 | ❌ `assets/icon.jpg` |

적은 경로가 규칙을 어기거나 그 자리에 파일이 없으면 **관례로 되돌아갑니다**. 수동 설치
미리보기가 그 사실을 경고로 알려 줍니다.

## 규격

| 항목 | 규격 |
| --- | --- |
| 형식 | SVG 권장, PNG·WebP 허용 |
| 모양 | **정사각** — SVG 는 `viewBox` 의 가로=세로, 그림 파일은 가로=세로 |
| 크기 | 그림 파일은 한 변 **128px 이상**. 파일은 **100KB 이하** |
| 배경 | 투명 권장 |
| 색 | 제한 없습니다(풀컬러 가능) |

### SVG 안전 규칙

아이콘은 언제나 `<img>` 로 그려지지만, 그것과 별개로 다음을 금지합니다.

```text
금지: <script> 요소
금지: onload= 같은 on 으로 시작하는 속성
금지: <foreignObject>
금지: 외부 파일 참조 (href·xlink:href 가 # 로 시작하지 않는 것)
금지: 스타일의 @import, url(외부주소)
금지: <!DOCTYPE>, <!ENTITY>, <?xml-stylesheet?>
```

문서 안 조각 참조(`url(#gradient)`, `href="#mark"`)는 그라디언트·마스크에 필요하므로
허용합니다.

**색 고르기 팁** — 아이콘은 연회색 라운드 박스(밝은 화면 `#f3f4f6`, 어두운 화면 `#374151`)
위에 그려집니다. 흰색 단색 아이콘은 밝은 화면에서 사라져 보이니 피하세요.

### 정상 예시

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" role="img">
  <title>내 플러그인</title>
  <rect x="4" y="4" width="56" height="56" rx="12" fill="#2563eb"/>
  <path d="M20 32h24M32 20v24" stroke="#ffffff" stroke-width="5" stroke-linecap="round"/>
</svg>
```

## 언어팩 아이콘

언어팩은 대개 자기 그림이 필요 없습니다. 기본값은 **대상 확장의 아이콘에 언어 표시를
얹은 모습**입니다.

| 상황 | 표시 |
| --- | --- |
| 언어팩이 `icon` 을 선언했거나 `assets/icon.svg` 가 있음 | 그 그림만 (언어 표시 없음) |
| 코어 언어팩 | 그누보드7 아이콘 + 언어 표시 |
| 확장 언어팩 | 대상 확장 아이콘 + 언어 표시 |
| 대상 확장에도 아이콘이 없음 | 기본 그림 + 언어 표시 |

**국기는 쓰지 않습니다** — 언어와 국가는 같지 않기 때문입니다. 언어 표시는 로케일
코드(`ja`, `en` 등)입니다.

---

## 아이콘 주소

표시용 주소는 다음과 같습니다.

```text
GET /api/extensions/{type}/{identifier}/icon
GET /api/extensions/plugin/sirsoft-gdpr/icon?v=1.1.0
```

`{type}` 은 `module` · `plugin` · `template` · `language-pack` 중 하나입니다.

- **로그인이 필요 없습니다.** 아직 설치하지 않은 동봉 확장의 아이콘도 목록에 보여야 하기
  때문입니다.
- `?v=` 는 캐시를 새로 받기 위한 값입니다. 보통 확장 버전을 씁니다.
- 응답에는 파일의 변경 시각·크기로 만든 `ETag` 가 붙습니다. 브라우저가 다음 요청에
  `If-None-Match` 로 그 값을 보내면 내용이 그대로일 때 **304** 로 답해 파일을 다시
  내려보내지 않습니다. 그래서 버전을 올리지 않고 아이콘 파일만 바꿔도 새 그림이 보입니다.
- 파일이 없거나 규격을 어기면 **404** 입니다. 화면은 기본 그림으로 표시합니다.
- 이 주소는 정적 게시 대상이 아닙니다.

**설치된 확장**의 아이콘은 설치본에서만 찾습니다. 설치본에 아이콘 파일이 없으면 동봉 원본에
있더라도 기본 그림으로 표시합니다 — 실제로 동작하는 것은 설치본이고, 설치본은 동봉 원본과
버전이 다르거나 동봉 원본에 없을 수 있기 때문입니다. 아이콘을 바꾸려면 확장을 업데이트해
설치본에 반영하세요.

**아직 설치하지 않은 확장**의 아이콘만 **설치본 → 대기 → 동봉** 순으로 찾습니다. 기존 확장
자산 주소가 설치본만 보는 것과 다릅니다 — 설치 전에도 그림이 보여야 하기 때문입니다. 확장
관리 화면의 라이선스 보기도 같은 규칙을 따릅니다.

---

## 동봉 확장과 제3자 확장

| 구분 | 의무 |
| --- | --- |
| 그누보드7에 함께 실려 오는 확장 | 전부 아이콘을 담고 자동 검사를 받습니다 |
| 제3자가 만든 확장 | **넣지 않아도 됩니다.** 넣는다면 위 규격만 지키면 됩니다 |

제3자 확장에 강제하지 않는 이유는, 아이콘이 없다고 해서 확장이 덜 동작하지는 않기
때문입니다. 없으면 종류별 기본 그림으로 표시됩니다.

---

## 확인하는 방법

만든 아이콘이 규격에 맞는지는 **수동 설치 미리보기**에서 확인할 수 있습니다. 관리자
확장 관리 화면에서 패키지를 올리고 미리보기를 실행하면 아이콘 항목에 다음 중 하나가
나옵니다.

```text
아이콘 포함: assets/icon.svg          ← 통과
아이콘이 규격에 맞지 않아 …            ← 무엇이 문제인지 함께 나옵니다
아이콘이 없어 기본 아이콘으로 …         ← 넣지 않은 경우
```

규격을 어겨도 **설치는 됩니다**. 표시만 기본 그림으로 떨어집니다.
