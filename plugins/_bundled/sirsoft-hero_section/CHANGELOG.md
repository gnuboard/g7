# Changelog

형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,

## [1.0.0] - 2026-10-26

### Added

- 환경설정에 「공개 자산 디스크」를 두었습니다(비우면 코어 환경설정 > 드라이버 > 공개 자산 디스크를 따름). 공개 디스크(public)나 CDN 주소를 가진 디스크를 고르면 새로 올리는 배너 이미지·영상이 그 디스크에 저장되고, 사이트 슬라이더는 원본 이미지(`<img src>`·srcset 의 원본 후보)·영상·대표 이미지를 PHP 를 거치지 않는 직접 주소(`/storage/…` 또는 CDN, 파일 확장자 포함)로 받습니다. 영상의 범위 요청(탐색·이어받기)도 웹서버·CDN 이 처리합니다. 축소 후보(`?size=`)는 그대로 공개 API 주소이고 서버가 공개 썸네일 디스크로 보냅니다(302).
- 사용자 화면 배너 응답(`hero`)의 이미지·영상에 `direct_url`(공개 자산 디스크 행의 직접 주소, 아니면 null)을, 관리자 이미지 응답에 `preview_url`(썸네일 기준 API 주소)과 `direct_url` 을 더했습니다. 관리자 응답의 `download_url` 은 직접 주소가 있으면 그 주소입니다. 기존 `url` 은 그대로 공개 API 주소입니다.
- 이미 올린 배너 파일의 서빙·썸네일·삭제·임시 파일 정리·「데이터까지 삭제」는 파일을 올린 디스크(행 disk)를 따릅니다. 디스크 설정을 바꿔도 옛 파일은 올린 디스크에서 그대로 열리고, 그 디스크를 주던 확장이 꺼지면 예외 없이 「없음」(404)으로 처리합니다. 공개 자산 디스크를 다시 꺼도 그 디스크에 올린 파일은 계속 직접 주소로 나갑니다(파일 자체가 공개 위치에 있으므로 배너를 지워야 주소가 닫힙니다).
- 코어 환경설정의 드라이버 탭을 저장하면 사용자 화면 배너 캐시를 비웁니다(공개 자산 디스크를 바꾼 뒤 옛 주소가 캐시에 남지 않게).
- 게시판 목록(게시판마다)·상품 상세(상품마다)·카테고리 목록(카테고리마다) 상단에도 배너를 둘 수 있습니다. 게시판·이커머스 모듈이 켜져 있을 때 위치가 생기고, 배너 목록에서 대상을 이름으로 찾아 고른 뒤 그 대상의 배너만 등록·순서 변경·미리보기합니다. 위치 탭을 옮기면 앞 위치에서 찾거나 고른 대상은 고르기 칸에 남지 않습니다. 「사이트에서 보기」는 고른 대상의 화면을 엽니다. 화면 주소 값은 slug(상품은 상품 코드)를 먼저 찾고, 없을 때만 숫자 id 로 찾습니다. 배너가 없는 대상에는 아무것도 나오지 않고, 처음 여는 대상에는 받는 동안의 자리 표시도 하지 않습니다. 슬라이더 설정은 위치 단위라 그 위치의 모든 대상에 함께 적용됩니다.
- 다른 모듈·플러그인이 필터 `sirsoft-hero_section.position.registered_positions` 로 배너 위치를 더할 수 있습니다. 대상(게시판·상품처럼 화면마다 다른 것)이 있는 위치는 대상 해석기 계약(`TargetResolverInterface`)으로 화면 값과 저장 키를 잇습니다. 대상 고르기 목록은 히어로 조회 권한으로 받아, 게시판·상품 관리 권한이 없는 히어로 관리자도 대상을 고를 수 있습니다. 위치를 더한 확장은 히어로 코드를 고치지 않고 자기 화면 확장점에 슬라이더 조각을 붙여 배너를 보입니다(확장 문서에 정적·동적 위치 조각 예시를 두었습니다). 그 확장을 켜고 끄면 첫 화면 자리 표시 정보도 바로 맞춰집니다.
- 위치를 더한 확장을 끄거나 대상(게시판·상품·카테고리)을 지워도 배너는 지우지 않습니다. 배너 목록에 「등록되지 않은 위치」·「없는 대상」으로 보여 고치거나 지울 수 있고, 사이트에는 나가지 않으며, 확장을 다시 켜면 그대로 보입니다. 배너 등록·수정·삭제·일괄 노출 전환·순서 변경 활동 로그에 대상이 함께 남고, 활동 로그 목록 한 줄에 위치 이름과 대상 이름(「(대상: 자유게시판)」)이 보입니다.
- 배너 문구에 제목 위 짧은 한 줄(머리글)을 더할 수 있습니다. 언어마다 입력하고 보이기·색을 정하며, 정렬은 제목을 따릅니다.
- 배너마다 문구 자리를 PC·휴대폰 따로 정합니다. 9칸(왼쪽 위~오른쪽 아래)으로 빠르게 고르거나 가로·세로 %를 직접 넣고, 수정 화면 미리보기에서 문구를 끌거나 화살표 키(Shift 와 함께 10%씩)로 옮길 수 있습니다. 문구 상자 폭(30~100%)도 정합니다. 기존 배너는 지금처럼 왼쪽 아래 전폭입니다.
- 배너마다 문구 등장 효과를 고릅니다(없음·아래에서 떠오르기·서서히·왼쪽에서·오른쪽에서·확대·흐림 걷힘·글자 하나씩, 속도 3단계·시작 지연 0~2초). 배너가 보일 때마다 머리글 → 제목 → 설명 → 버튼 순으로 0.2초씩 늦게 나타나며, 수정 화면 미리보기에서 「효과 다시 보기」로 확인합니다. 문구가 아래에서 올라오는 동안에도 문구 영역에 스크롤 막대가 생기지 않습니다. 움직임 줄이기를 켠 방문자에게는 효과 없이 보입니다.
- 위치 설정에 「메뉴 겹치기」를 두었습니다. 화면 전체 폭일 때 켜면 사이트 상단 메뉴가 배너 위에 투명하게 겹치고, 화면을 내리면 원래 배경으로 돌아옵니다. 메뉴 글자색은 배너마다 정한 바탕 밝기(어두움 → 흰 글자, 밝음 → 검은 글자)를 따릅니다. 이 기능을 지원하는 사이트 템플릿(기본 템플릿 sirsoft-basic)에서 보이며, 지원하지 않는 템플릿에서는 화면이 그대로입니다.
- 배너마다 미디어 종류를 이미지·영상 파일 중에서 고를 수 있습니다. 영상 파일은 PC·모바일용 MP4·WEBM 을 올립니다(모바일 영상이 없으면 휴대폰에서도 PC 영상). 사이트에서는 소리 없이 자동 재생하고 영상이 끝나면 다음 배너로 넘어가며, 배너가 하나면 반복 재생합니다. 재생할 수 없는 영상은 이미지 배너처럼 전환 간격으로 넘어갑니다.
- 영상 배너도 PC 이미지는 대표 이미지로 필수입니다. 영상을 받는 동안과 움직임 줄이기를 켠 방문자에게 대표 이미지를 보이며(휴대폰에서는 모바일 이미지, 먼 배너는 차례가 다가올 때 받음), 움직임 줄이기에서는 영상이 멈춘 채 시작하고 「배너 다시 재생」 단추로 재생합니다. 일시정지 단추는 자동 넘김과 영상 재생을 함께 멈추고, 다시 누르면 멈춘 자리부터 이어 재생합니다(다른 배너로 넘어가면 다음 차례에 처음부터). 재생이 시작되기 전에 멈추거나 넘기거나 화면을 돌려도 그 영상은 다음에 다시 재생됩니다.
- 환경설정에 영상 최대 용량(기본 30MB, 1~100MB, 서버 PHP 업로드 한도를 넘을 수 없음)을 두었고, 배너 목록에 영상 배너를 표시합니다. 영상 교체·삭제도 활동 로그에 남습니다.
- 사이트 화면에서 배너 수정 권한이 있는 회원에게는 슬라이더 오른쪽 위에 「관리자에서 수정」 단추가 보이고, 누르면 지금 보이는 배너의 관리자 수정 화면이 새 탭으로 열립니다.
- 언어팩을 꺼 지원 목록에서 빠진 언어의 번역이 저장된 배너도 그대로 수정할 수 있습니다. 저장돼 있던 번역은 보존되어 언어팩을 다시 켜면 복구되고, 새 언어 키는 거부합니다.
- 영상 배너는 재생할 장만 다 받고 다음 장은 정보만, 그 뒤 장은 받지 않습니다. 움직임 줄이기·데이터 절약을 켠 방문자는 재생하기 전까지 영상을 받지 않습니다.
- 플러그인을 데이터까지 삭제할 때 이미지 폴더도 비웁니다. 제거가 막히거나 데이터를 남기는 제거에서는 파일을 건드리지 않습니다.
- 사이트 화면을 새로 열면 배너를 받는 동안 같은 크기·같은 폭(본문 폭·화면 전체)의 스켈레톤이 먼저 자리를 잡아, 배너가 늦게 나타나며 아래 본문을 밀어내지 않습니다. 배너는 받으면 서서히 나타나고, 움직임 줄이기를 켠 사용자에게는 빛 흐름·나타남 효과 없이 보입니다. 배너가 없는 위치는 처음 접속할 때도 스켈레톤을 그리지 않습니다.
- 사용자 슬라이더에 Swiper 기본 모양의 좌우 화살표(PC)와 장마다 누를 수 있는 점 표시를 두었고, PC 에서도 마우스로 끌어 넘길 수 있습니다. 휴대폰에서는 화살표가 문구를 가리지 않도록 감추고 손가락 넘기기와 점 표시로 넘깁니다. 전환 효과에 큐브·뒤집기·커버플로·겹쳐 넘기기를 더했습니다. 슬라이더 모양(넘김·전환 효과)은 따로 불러오며, 불러오는 동안에는 같은 자리의 자리 표시가 보이고, 끝내 불러오지 못하면 다시 시도할 수 있는 알림을 띄운 채 전환 효과 없이 배너를 보입니다.
- 위치마다 페이징 모양을 고를 수 있습니다 — 점(기본, 지금 화면 그대로) · 진행 막대 점(지금 배너의 점이 길어지며 다음 배너로 넘어가기까지 남은 시간이 차오름) · 배너 이름 탭(배너 제목을 누르는 탭, 휴대폰에서는 막대만) · 번호(01 / 05). 배너 목록에서 고르면 저장하기 전에 미리보기가 바로 바뀌고, 미리보기 안 화살표·점·탭으로 배너를 넘겨 볼 수 있습니다(미리보기에서는 자동 넘김·전환 효과 없이 바로 바뀝니다).
- 위치마다 배너를 본문 폭에 맞출지 화면 전체 폭으로 펼칠지 고를 수 있습니다(기본은 본문 폭이라 지금 화면 그대로입니다). 화면 전체 폭은 이미지를 화면 끝까지 넓히고 제목·버튼·넘김 단추는 본문과 같은 줄에 맞추며, 화면이 1920px 보다 넓으면 높이 640px 에서 멈추고 이미지 초점을 기준으로 위아래를 자릅니다. 배너 목록에서 고르면 저장하기 전에 미리보기가 바로 바뀝니다. 자리가 본문 상자 안에 있는 사이트 템플릿에서는 두 설정 모두 자리 폭 그대로 보입니다.
- 배너 등록·수정 화면은 이미지를 문구보다 먼저 입력하고, 휴대폰에서는 미리보기가 입력 위에 옵니다. 저장 단추가 잠기면 그 옆에 이유(이미지 올리는 중, PC 이미지 없음)를 보이고 PC 이미지 칸으로 바로 갈 수 있습니다.
- 버튼 문구는 있는데 이동 주소가 없으면 사이트에 버튼이 보이지 않는다고 알리고, 링크 칸 아래에 배너를 누르면 어떻게 되는지(버튼만, 배너 전체, 이동 안 함)를 한 줄로 보입니다.
- 배너 목록에 행마다 제작 상태(제목이 빈 사이트 언어, 모바일 이미지 없음, 버튼 문구만 있고 주소 없음)와 그 위치가 있는 사이트 화면을 새 창으로 여는 「사이트에서 보기」를 보입니다. 지금 쓰는 사이트 템플릿에 그 배너 자리가 없으면 알립니다.
- 위치에 배너가 하나도 없을 때는 권장 이미지 크기와 [첫 배너 등록]을, 상태·검색으로 걸러 0건일 때는 조건 안내를, 배너는 있는데 지금 노출이 없을 때는 예약·비노출·종료 건수를 보여 서로 구분합니다.
- 배너 편집 화면에서 업로드 중이거나 실패한 파일이 있으면 저장을 막고, 저장 중에는 업로더를 잠급니다.
- 미리보기를 실제 PC·모바일 크기로 렌더링해 축소하고 확대할 수 있으며, 편집한 콘텐츠 언어와 기본 언어 대체를 확인할 수 있습니다(언어 선택, 대체 안내, 목록의 「… 제목 없음」 표시는 언어 탭과 같은 언어 이름으로 보입니다).
- PC·모바일의 이미지 초점과 문구 배경을 정할 수 있습니다. 모바일은 PC 대체 이미지도 750×1000 세로 비율로 표시합니다.
- 기간 안내에 사이트 시간대를 표시하고 서버 시각으로 상태를 계산합니다. 다른 관리자가 먼저 저장했으면 내 입력을 보존하고 충돌을 알립니다.
- 마우스와 키보드 포커스 정지 조건이 겹칠 때 한쪽을 벗어나도 자동 재생을 계속 멈춥니다. 마우스로 화살표를 누르거나 휴대폰에서 점·배너를 탭한 뒤에는 자동 넘김이 멈춘 채 남지 않습니다.
- 등록·수정 화면에서 저장을 빠르게 연달아 눌러도 한 번만 보냅니다. 그래도 겹친 요청은 먼저 저장된 배너의 이미지를 가져가지 않고 저장되지 않으며, 「이미 저장되었으니 목록에서 확인하라」고 알립니다.
- 편집 미리보기가 기기 화면 폭(PC 1366·모바일 390)은 그대로 두고, 그 안의 배너 자리를 지금 쓰는 사용자 템플릿의 본문 여백·최대 폭대로 그려 사이트 홈·쇼핑몰 메인과 같은 폭·줄바꿈으로 보입니다. 관리자 레이아웃 편집기에서 그 레이아웃을 저장하면 바로 새 폭을 따르고, 읽지 못한 레이아웃은 건너뛰면서 기본 로그 설정에서도 남는 오류 로그를 남깁니다. 미리보기 화면의 모양(CSS)을 다 받기 전에는 미리보기를 가려, 배너 자리가 잠깐 넓게 보였다가 좁아지지 않습니다(8초 안에 받지 못하면 그대로 보입니다). 슬라이더 모양 CSS 를 다시 받아 실렸을 때와 미리보기 화면을 새로 만들 때도 받을 때까지 가립니다.
- 다른 관리자가 먼저 저장해 저장이 막히면, 같은 창에서 최신본을 불러와 항목별로 누가 바꿨는지 비교하고 골라 적용한 뒤 다시 저장할 수 있습니다. 다른 관리자가 바꾼 항목은 기본으로 지키고, 둘 다 바꾼 항목은 직접 골라야 하며, 미디어(종류·영상)도 비교 항목에 들어 있어 내가 바꾼 미디어가 적용 때 빠지지 않으며, 다른 관리자가 바꾼 이미지·영상은 내 예전 이미지·영상으로 되돌릴 수 없습니다. 불러오기에 실패하면 입력을 그대로 둔 채 다시 시도할 수 있습니다.
- 긴 제목·설명·버튼 문구도 줄이거나 지우지 않고 배너 폭 안에서 줄을 바꾸며, 배너 높이를 넘으면 문구 영역 안에서 스크롤해 끝까지 읽을 수 있습니다(넘김 단추 자리는 비워 둡니다). 문구가 넘칠 때만 그 영역에 키보드(Tab)로 들어가 위아래 화살표로 읽을 수 있고, 휴대폰에서는 문구 영역을 위아래로 밀면 문구가 스크롤되고 옆으로 밀면 다음 배너로 넘어갑니다. 버튼 문구 없이 배너 전체가 링크여도 문구 영역은 링크와 겹치지 않으며, 문구를 눌러도 링크로 이동합니다.
- 사이트 슬라이더를 화면 읽기 프로그램으로 들을 때 배너 제목을 한 번만 읽습니다(배너 전체가 링크면 링크 이름으로 읽고, 대체 텍스트가 제목과 같은 이미지는 건너뜁니다). 장 번호는 「3개 중 1번째」처럼 사이트 언어로 읽고 방문자가 넘길 때만 알려 두 번 읽지 않으며, 캐러셀·슬라이드라는 역할 이름도 사이트 언어로 읽습니다. 점 표시는 10px 로 보이되 누를 자리는 24px 라 휴대폰에서도 누르기 쉽습니다.
- 두 관리자가 같은 위치의 슬라이더 설정을 거의 동시에 처음 저장해도 서버 오류 없이 저장됩니다(나중에 저장한 값이 남습니다).
- 편집 미리보기에서 문구가 그 기기의 배너 높이를 넘거나(배너 2장 이상일 때의 넘김 단추 자리 포함), 사진 평균 밝기와 문구 배경으로 어림한 글자 대비가 낮으면 안내합니다. 안내일 뿐 글자색을 바꾸거나 저장을 막지 않습니다.

- 사이트 홈·쇼핑몰 메인 상단의 히어로섹션(메인 배너)을 관리하는 플러그인을 추가했습니다.
- 배너마다 언어별 제목·설명·버튼 문구·대체 텍스트, 문구 표시 여부·색상·정렬, PC·모바일 이미지(모바일이 없으면 PC 이미지 사용), 이동할 주소·새 창 열기를 정할 수 있습니다. 이동할 주소는 사이트 안 경로와 http(s) 주소만 받습니다.
- 상시 노출 또는 기간 지정 노출을 고를 수 있고, 기간은 사이트 시간대로 입력합니다. 시작 시각이 되면 자동으로 보이고 종료 시각이 지나면 자동으로 사라집니다(예약 작업 없이 조회할 때 판단).
- 노출 상태(노출중·예약·종료·비활성)로 걸러 보고, 일괄 노출·비노출·삭제와 위치별 순서 변경을 할 수 있습니다(일괄 처리는 고른 건수가 많아도 빠르게 끝납니다). 삭제는 이미지 파일까지 영구 삭제합니다.
- 위치마다 슬라이더의 자동 재생·전환 간격(3·5·7초)·전환 효과(슬라이드·페이드·큐브·뒤집기·커버플로·겹쳐 넘기기·없음)·표시 폭(본문 폭·화면 전체)을 정할 수 있습니다.
- 조회 / 등록·수정 / 삭제 권한을 나눴고, 모든 작업이 활동 로그에 남습니다. 일괄 노출·비노출 기록은 바꾼 그때의 값으로 남아, 기록되기 전에 배너를 지우거나 다시 고쳐도 빠지지 않습니다.
- 환경설정에서 이미지 최대 용량(서버 PHP 업로드 한도를 넘을 수 없음)과 사용자 화면 배너 캐시 시간을 정합니다. 배너를 바꾸면 캐시와 관계없이 바로 반영되고(사이트 공통 캐시 시간이 더 짧아도 고치기 전 화면으로 돌아가지 않음), 예약 시작·종료 시각에도 캐시가 먼저 만료됩니다.
- 배너 등록·수정 화면에서 올리거나 뺀 이미지는 [저장]을 눌러야 사이트에 반영되고, 저장하지 않고 나가면 사이트 화면은 그대로입니다. 올리기만 하고 저장하지 않은 이미지는 매일 자동으로 정리됩니다.
- 관리자 메뉴 「히어로섹션 관리」에서 위치 탭별 배너 목록, 지금 노출 중인 배너 미리보기(PC·모바일), 위치별 슬라이더 설정, [순서 변경] 창(끌기·↑↓ 단추)을 씁니다. 위치·상태·검색·정렬·쪽은 주소에 남아 새로고침·뒤로 가기에도 그대로입니다. 노출 중 미리보기는 머리글 같은 언어별 문구를 화면 언어로 그리고, 그리다 실패해도 그 자리에만 안내를 남긴 채 다른 위치 탭으로 옮기면 다시 그립니다. 삭제, 일괄 삭제, 순서 변경 창의 단추는 창 아래에 고정되어 본문이 길어도 함께 밀리지 않습니다.
- 배너 등록·수정 화면 오른쪽에서 저장 전 입력값을 사용자 화면 슬라이더 그대로 미리 봅니다. 권장 크기와 다른 이미지를 올리면 안내가 뜨고(저장은 막지 않음), 기간을 정하면 저장했을 때의 상태(노출중·예약·종료)를 미리 알려 줍니다.
- 사이트 홈과 쇼핑몰 메인 상단에 배너 슬라이더가 보입니다(사용자 템플릿이 `home_hero`·`shop_hero` 자리를 열어 둔 경우). 첫 배너는 바로, 나머지는 필요할 때 받아 화면이 밀리지 않고, 휴대폰에서는 손가락으로 넘길 수 있으며 마지막 배너 다음에는 첫 배너가 이어집니다. 자동 넘김은 마우스를 올리거나 키보드로 들어오면 멈추고, 움직임 줄이기 설정을 따르며, 자동으로 넘어가는 동안에는 화면 읽기 프로그램이 장 번호를 매번 읽지 않습니다.
- 환경설정 화면에 현재 서버 업로드 한도를 보여 주고, 설정값이 그보다 크면 경고합니다.
- 하위 폴더에 설치한 사이트(`https://도메인/g7/` 처럼)에서도 배너 링크의 사이트 안 주소(`/shop/products` 등)가 그 사이트 안으로 이동하고, 배너 이미지, 휴대폰 이미지, 영상, 영상 대표 이미지도 그 사이트 안 주소로 불러옵니다. 바깥 주소(`https://…`)는 그대로입니다.
- 배너 이미지와 영상을 브라우저가 다시 확인할 때 바뀌지 않았으면 다시 내려받지 않습니다(「변경 없음」 응답, 영상은 부분 요청도 그대로). 캐시와 형식 판정 헤더는 사이트의 다른 첨부 이미지와 같습니다.
- 서버가 PHP 설정 읽기(`ini_get`)를 막아 둔 호스팅에서도 배너 이미지·영상 업로드 화면과 업로드가 오류 없이 동작합니다. 이때 업로드 한도는 플러그인 설정 값을 따릅니다.
- 배너 이미지를 화면에 맞는 크기로 줄여 보냅니다. 사이트 슬라이더는 PC 이미지와 휴대폰 이미지를 각자 원본 크기에 맞춰 여러 크기(환경설정 > 업로드 탭의 썸네일 규격 중 원본보다 작은 것과 원본)로 알려 주어, 브라우저가 화면 폭과 해상도에 맞는 크기를 고릅니다. 본문 폭에 맞춘 배너는 실제로 그려진 자리 폭을 알려, 1920 화면의 본문 칸에서 원본 대신 한 단계 작은 이미지를 받습니다. 관리자 배너 목록과 순서 변경 창은 가로 240px 로 줄인 이미지를 늦게 불러옵니다. 이 크기는 환경설정 > 업로드 탭 「썸네일 규격」 표에 「배너 목록」(식별자 `sirsoft-hero_section.list`)으로 나타나며 값만 고칠 수 있고 「기본값으로」로 되돌립니다. 썸네일을 요청했는데 원본을 보낸 경우(규격보다 작은 원본 등)에는 그 주소를 1년 고정 캐시로 두지 않고 줄인 이미지와 같은 시간(환경설정 레이아웃 캐시 유지 시간, 기본 1시간)만 캐시해, 규격을 바꾸면 반영됩니다. 줄인 이미지는 처음 요청할 때 만들어 두고, 배너 이미지를 바꾸거나 지우면 함께 지워집니다. 환경설정 「기존 이미지 썸네일 만들기」와 썸네일 캐시 비우기에 배너 이미지가 들어갑니다. Safari 에서도 첫 배너 이미지를 한 번만 받습니다.
- 화면 폭에 따라 바뀌는 모양은 엔진 responsive 로 정합니다(Tailwind 반응형 접두와 폭 미디어를 품은 의미 클래스를 쓰지 않습니다 — 배너 폼 머리와 넓은 화면의 미리보기 고정 포함). 화면 모양은 같습니다.
- 사용자 슬라이더의 휴대폰·태블릿 모양(영역 비율, 이미지·영상 초점, 문구 자리, 배너 이름 탭, 좌우 화살표 숨김)을 화면 폭 미디어 쿼리 대신 엔진 반응형 폭으로 판정해, 레이아웃 편집기 미리보기의 기기 폭과 같은 경계(767px·1023px)로 바뀝니다. PC·모바일 이미지와 영상 파일의 선택도 같은 판정을 따라, 편집기 미리보기 틀이 휴대폰 폭이면 창이 넓어도 모바일 이미지를 씁니다(실제 브라우저에서는 종전과 같은 767px 경계). 슬라이더 루트에 `hs-slider--mobile`(767px 이하)·`hs-slider--portable`(1023px 이하) 클래스가 붙습니다.
