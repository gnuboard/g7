# Changelog

이 프로젝트의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.0] - 2026-10-26

### Added

- 배너 편집 화면에서 업로드 중이거나 실패한 파일이 있으면 저장을 막고, 저장 중에는 업로더를 잠급니다.
- 미리보기를 실제 PC·모바일 크기로 렌더링해 축소하고 확대할 수 있으며, 편집한 콘텐츠 언어와 기본 언어 대체를 확인할 수 있습니다.
- PC·모바일의 이미지 초점과 문구 배경을 정할 수 있습니다. 모바일은 PC 대체 이미지도 750×1000 세로 비율로 표시합니다.
- 기간 안내에 사이트 시간대를 표시하고 서버 시각으로 상태를 계산합니다. 다른 관리자가 먼저 저장했으면 내 입력을 보존하고 충돌을 알립니다.
- 마우스와 키보드 포커스 정지 조건이 겹칠 때 한쪽을 벗어나도 자동 재생을 계속 멈춥니다.

- 사이트 홈·쇼핑몰 메인 상단의 히어로섹션(메인 배너)을 관리하는 플러그인을 추가했습니다.
- 배너마다 언어별 제목·설명·버튼 문구·대체 텍스트, 문구 표시 여부·색상·정렬, PC·모바일 이미지(모바일이 없으면 PC 이미지 사용), 이동할 주소·새 창 열기를 정할 수 있습니다. 이동할 주소는 사이트 안 경로와 http(s) 주소만 받습니다.
- 상시 노출 또는 기간 지정 노출을 고를 수 있고, 기간은 사이트 시간대로 입력합니다. 시작 시각이 되면 자동으로 보이고 종료 시각이 지나면 자동으로 사라집니다(예약 작업 없이 조회할 때 판단).
- 노출 상태(노출중·예약·종료·비활성)로 걸러 보고, 일괄 노출·비노출·삭제와 위치별 순서 변경을 할 수 있습니다. 삭제는 이미지 파일까지 영구 삭제합니다.
- 위치마다 슬라이더의 자동 재생·전환 간격(3·5·7초)·전환 효과(슬라이드·페이드·없음)를 정할 수 있습니다.
- 조회 / 등록·수정 / 삭제 권한을 나눴고, 모든 작업이 활동 로그에 남습니다.
- 환경설정에서 이미지 최대 용량(서버 PHP 업로드 한도를 넘을 수 없음)과 사용자 화면 배너 캐시 시간을 정합니다. 배너를 바꾸면 캐시와 관계없이 바로 반영되고, 예약 시작·종료 시각에도 캐시가 먼저 만료됩니다.
- 배너 등록·수정 화면에서 올리거나 뺀 이미지는 [저장]을 눌러야 사이트에 반영되고, 저장하지 않고 나가면 사이트 화면은 그대로입니다. 올리기만 하고 저장하지 않은 이미지는 매일 자동으로 정리됩니다.
- 관리자 메뉴 「히어로섹션 관리」에서 위치 탭별 배너 목록, 지금 노출 중인 배너 미리보기(PC·모바일), 위치별 슬라이더 설정, [순서 변경] 창(끌기·↑↓ 단추)을 씁니다. 위치·상태·검색·정렬·쪽은 주소에 남아 새로고침·뒤로 가기에도 그대로입니다.
- 배너 등록·수정 화면 오른쪽에서 저장 전 입력값을 사용자 화면 슬라이더 그대로 미리 봅니다. 권장 크기와 다른 이미지를 올리면 안내가 뜨고(저장은 막지 않음), 기간을 정하면 저장했을 때의 상태(노출중·예약·종료)를 미리 알려 줍니다.
- 사이트 홈과 쇼핑몰 메인 상단에 배너 슬라이더가 보입니다(사용자 템플릿이 `home_hero`·`shop_hero` 자리를 열어 둔 경우). 첫 배너는 바로, 나머지는 필요할 때 받아 화면이 밀리지 않고, 휴대폰에서는 손가락으로 넘길 수 있으며 마지막 배너 다음에는 첫 배너가 이어집니다. 자동 넘김은 마우스를 올리거나 키보드로 들어오면 멈추고, 움직임 줄이기 설정을 따르며, 자동으로 넘어가는 동안에는 화면 읽기 프로그램이 장 번호를 매번 읽지 않습니다.
- 환경설정 화면에 현재 서버 업로드 한도를 보여 주고, 설정값이 그보다 크면 경고합니다.
