# Changelog

All notable changes to this plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-10-22

### Added

#### 기본

- SSO 연동 플러그인 최초 릴리즈. 회사 계정(SAML 2.0, OpenID Connect, LDAP/Active Directory)으로 로그인하고 SCIM 2.0 으로 회원을 만들고 지운다. 기본 언어는 한국어와 영어이고 일본어는 번들 언어팩으로 제공한다. 코어 7.2.0 이상이 필요하다(`g7_version >=7.2.0`)
- 로그인 관문(잠금, 2단계 인증, 비밀번호 변경, 휴면 해제)은 코어가 그대로 맡는다. 회사 계정으로 인증한 회원도 코어 로그인 인계를 거쳐 비밀번호 로그인과 같은 관문을 지난다
- IdP 를 사이트에 여러 개(최대 20개) 등록하고 IdP 마다 프로토콜, 버튼 표시, 관리자 로그인 허용, 소유 도메인을 정한다
- 외부 패키지(`onelogin/php-saml`, `firebase/php-jwt`)를 플러그인에 함께 싣는다. composer 를 쓰지 않는 설치에서도 바로 동작한다

#### 프로토콜

- OpenID Connect 로그인: discovery 주소로 설정을 채우고, id_token 서명(허용 알고리즘 고정, 서명 키 회전 시 1회 다시 받음), 발급자, 수신자, 유효 시각, nonce, PKCE 를 검증한다. 회원 식별 값은 IdP 마다 `sub`, `oid`, 지정 클레임 중에서 고른다
- SAML 2.0 로그인: IdP 메타데이터 주소나 XML 로 연결하고, 서명, 대상, 유효 시각을 검증한 응답만 받는다(서명 감싸기, 재전송 거절). Keycloak 기본 설정처럼 같은 이름 속성을 여러 번 보내면 값을 합쳐 받고, 응답을 읽지 못하면 SAML 응답 오류로 알린다. 붙여 넣은 메타데이터 XML 은 저장할 때 읽어 보고, 읽지 못하면 그 칸에 알린다. IdP 가 시작한 로그인은 IdP 마다 켤 수 있다(기본 꺼짐)
- SAML SP 메타데이터 주소와 SP 키 생성(교체 시 이전 키 30일 병행), IdP 메타데이터 매일 갱신과 서명 인증서 만료 30일, 7일 전 알림
- LDAP / Active Directory 로그인: 로그인 화면의 이메일 또는 사내 아이디와 비밀번호를 사내 디렉터리로 확인한다(StartTLS, LDAPS). 서버에 PHP LDAP 확장이 없으면 LDAP 만 쓸 수 없다고 표시하고 나머지 프로토콜은 그대로 쓴다
- 다른 확장은 필터 훅 `sirsoft-sso.protocol.filter_registered` 로 새 프로토콜 드라이버를 더할 수 있다

#### 로그인과 계정 연결

- 처음 온 사람은 IdP 마다 「자동 가입」 또는 「사전 등록된 회원만」으로 받는다. 자동 가입은 IdP 마다 약관 동의를 받거나 생략하고, 회원은 비밀번호 없이 만들어진다. 사이트가 일반 회원가입을 닫아도 회사 계정 자동 가입은 열려 있다
- 기존 회원 연결 3방식(IdP 소유 도메인 자동 연결, 비밀번호나 메일 인증번호로 본인확인 후 연결, 관리자 단건 연결과 CSV 가져오기)을 IdP 마다 켜고 끈다. 관리자 계정은 관리자 단건 연결로만 이어진다
- 로그인 화면 진입 4가지: IdP 버튼, 이메일을 먼저 입력하면 도메인으로 회사 계정 로그인 안내, IdP 로 자동 이동(`?local=1` 로 비밀번호 로그인 화면 유지), IdP 가 시작한 로그인
- 관리자 로그인 화면에서도 회사 계정으로 로그인한다. 관리자 권한이 없는 회원은 거절한다
- 인계 코드, 동의 대기, 연결 확인 대기, 로그인 시작 주소를 로그인을 시작한 브라우저에 묶어, 주소를 다른 브라우저에 붙여 넣어도 로그인이나 계정 연결이 되지 않는다
- 메일을 받을 수 없는 회사 계정 회원은 민감한 작업의 본인 재확인을 IdP 로 다시 로그인해 통과한다
- 2단계 인증은 IdP 마다 「항상 생략」, 「IdP 가 다중 인증을 알려 줄 때만 생략」, 「항상 G7 2단계 인증」 중에서 고른다

#### 비밀번호 로그인 강제와 비상 계정

- 비밀번호 로그인 강제 단위 4가지(IdP 소유 도메인, 역할, 회사 계정이 연결된 회원, 사이트 전체). 강제 대상은 비밀번호 로그인과 비밀번호 찾기 대신 회사 계정 로그인 안내를 받고, 비밀번호가 없는 회원은 비밀번호를 새로 만들 수 없다
- 강제를 켜거나 넓히면 새로 대상이 된 회원의 비밀번호 로그인 세션을 끝낸다. 저장 전에 영향 받는 회원 수와 세션 수를 보여 준다. 사이트 전체 강제는 셀프 가입도 닫는다
- 비상 계정(최소 1명, 설치 직후 첫 최고관리자)은 강제와 상관없이 비밀번호로 로그인하되 2단계 인증을 반드시 거치고, 로그인하면 활동 로그와 알림을 남긴다. 활성 IdP 가 없으면 사이트 전체 강제를 저장할 수 없다
- 강제 해제 명령 `sirsoft-sso:enforcement --status|--disable|--restore` 로 잠겼을 때 콘솔에서 강제를 풀고 이전 값으로 되돌린다. 플러그인을 끄면 강제도 풀린다

#### 프로비저닝과 퇴사 처리

- SCIM 2.0 프로비저닝: IdP 마다 Bearer 토큰(발급 때 한 번만 보임), Users(목록 필터, 생성, 교체, 부분 수정, 삭제), Groups(역할 매핑 입력), ServiceProviderConfig, ResourceTypes, Schemas, 수신 이력. SCIM 의 회원 삭제는 회원을 지우지 않고 퇴사 처리한다(게시글과 주문 기록 보존)
- 퇴사 처리 4방식(SCIM, 주기 점검, 다음 로그인 차단, 세션 수명 상한)을 조합한다. 퇴사하면 회원을 차단하고 모든 로그인 세션을 끝낸다. 다른 IdP 연결이 살아 있으면 차단하지 않는다
- 주기 점검: LDAP/AD 는 디렉터리 조회, OpenID Connect 는 갱신 토큰, SAML 은 재직 조회 디렉터리를 지정했을 때 그 디렉터리로 재직 여부를 확인한다. IdP 장애는 퇴사로 판정하지 않는다
- IdP 에서 다시 활성화되면 그 연결이 건 차단만 푼다(관리자가 다른 이유로 차단한 회원은 그대로). 퇴사 N일 뒤 탈퇴(익명화)를 켤 수 있고 관리자 계정은 건너뛰고 알린다

#### 역할, 회원 정보, 세션

- IdP 그룹을 역할로 매핑한다(매핑한 역할만 회수 / IdP 가 전부 결정 / 처음 한 번만). 관리자 권한 역할로 이어지는 규칙과 관리자가 연결된 IdP 의 매핑 방식 변경은 최고관리자만 한다. 최고관리자의 역할은 바꾸지 않고, 바꾸지 않고 건너뛴 사실도 활동 로그에 남긴다
- 회원 정보 항목별 동기화(매 로그인 덮어쓰기와 수정 잠금 / 덮어쓰기 / 처음 한 번만 / 가져오지 않음). 부서, 직급, 사번 같은 추가 속성을 보관한다. 이메일은 IdP 소유 도메인일 때만 바꾸고 다른 회원이 쓰는 주소면 건너뛰고 알린다
- SSO 세션 기록, 세션 수명 상한(IdP 값과 사이트 값 중 작은 값), 로그아웃 범위(G7 만 / G7 에서 IdP 까지 / 양방향), OpenID Connect back-channel 로그아웃(IP 접근 제한 규칙에서 자동 제외)과 SAML 단일 로그아웃(IdP 가 보낸 로그아웃은 서명된 요청만)

#### 관리자 화면

- 설정 화면: IdP 목록과 편집(기본, 연결 정보, 계정과 연결, 속성, 역할 매핑, 보안, 프로비저닝, 진단), 정책, 보존 기간. IdP 콘솔에 넣을 값 복사, 연결 테스트, 브라우저 로그인 테스트, LDAP 계정 테스트를 한다. 비밀값은 가린 채 보여 주고 가린 값 그대로 저장하면 기존 값을 유지한다
- 한 도메인은 IdP 하나만 소유한다(다른 IdP 가 소유한 도메인은 저장을 거절). 진단의 최근 시도에는 실패한 SAML 응답의 요약(서명 여부, 유효 시각, 대상)을 보여 준다(응답 원문은 저장하지 않음). 정책 화면에는 플러그인을 끄면 강제가 풀린다는 경고가 늘 보인다
- 「회원 연결」 화면(목록, 검색, 연결 추가, 사전 등록, CSV 가져오기 최대 1000행과 결과 내려받기, 연결 해제 — 유일한 로그인 수단이면 한 번 더 확인)과 「이력」 화면(로그인 시도, SCIM 수신을 IdP, 기간, 결과로 거름)
- 코어 회원 화면 확장: 회원 상세 「SSO」 탭, 회원 목록 IdP 필터(「SSO 연결 없음」 포함)와 부서, 직급 열. 마이페이지에 「연결된 회사 계정」 카드(연결 추가, 연결 해제). 회사 계정 연결이나 재확인이 실패해 돌아오면 출발 화면(마이페이지, 정보 수정, 관리자 회원 수정, 앱 키 재생성)에 사유를 알린다
- 권한 6종(설정 열람, 설정 변경, 회원 연결 열람, 연결 해제, 연결 추가와 사전 등록, 이력 열람)과 「SSO 운영자」 역할

#### 알림, 기록, 운영

- 알림 7종: 비상 계정 로그인, IdP 연속 실패(기본 10분 안 5회, 하루 1회), 인증서 만료 임박, 이메일 충돌, 최고관리자 퇴사 처리, 관리자 자동 탈퇴 건너뜀, 비밀번호 찾기 회사 계정 안내. IdP 이름 같은 본문 값은 받는 사람 언어로 들어간다
- 활동 로그: 회사 계정 로그인과 실패, 연결과 해제, 자동 가입, 퇴사 처리와 재활성, 역할 동기화, IdP 와 정책 변경, SP 키와 SCIM 토큰 발급, 비상 계정 로그인, 사전 등록, CSV 가져오기
- 스케줄 4종(`sirsoft-sso:deprovision-check`, `sirsoft-sso:withdraw-deprovisioned`, `sirsoft-sso:metadata-refresh`, `sirsoft-sso:prune`)과 LDAP 연결 진단 명령 `sirsoft-sso:ldap-test`
- 개발과 검수용 모의 IdP(OpenID Connect, SAML) — `sirsoft-sso:mock --enable --minutes=N`(최대 240분), `sirsoft-sso:mock-saml` 으로만 켜고 운영 환경에서는 켜지지 않는다
