# Changelog

이 프로젝트의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.1.0] - 2026-09-07

### Security

- 에디터에 올린 이미지를 내보낼 때 일반 이미지(JPG·PNG·GIF·WebP 등)만 화면에 바로 보여 주고, 그 밖의 형식은 내려받기로 처리하도록 바꿨습니다. 이미지 응답에는 브라우저가 파일 형식을 추측하지 못하게 하는 헤더를 붙였습니다. (KVE-2026-2366 전수 조치)

### Added

- 확장 아이콘을 동봉했습니다. 관리자 확장 관리 화면과 설치 마법사에 표시됩니다.
- 환경설정 화면과 에디터·본문 표시 조각을 `.g7.html` 마크업 형식으로도 제공합니다. HTML 에 가까운 문법이라 화면 구조를 눈으로 따라가기 쉽고,
  기존 JSON 레이아웃도 그대로 함께 들어 있어 두 표기를 나란히 비교할 수 있습니다.
- **레이아웃 편집기에서 업로드 관리·설정 화면을 상태별로 볼 수 있습니다.** 검색 필터가 걸린 화면, 행을 선택했을 때의 일괄 작업 막대, 삭제 확인 창, 설정 화면의 미리보기 펼침을 상태로 열 수 있습니다.

- 편집기를 놓는 화면이 **작성한 본문을 담을 자리를 지정**할 수 있습니다. 알림 템플릿 수정 창처럼 한 화면이 여러 입력을 함께 저장하는 곳에서, 편집기가 쓴 본문이 그 화면이 저장하는 자리에 곧바로 담깁니다. 지정하지 않으면 종전과 같이 동작합니다.

### Changed

- 코어 최소 요구 버전을 7.1.0 으로 상향 — 화면 마크업 형식(`.g7.html`)을 읽는 기능이 이 코어부터 제공됩니다.

- 설치 시 `.g7.html` 이 있으면 그것을 우선 사용합니다. 짝이 되는 JSON 과 결과가 완전히 같으므로 화면 동작은
  달라지지 않으며, JSON 만 쓰던 환경에서도 종전과 동일하게 설치됩니다.
- 에디터 이미지 사용처 검사가 코어 7.1.0 에서 없어진 테이블(`mail_templates`·`identity_message_templates`)을 더 찾지 않습니다 — 본인인증 메일
  본문의 이미지는 알림 템플릿 검사로 찾습니다.

- 에디터의 이미지 업로드가 사이트 공통 요청 경로로 나갑니다. 편집 중에 로그인이 만료되면 다시 로그인하도록 안내받고,
  업로드 진행률과 거절 사유(용량 초과·허용하지 않는 형식 등)는 종전처럼 에디터에 표시됩니다.
- 편집기를 감싸는 칸에 붙어 있던 `ckeditor5-wrapper` 클래스를 뺐습니다. 이 이름에 걸린 스타일이 없어 화면은 달라지지 않습니다.
  사이트 CSS 에서 편집기 칸을 고르려면 `ckeditor5-{필드 이름}` 형식의 칸 id(본문이면 `#ckeditor5-content`)를 쓰세요.

### Fixed

- 영어 화면에서 이미지 1개를 일괄 삭제할 때 확인 문구가 「the 1 selected images」로 표시되던 문제를 수정했습니다.
- 영어 화면에서 이미지 일괄 삭제 완료 알림이 「Deleted 1 selected image(s).」처럼 「(s)」를 붙여 나오던 문제를 수정했습니다. 1이면 단수, 0·2 이상이면 복수로 나옵니다.
- 레이아웃 편집기에서 업로드 관리 화면의 이미지 썸네일 표본이 깨진 그림으로 보이던 것을 고쳤습니다.
- 관리자 「에디터 업로드 이미지」 목록의 업로드일 조건이 날짜를 UTC 하루로 잘라, 한국 시간 새벽에 올린 이미지가 목록에는 그날로 보이는데 그날로 거르면 빠지던 문제를 고쳤습니다. 보는 사람의 시간대 하루로 거릅니다.
- 업데이트 도중 데이터베이스 변경이 중단됐을 때, 다시 실행하면 이어서 정상 진행됩니다. 종전에는 일부 변경만 적용된 상태에서 멈추면 재실행이 "이미 존재하는 항목" 오류로 계속 실패해 운영자가 직접 손대지 않고는 업데이트를 마칠 수 없었습니다.
- 「공개 자산 디스크」로 고른 디스크를 제공하던 확장을 끄면 에디터 설정을 어떤 항목도 저장할 수 없던 문제를 고쳤습니다. 이제 그 칸은 실제 동작대로 「사용 안 함 (스트리밍)」으로 보이고, 저장했던 디스크를 쓸 수 없게 됐다는 안내가 함께 나옵니다. 새 디스크를 골라 저장하면 안내도 바로 사라집니다.
- 플러그인을 비활성화했다가 다시 활성화하면 운영자가 관리자 메뉴에 지정해 둔 역할이 사라지던 문제를 수정했습니다. 비활성화할 때 메뉴를 지우지 않고(비활성 동안은 사이드바에 보이지 않습니다), 메뉴는 플러그인을 제거할 때 지웁니다.
- 레이아웃 편집기 미리보기에서 본문 편집기가 「편집기를 불러오지 못했습니다」 안내와 함께 임시 입력창으로 바뀌던 문제를 고쳤습니다. 편집기 파일이 두 번 실행되면 두 번째 실행이 첫 실행의 결과를 지워 편집기를 만들 수 없었습니다. 이제 다른 곳에서 불러오는 중인 편집기 파일이 있으면 새로 불러오지 않고 그 실행을 기다리며, 동시에 들어온 초기화 요청은 한 번만 불러옵니다. 기다리는 사이 화면에서 빠진 자리에는 편집기를 세우지 않습니다.
- 환경설정 화면에서 항목 이름·설명과 입력칸이 나란히 놓이지 않고 위아래로 쌓이던 문제와, 섹션 제목이 오류 안내처럼 붉은 작은 글자로
  보이던 문제를 수정했습니다. 저장 오류 상자의 제목과 목록 글자도 각자의 오류 안내 색으로 맞췄습니다.
- 에디터의 이미지 파일 선택 창에서 서버가 받지 않는 BMP, TIFF 도 고를 수 있어, 고르면 「이미지 파일만 업로드할 수 있습니다」로
  실패하던 문제를 수정했습니다. 이제 JPEG, PNG, GIF, WebP 만 고를 수 있습니다.
- 편집기가 화면을 처음 그릴 때의 읽기 전용 여부로 굳어, 권한 확인이 늦게 끝나는 화면에서 권한 있는 관리자에게도 입력할 수 없는 편집기가 남던 문제를 고쳤습니다. 이제 읽기 전용 여부가 바뀌면 편집기도 바로 따라갑니다.
- 확장 관리 > 플러그인 정보 창의 「훅」·「필터」 칸 설명이 일본어 화면에서 한국어로 보이던 것을 고쳤습니다. 이제 일본어 설명도 함께 둡니다.
- 편집기 스크립트를 끝내 불러오지 못했을 때 안내가 「ckeditor5_script을(를) 불러오지 못했습니다.」처럼 내부 이름으로 나오지 않고
  「편집기 불러오기에 실패했습니다.」로 나오도록 편집기 스크립트에 이름을 붙였습니다.
- 편집기 본체를 끝내 불러오지 못했을 때 안내가 「2개 항목을 불러오지 못했습니다. 편집기, 편집기」로 묶여 나오고
  「임시 입력창으로 전환했습니다」 안내가 빠지던 문제를 수정했습니다. 이제 편집기 안내 한 건만 나옵니다.

## [1.0.3] - 2026-09-06

### Added

- CKEditor 5 본체·스타일·번역 파일을 플러그인에 함께 담았습니다. 이제 외부 CDN 에 연결하지 않고 사이트 자신의 서버에서 불러오므로, 폐쇄망이나 외부 접속이 제한된 환경에서도 에디터가 동작합니다.
- 에디터를 불러오지 못한 경우 안내와 함께 임시 입력창으로 자동 전환됩니다. 작성한 내용은 그대로 저장되고, 이미 저장된 글을 수정할 때는 기존 본문이 임시 입력창에 그대로 실립니다. [다시 시도] 로 편집기를 되살리면 입력해 둔 내용이 그대로 이어집니다.
- 개발자와 AI 에이전트를 위한 문서를 추가했습니다. 확장 폴더의 `AGENTS.md`(설계 의도·확장점·수정 시 확인할 것)와 `README.md`(도입·운영 안내), `docs/`(상세 문서)로 구성됩니다.
- 확장 문서에 「레이아웃 편집기 스펙」 항목을 추가했습니다. 이 확장이 레이아웃 편집기에 무엇을 선언했는지와, 화면 요소나 데이터를 추가할 때 편집기 쪽에서 함께 해야 할 일을 담습니다.
- 문서의 제품 표기를 「그누보드7」로 통일했습니다.

### Fixed

- 관리자 화면에서 글을 수정하다 다른 글의 수정 화면으로 곧바로 옮기면 편집기에 이전 글의 본문이 그대로 남아 있던 문제를 고쳤습니다. 그 상태에서 글자를 입력하면 저장 시 본문이 이전 글의 것으로 덮어써질 수 있었습니다.
- 플러그인 설정 화면에서 미리보기 편집기에 입력한 내용이 설정과 함께 저장되던 문제를 고쳤습니다. 미리보기는 설정을 시험해 보는 자리이므로 저장 대상에서 제외됩니다.
- 글을 수정할 때 본문만 고치면 [저장] 버튼이 계속 비활성으로 남아 저장할 수 없던 문제를 고쳤습니다. 제목 등 다른 항목을 함께 건드리면 버튼이 켜졌기 때문에 화면에 따라 드러나기도 하고 아니기도 했습니다.
- 에디터 스타일과 본문 스타일을 불러오지 못했을 때 아무 표시 없이 서식만 깨지던 문제를 고쳤습니다. 이제 다시 시도한 뒤에도 실패하면 화면에 알립니다.
- 번역 파일을 불러오지 못하면 아무 기록 없이 영어로 표시되던 동작에 경고 기록을 남기고, 일시적인 실패는 다시 시도합니다.

### Changed

- 확장 문서(README · AGENTS.md · docs/README.md)의 제목에 「그누보드7」과 확장 유형을 함께 표기했습니다. 제목만 보고도 그누보드7의 어떤 종류 확장인지 알 수 있습니다.
- Composer 잠금 파일을 확장 정보와 다시 맞췄습니다. 설치·업데이트 과정에서 잠금 파일이 오래되었다는 경고가 나오지 않습니다.

## [1.0.2] - 2026-08-19

### Security

- 에디터 이미지 업로드의 권한 검사가 클라이언트가 보낸 값에 좌우되어, 그 값이 비어 있으면 검사가 통째로 건너뛰어지던 구조를 제거했습니다. 업로드는 종전처럼 관리자만 할 수 있으며, 이제 그 판정은 전적으로 서버가 합니다. (sir.kr 커뮤니티의 Xbuilder 님께서 제보해주셨습니다.)

### Added

- 에디터 이미지 업로드에 파일 가공 필터 훅 제공 — 확장에서 업로드 이미지를 저장 전에 변환할 수 있습니다.
- 에디터에 올린 이미지를 코어의 공개 자산 스토리지(S3+CDN 등) 디스크에 저장하고 본문에는 CDN 직접 주소로 서빙할 수 있습니다. 에디터 설정의 「공개 자산 디스크」에서 이 플러그인만 다른 디스크를 쓰도록 개별 설정할 수도 있습니다(비우면 코어 설정 따름). 디스크를 바꿔도 기존 이미지는 원래 위치에서 계속 정상 표시됩니다. (#100 @lyg-kaban 님께서 건의해주셨습니다.)

#### 미사용 이미지 정리

- 에디터에 올렸지만 어떤 콘텐츠에서도 더 이상 사용되지 않는 이미지를 자동으로 정리할 수 있습니다. 플러그인 설정에서 자동 정리를 켜면(기본 꺼짐) 설정한 보존기간(기본 30일)이 지난 미사용 이미지를 파일과 기록까지 매일 삭제합니다. (#115 @Tuwasduliebst 님께서 건의해주셨습니다.)
- 「에디터 업로드 이미지」 관리 화면이 추가되었습니다. 업로드한 이미지를 미리보기·업로더·용량과 함께 확인하고, 사용 중인지 여부를 배지로 구분해 필요한 것만 골라 삭제할 수 있습니다(개별·선택 삭제).
- 사용 여부는 게시글·페이지·상품 설명 등 등록된 콘텐츠를 훑어 판정합니다. 자체 콘텐츠를 가진 확장은 판정 대상에 자기 콘텐츠를 등록할 수 있어, 그 확장에서만 쓰이는 이미지도 「사용 중」으로 올바르게 인식됩니다. 비활성 상태의 모듈이 있으면 그 콘텐츠를 확인할 수 없으므로 자동 정리는 안전하게 건너뛰고, 관리 화면에도 판정이 불완전할 수 있음을 알립니다.
- 무엇이 지워질지 먼저 확인하려면 서버에서 `php artisan sirsoft-ckeditor5:prune-unused-images --dry-run` 을 실행하면 됩니다.

### Changed

- 코어 7.0.7의 외부 스크립트 보안 정책 강화에 맞춰, 에디터가 사용하는 CKEditor CDN 주소(`cdn.ckeditor.com`)를 이 플러그인의 신뢰 출처로 선언했습니다. 정책이 강화된 이후에도 위지윅 에디터가 정상적으로 로드됩니다.
- 코어 최소 요구 버전을 7.0.7 로 상향했습니다.

### Fixed

- 플러그인 설정 화면의 「에디터 이미지 업로드」 스위치가 레이아웃 편집기에서 편집 대상으로 선택되지 않던 문제를 수정했습니다.
- 플러그인 설정 저장이 실패했을 때 실패 사유 대신 일반 안내 문구만 표시되던 문제를 수정했습니다. 이제 서버가 알려준 사유가 그대로 안내됩니다.

## [1.0.1] - 2026-08-10

### Changed

- 에디터에 올린 이미지에도 환경설정 > 업로드의 최대 가로/세로·품질 설정이 적용됩니다. 다른 업로드 경로와 같은 기준으로 축소·재압축되어 저장되므로, 큰 이미지를 그대로 올려도 설정한 크기를 넘지 않습니다.
- 이 기능을 사용하기 위해 이 플러그인은 이제 코어 7.0.6 이상이 필요합니다.

## [1.0.0] - 2026-07-01

### Added

- 레이아웃 편집기 데이터 소스 목록에서 이 확장이 제공하는 데이터 소스가 친화 명칭으로 표시되고, 어느 확장이 제공했는지 출처가 함께 표시됩니다.

### Changed

- 관리자 화면 좌우 정렬 컨테이너(섹션 헤더 · 액션바 · 카드 상단부 등) 외형을 표준 시맨틱(.flex-between)으로 정리 — 시각 변경 없음, 향후 톤 조정이 한 곳에서 가능.
- 플러그인 환경설정 화면의 하단 저장 버튼이 스크롤 중에도 화면에 고정되도록 개선.
- 플러그인 표준 베이스를 따르도록 내부 구조 정비. 이미지 업로드·서빙 동작은 동일합니다.
- 코어 최소 요구 버전을 7.0.0-beta.8 로 상향.
- 플러그인 환경설정 화면의 폼 라벨 / 보조 설명 / 에러 메시지 시각 시맨틱을 sirsoft-admin_basic 표준 시맨틱과 정합 — 다른 관리자 화면과 같은 결로 통일.
- 플러그인 환경설정 화면 곳곳의 텍스트 톤 (보조 설명 · 라벨 · 본문 · 강조 · 작은 보조) 시각 시맨틱을 관리자 표준 시맨틱과 정합 — 같은 결의 글자 톤이 한 곳에서 일괄 조정 가능.
- 플러그인 환경설정 화면의 세로 정렬 컨테이너 / 입력 박스를 sirsoft-admin_basic 표준 시맨틱 (.stack / .input) 과 정합 — 표준 간격과 외형이 일관 표시되도록 정리.
