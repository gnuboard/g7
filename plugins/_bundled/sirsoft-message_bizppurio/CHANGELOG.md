# Changelog

이 프로젝트의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.1.0] - 2026-10-10

### Added

- 확장 아이콘을 동봉했습니다. 관리자 확장 관리 화면과 설치 마법사에 표시됩니다.
- **레이아웃 편집기에서 비즈뿌리오 설정 화면을 상태별로 볼 수 있습니다.** 종전에는 연결 탭만 그려져 알림톡 템플릿 탭과 템플릿 작성·대체 문자·승인 취소·반려 사유·삭제 창의 내용을 편집기에서 열 수 없었습니다. 이제 화면 상태 고르개에서 탭·준비 안 됨 안내·0건 목록·검증 실패와 창 5종의 내용을 골라 편집할 수 있습니다.

### Changed

- 알림 템플릿 [편집] 창의 알림톡·문자 섹션이 읽는 데이터(템플릿 요약, 알림톡 분류, 발신 프로필)를 알림 설정 화면별로 따로 싣지 않고 섹션과 함께 싣습니다. 화면을 열 때 템플릿 요약을 한 번 받는 시점은 종전과 같고, 메시지 조회 권한이 없는 관리자가 이 화면들을 열어도 권한 오류 알림 대신 빈 요약으로 그립니다.
- 운영 모드 저장 검증이 사용 중단 예정인 훅 이름(`core.plugin_settings.update_rules`) 대신 표준 이름
  `core.plugin_settings.update_validation_rules` 를 구독합니다. 검증 동작은 같습니다.
- 문자·알림톡 채널을 **코어 알림 채널 훅 하나로** 등록합니다. 지금까지는 코어 인증·게시판·쇼핑몰의 알림을 이름으로 골라 문자 채널을 붙여, 목록에 없는 새 모듈의 알림에는 문자를 보낼 수 없었습니다. 이제 어느 모듈이 보내는 알림이든 문자·알림톡이 후보에 오르고, 실제 발송 여부는 종전처럼 알림 설정에서 켠 채널과 연동 설정 완료 여부로 정해집니다.
- 비회원 주문 문자의 수신 번호를 이 플러그인이 쇼핑몰 주문 정보에서 직접 읽지 않습니다. 쇼핑몰이 알림 데이터에 코어 표준 수신 전화번호 키로 실어 보내고, 이 플러그인은 그 번호로 보냅니다. 비회원 주문 문자는 종전처럼 발송됩니다(쇼핑몰도 이번 판으로 함께 업데이트해야 합니다).
- 알림 설정 화면의 문자·알림톡 템플릿 행을 **코어 알림 저장 훅 하나로** 만듭니다. 지금까지는 코어 인증·게시판·쇼핑몰의 알림 저장 시점을 이름으로 골라 행을 만들어, 새로 설치한 모듈이나 다른 플러그인의 회원 알림에는 문자·알림톡 행이 생기지 않았습니다.
  - 이제 어느 모듈·플러그인의 회원 알림이든 설치·업데이트 때 행이 만들어지고, 이 플러그인을 켜는 순간 이미 설치된 모듈·플러그인의 회원 알림에도 바로 만들어집니다.
  - 켤 때는 알림 정의만 다시 저장하며(권한·메뉴는 건드리지 않음) 운영자가 고친 알림 내용은 그대로 둡니다.
  - 관리자 전용 알림은 종전처럼 제외합니다.
- 코어 최소 요구 버전을 7.1.0 으로 상향 — 코어 7.1.0 에서 추가된 알림 채널 후보 훅, 수신 전화번호 표준 키, 알림 저장 훅을 사용합니다.
- 알림톡 템플릿 이미지 업로드가 사이트 공통 요청 경로로 나갑니다. 작성 중에 로그인이 만료되면 다시 로그인하도록 안내받고,
  카카오 규격 위반 같은 거절 사유는 종전처럼 운영자 언어로 표시됩니다.
- 이 플러그인은 관리자 메뉴를 만들지 않습니다. 이전 판본이 만들어 둔 관리자 메뉴가 남아 있으면 이제 비활성화할 때가 아니라 **활성화할 때** 정리하므로, 켜져 있는 동안 쓰이지 않는 메뉴가 사이드바에 남지 않습니다. 제거할 때도 함께 지웁니다.
- 함께 쓰면 연동되는 확장(게시판, 쇼핑몰)을 manifest `integrations` 로 선언했습니다. 두 확장의 알림 설정 화면에 문자·알림톡 탭을
  덧붙이는 관계가 관리자 확장 상세에 표시됩니다. 설치를 막지는 않으며, 그 확장이 없으면 종전처럼 탭만 붙지 않습니다.

### Fixed

#### 알림톡 템플릿

- 알림톡 편집 창과 템플릿 관리 화면이 비즈뿌리오 서버에 연결하지 못했을 때(타임아웃, DNS, 프록시 실패) 서버 오류로 끝나던 것을 고쳤습니다. 이제 연결 확인 버튼과 같은 「비즈뿌리오 서버에 연결할 수 없습니다」 안내가 나오고, 원인은 경고(warning) 로그로 남깁니다(로그 레벨이 warning 이하일 때 기록).
  - 편집 창은 종전처럼 분류와 발신 프로필 목록을 빈 채로 그립니다.
  - 템플릿 삭제는 연결에 실패해도 사이트의 템플릿을 지우고, 카카오 측 템플릿을 지우지 못한 사유로 이 안내를 삭제 완료 안내에 함께 붙입니다.
  - 30분마다 도는 템플릿 상태 동기화는 연결에 실패해도 오류로 끝나지 않고, 그 주기만 건너뛰어 다음 주기에 다시 조회합니다.
- 알림톡 이미지 등록 안내의 용량·가로 크기가 실제 제약과 **따로 적혀 있던** 문제를 고쳤습니다. 안내 문구가 서버가 쓰는 값을 그대로 인용하므로, 둘이 어긋난 안내가 남지 않습니다.
- 알림톡 템플릿 작성 창의 「저장」이 본문·카테고리 같은 등록 필수값을 모두 채워야만 통과해 쓰다 만 내용을 초안으로 남길 수 없던 문제를 고쳤습니다. 이제 「저장」은 입력한 만큼 초안으로 남기고, 빠진 필수값은 검수 신청 때 항목별로 알려 줍니다.
  - 플러그인 설정의 「알림 템플릿 관리」 탭과 알림 설정 화면의 [편집] 창 하단 「저장」이 같게 동작합니다.
- 레이아웃 편집기의 모달 목록에서 **알림톡 템플릿·SMS 본문·반려 사유 창이 제목 식 원문으로 보이던 것**을 고쳤습니다.
  세 창에 편집기 전용 이름을 붙였습니다.
- 알림톡 템플릿 작성 창의 버튼·바로연결 「링크 유형」 선택칸이 화면 낭독기에서 이름 없이 읽히던 문제를 고쳤습니다. 이제 칸마다 「버튼 1 링크 유형」처럼 몇 번째 항목인지 함께 읽힙니다.
- 알림톡 템플릿 목록·요약·상세, 알림톡 분류·발신 프로필, 발송 결과를 받는 관리 응답의 안내 문장이 번역되지 않은 원문 키로 나가고, 없는 템플릿을 고를 때의 404 안내도 원문 키로 나가던 것을 고쳤습니다. 이제 관리자 언어로 「알림 템플릿을 찾을 수 없습니다.」 같은 문장이 나갑니다.
- 기본 관리자 템플릿이 아닌 관리자 템플릿에서 알림 설정의 문자·알림톡 탭과 템플릿 편집 창 배치가 흐트러질 수 있던 문제를 수정했습니다.
- 알림톡 템플릿 등록·검수 신청·삭제·연결 확인 버튼이 메시징 관리 권한 없이도 열려 거절되던 문제를 고쳤습니다. 알림 템플릿 편집 창의 비즈뿌리오 입력과 버튼, 설정 화면의 템플릿·SMS 편집 창에 있는 유형 선택·행 추가·삭제·치환 변수 버튼도 같은 권한으로 잠깁니다.

#### 설정·안내 문구

- 영어·일본어 화면의 알림 템플릿 편집 창에서 문자 발송 잔액 부족 알림의 「사용 가능한 변수」 설명이 한국어로 보이던 문제를 수정했습니다.
- 잔액 부족 알림을 받아도 **어디서 충전·설정하는지** 알 수 없던 문제를 고쳤습니다. 메일 본문에 설정 화면 주소가 함께 적히고, 사이트내 알림은 눌렀을 때 설정 화면으로 이동합니다. 종전에는 눌러도 아무 일도 일어나지 않았습니다.
- 환경설정 저장이 거절됐을 때 오류 안내의 항목 이름이 일본어 화면에서 한국어(「검수 모드」 등)로, 영어 화면의 비밀번호는 소문자 「password」로 나오던 것을 고쳤습니다. 이제 6개 항목 모두 화면 언어의 이름으로 안내합니다(일본어 이름은 일본어 언어팩이 채웁니다).
- 플러그인 설정의 리포트 수신 주소 「복사」 버튼을 눌러도 아무 일도 일어나지 않던 문제를 수정했습니다. 없는 동작을 부르고 있었으며, 이제 주소가 클립보드에 복사되고 복사 완료 안내가 뜹니다. 어느 관리자 템플릿을 쓰든 같게 동작합니다.
- 잔액 부족 훅(`sirsoft-message_bizppurio.balance.low`)을 발행하면서 확장 선언에 올리지 않아, 확장 관리의 플러그인 정보 창 「훅」 칸이 비어 보이고 확장 문서에도 유형·설명 없이 실리던 것을 고쳤습니다.
- 환경설정 저장 오류 상자의 제목이 오류 목록 줄과 같은 옅은 글자로 보여 구분되지 않던 문제를 수정했습니다. 제목을 오류 안내 제목 색으로 맞췄습니다.
- 환경설정의 청록 테두리 버튼 호버·다크 모드 테두리와 템플릿 편집 창의 높이 제한(화면 높이의 65%)이 적용되지 않아 긴 편집 창이 화면 밖으로 넘치던 문제를 수정했습니다.
- 플러그인 설정을 바꿀 권한이 없는 관리자에게 설정 화면이 입력할 수 있는 상태로 열려 저장할 때에야 거절되던 문제를 고쳤습니다. 이제 「읽기 전용」 안내와 함께 입력·저장 버튼이 잠깁니다.
- 환경설정 알림 탭의 비즈뿌리오 [설정하기]가 플러그인 설정 수정 권한이 없는 관리자에게도 보여 권한 없음 화면으로 이어지던 문제를 고쳤습니다.

### Security

- 휴대폰 번호를 등록하지 않은 회원이 문자 수신자가 되면, 그 알림이 함께 나르던 **다른 사람(주문 고객 등)의 번호로 문자가 나갈 수 있던** 문제를 막았습니다. 이제 회원 수신자에게는 그 회원의 번호만 쓰고, 번호가 없으면 보내지 않습니다. 비회원 수신자는 종전처럼 알림이 실어 준 번호를 씁니다.

## [1.0.1] - 2026-09-06

- 개발자와 AI 에이전트를 위한 문서를 추가했습니다. 확장 폴더의 `AGENTS.md`(설계 의도·확장점·수정 시 확인할 것)와 `README.md`(도입·운영 안내), `docs/`(상세 문서)로 구성됩니다.

- 문서의 제품 표기를 「그누보드7」로 통일했습니다.

## [1.0.0] - 2026-08-24

### Added

#### 문자·알림톡 발송

- 비즈뿌리오 연동 문자(SMS/LMS)·카카오 알림톡 발송 플러그인 최초 릴리즈. 회원가입·주문 등 코어 알림에 자동 연결되어 메일과 같은 방식으로 발송됩니다.
- 비즈뿌리오 계정 정보와 발신번호를 입력하는 환경설정 화면을 제공합니다.
- 검수 환경과 운영 환경을 구분해 운영합니다. 설치 직후에는 검수 환경이 기본이며, 환경설정에서 운영 환경으로 전환하면 그때부터 실제 고객에게 발송됩니다.

#### 알림톡 템플릿 작성·검수

- 알림 설정의 '비즈뿌리오' 통합 탭에서 각 알림의 [편집]을 누르면, 알림 템플릿 편집 창 안에서 카카오 알림톡 템플릿을 직접 작성해 검수를 신청할 수 있습니다.
- 승인된 템플릿은 그 내용으로 자동 발송됩니다. 승인 전에는 알림톡이 발송되지 않습니다.
- 기본형·부가정보형·채널추가형·복합형과 강조표기·이미지·아이템리스트 등 카카오 전 유형을 지원하며, 버튼과 바로연결도 함께 등록할 수 있습니다.
- 검수 결과는 30분 주기로 자동 확인되며, 편집 창의 [새로고침]으로 즉시 확인할 수 있습니다.
- 검수를 신청할 때 변수 예시값처럼 검수자에게 전달할 의견을 함께 적어 보낼 수 있습니다.
- 반려되면 사유를 같은 창에서 확인하고 수정 후 다시 신청합니다.
- 알림 목록의 각 행에 승인 여부(승인됨 / 미승인·세부 상태)와 문자 설정 요약이 표시됩니다.
- 게시판·이커머스의 알림 설정 화면에서도 동일하게 동작합니다.

#### 문자(SMS) 설정

- 같은 편집 창에서 알림별로 알림톡 실패 시 대체 SMS 사용 여부, SMS 단독 발송 여부, 문자 본문을 함께 설정합니다.
- 하단 [저장] 한 번으로 알림톡 템플릿·문자 설정·수신자 규칙이 모두 저장됩니다.
- 문자 본문은 언어별로 입력하며 회원이 사용하는 언어로 발송됩니다. 해당 언어가 비어 있으면 기본 언어로 발송됩니다.
- [SMS 단독]을 선택한 알림은 템플릿이 승인되어 있어도 알림톡을 보내지 않고 문자로만 발송합니다.
- 검수중·승인된 템플릿은 내용이 잠깁니다. 승인 취소는 즉시 알림톡 발송이 중단됨을 같은 창에서 확인한 뒤 진행합니다.

#### 템플릿 관리

- 플러그인 설정의 '알림 템플릿 관리' 화면에서 모든 알림의 템플릿 상태를 한눈에 보고 검색·필터·수정·삭제할 수 있습니다.
- 좁은 화면에서는 목록이 카드 형태로 전환되어 모바일에서도 상태를 확인할 수 있습니다.

#### 발송 결과·이력

- 비즈뿌리오 webhook 으로 발송 결과를 수신해 "알림 발송 이력" 화면에 성공/실패와 사유를 기록합니다.
- 지갑 잔액 부족 등으로 발송이 막히면 관리자에게 알립니다.
- 요청 과다로 인한 일시적 발송 실패도 사유가 함께 표시됩니다.

#### 안내

- 플러그인을 삭제하면 추가했던 발송 채널이 함께 정리되고, 재설치하면 자동 복원됩니다.
- 한국어·영어를 기본 제공하며, 일본어는 번들 언어팩으로 제공됩니다.
- 코어 7.0.6 이상이 필요합니다.
