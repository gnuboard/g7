# Changelog

이 프로젝트의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.1.0] - 2026-11-19

### Added

- 실패 알림 카드에서 템플릿이 없던 발송 수단을 켜고 저장하면 빈 템플릿이 만들어지고, 「채운 뒤 켜야 발송된다」는 안내가 보입니다. 켜기가 거절된 템플릿 스위치는 저장된 상태로 돌아옵니다
- 알림 템플릿 편집 창에서 제목, 본문, 이동 주소에 지금 없는 회원 항목 변수를 쓰고 저장하면, 저장은 되고 창이 닫히지 않은 채 위쪽 경고 상자에 그 변수가 보입니다. 경고가 보이는 동안 취소 단추는 「닫기」로 바뀌고, 고쳐 다시 저장하면 지난 경고가 지워집니다. 경고가 없으면 종전처럼 창이 닫힙니다.
- 같은 창의 변수 안내가 이 알림의 변수와 「회원 항목」 묶음(표시 이름, 회원 항목, 운영자가 더한 항목)으로 나뉩니다. 회원 항목 묶음은 접힌 채로 시작하고 제목을 눌러 펼칩니다.
- 알림 템플릿 편집 창의 받는 사람에 「사이트 관리자 이메일」(코어 환경설정 > 일반의 관리자 이메일, 메일만)을 고를 수 있습니다(코어 7.2.0).

### Changed

- 이커머스 설정 서비스 대신 이커머스 공개 환율 계약(`Contracts\Currency\ExchangeRateGateway`)으로 통화 설정을 읽고 환율을 반영합니다. 이커머스 1.4.0 이상이 필요합니다 — 이커머스를 먼저 업데이트하세요 (#83 @jiwonpapa 님께서 건의해주셨습니다.)
- 화면 스타일을 확장 자체 CSS 로 제공합니다 — 템플릿의 CSS 라이브러리와 무관하게 표시됩니다(화면 모양은 그대로입니다). 다크 모드는 템플릿이 선언한 다크 방식을 따릅니다.
- 환율 정기 갱신 시각을 플러그인 설정이 아니라 관리자 > 스케줄 관리에서 바꾸도록 옮겼습니다. 설정 화면의 갱신 시각 칸은 없어지고, 이미 11:30 이 아닌 시각을 저장해 둔 사이트는 업데이트할 때 그 시각이 스케줄로 옮겨집니다. 상태 화면의 다음 실행 시각과 재시도 시작 시각도 스케줄을 따릅니다.
- 환율 갱신·재시도·이력 정리 작업을 관리자 > 스케줄 관리에서 보고 주기·사용 여부를 바꿀 수 있게 했습니다. 바꾼 값은 확장을 갱신해도 유지되고, 실행 시각은 이전과 같습니다.
- 코어 최소 요구 버전을 7.2.0 으로 상향
- 설정 화면에 다음 실행 시각과 「스케줄 관리에서 변경」 링크를 보이고, 갱신 스케줄이 꺼져 있거나 아직 등록되지 않았으면 안내합니다.
- 설정 화면의 갱신 일정 영역을 한 줄 전체로 넓히고, 실행 요일은 이 화면에서·갱신 시각은 스케줄 관리에서 정한다는 안내와 11:00 이후 권장 안내를 한곳에 모았습니다. 실패 알림 칸에는 스케줄 관리의 실패 알림(작업이 실행되지 못했을 때)과의 차이를 안내하고, 「이력 보존 일수」 칸 이름을 「이력 보관 기간 (일)」로 바꿨습니다.
- 화면 폭 분기를 Tailwind 반응형 접두와 폭 미디어를 품은 관리자 화면 의미 클래스(`koreaexim-sticky-tab-nav-responsive` 등) 대신 엔진 responsive 로 바꿨습니다(화면 변화 없음).
- 메일·알림·문자에 담기는 링크가 코어의 바깥 링크 주소(`G7_PUBLIC_LINK_URL`, 비우면 사이트 주소)를 따릅니다 — 공개 주소와 다른 주소로 띄운 서버에서 보내도 공개 주소로 연결됩니다(코어 7.2.0).

### Fixed

- 「지금 갱신」에서 쇼핑몰 통화 설정 저장이 실패하면 화면에 오류(500)가 나던 문제를 고쳤습니다. 실행 이력에 「환율 저장 실패」로 남고 안내 문구가 보입니다.
- 「환율 갱신 실패」 알림 메일 본문이 쓰는 사이트명·받는 사람 이름 변수가 알림 설정 화면의 변수 목록에 없던 것을 채우고, 이 알림을 운영자 수신 알림으로 분류했습니다.
- 관리자 확인 창 바닥 단추가 640px 이하에서 세로로 쌓이지 않던 문제를 고쳤습니다. 단추는 창 아래에 고정되어 본문이 길어도 함께 밀리지 않습니다.

## [1.0.2] - 2026-11-10

### Fixed

- 환율 갱신 실패 메일의 제목에 사이트명 대신 `{app_name}` 글자가 그대로 나가던 문제를 고쳤습니다. 알림 편집 화면의 변수 목록에도 수신자 이름(`{name}`)과 사이트 이름(`{app_name}`)을 보이고, 두 변수의 설명도 영어·일본어 화면에서 그 언어로 보입니다.
- 환율 갱신 실패 메일의 상태 이름(`{status_label}`)이 수신자 언어와 상관없이 갱신을 실행한 쪽의 언어(예약 작업이면 사이트 언어)로 나가, 영어 메일에 한국어 상태 이름이 섞이던 문제를 고쳤습니다. 그누보드7 코어 7.1.5 이상에서는 수신자 언어로 나가고, 그보다 낮은 코어에서는 지금과 같습니다.

## [1.0.1] - 2026-10-21

### Changed

- 코어 최소 요구 버전을 7.1.1 로 올렸습니다. 화면 이동 링크(가운데 클릭·Ctrl+클릭·「새 탭에서 열기」)가 코어 7.1.1 의 링크 이동 처리를 쓰므로, 코어를 먼저 올린 뒤 이 판으로 올려야 합니다.
- 환경설정 탭(설정·이력), 「이력 탭」 바로가기, 목록으로 돌아가기, 갱신 이력의 페이지 번호를 링크로 바꿔 새 탭에서 열 수 있습니다.

### Fixed

- 알림 템플릿 편집 창의 수신 역할·회원 선택칸이 화면 낭독기에서 고른 값만 읽히던 문제를 고쳤습니다. 수신자 규칙 줄 칸(타입·관계·역할·사용자·발생시킨 본인 제외)은 「수신자 규칙 1 타입」처럼 몇 번째 규칙의 어떤 칸인지 읽힙니다.
- 환경설정 → 알림 카드에서 채널 스위치를 바꾼 뒤 「취소」를 눌러도 스위치가 저장된 값으로 돌아가지 않던 문제를 고쳤습니다.
- 플러그인 설정의 알림 문안 편집 창을 「취소」·창 머리 닫기·Esc 로 닫으면 「특정 회원」 검색 결과(회원 이름·이메일)가 화면 상태에 남던 문제를 고쳤습니다. 이제 어느 방법으로 닫든 비웁니다. 회원 검색 중에 창을 닫으면 늦게 도착한 검색 결과가 비운 상태를 다시 만들던 문제도 함께 고쳤습니다.
- 플러그인 설정의 알림 문안 편집 창 「특정 회원」 수신자 검색에 탈퇴 회원이 더는 나오지 않습니다.
- 환경설정의 실행 이력 탭과 최근 실행 목록을 불러오는 동안 「조회 중」 표시 없이 「없습니다」가 먼저 보이던 문제를 고쳤습니다. 이제 불러오는 동안에는 표를 흐리게 덮습니다.
- 플러그인 설정 화면에서 설정을 불러오지 못했을 때 안내 없이 빈 설정 폼이 열리던 문제와, 저장하지 않은 변경이 있을 때 다른 화면으로 이동하거나 뒤로 가기·새로고침을 하면 확인 없이 입력이 사라지던 문제를 고쳤습니다. 이제 처음 불러오지 못하면 오류 화면을 보여 주고(다시 불러오다 실패하면 보던 화면을 그대로 두고 안내만 띄웁니다), 떠나기 전에 확인을 묻습니다(코어 7.1.1 필요).
- 설정·안내 화면의 배지·안내 글자 대비를 높였습니다.
- 다크 모드에서 마우스를 올려도 목록 행·단추 바탕이 바뀌지 않던 문제를 고쳤습니다.

## [1.0.0] - 2026-10-10

### Added

- 수출입은행 환율 플러그인 최초 릴리즈. 한국수출입은행 공식 환율로 쇼핑몰 통화 환율을 교차환산해 자동으로 갱신하는 환율 제공자를 처음 제공합니다. 쇼핑몰 모듈 1.3.0 이상과 그누보드7 코어 7.1.0 이상이 필요하며, 한국어와 영어를 기본 제공하고 일본어는 번들 언어팩으로 제공합니다.
- 확장 아이콘을 동봉했습니다. 관리자 확장 관리 화면과 설치 마법사에 표시됩니다.

#### 환율 갱신

- 공식 환율 교차환산으로 환율을 자동 갱신·재시도하고, 환율 종류·소수 자릿수·갱신 요일과 시각을 고를 수 있습니다. 쇼핑몰 통화 설정이 바뀌면 환율을 다시 적용하고, 갱신 이력은 보존 기간이 지나면 자동 정리합니다.
- 쇼핑몰 언어/통화 설정에서 환율 제공자로 고르면 관리 통화의 환율 입력만 잠기고, 나머지 표시·절사 설정은 그대로 편집할 수 있습니다.

#### 관리자 화면

- 관리자 상태, 설정, 갱신 이력 화면과 코어 알림 정의.
- 플러그인 관리의 설정 메뉴에서 인증키, 갱신 정책, 이력을 관리하는 전용 환경설정 화면. 별도 시스템 메뉴는 등록하지 않습니다.
- 인증키 마스킹과 필수 검증, 설정과 이력 탭, 플러그인 목록으로 돌아가는 화면 이동. 이력의 기간 필터는 종료일이 시작일보다 앞서지 않도록 서로의 선택 범위를 제한하고, 뒤집힌 기간이면 조회하지 않고 그 이유를 알려 줍니다. 검증 오류 문구는 화면의 칸 이름(시작일, 종료일 등)으로 적습니다.
- 환율 설정의 입력·저장은 환율 관리 권한과 플러그인 설정 수정 권한을 모두 가진 관리자에게만 열리고, 빠진 권한에 맞는 읽기 전용 안내를 따로 보입니다. 설정이나 알림 정의를 볼 권한이 없으면 빈 화면 대신 그 이유를 안내합니다.
- 연결 테스트와 「지금 갱신」은 누른 버튼에만 진행 표시가 나타나고, 한쪽이 도는 동안 다른 쪽은 잠깁니다.
- **레이아웃 편집기에서 환율 설정 화면을 상태별로 볼 수 있습니다.** 실행 이력 탭, 펼친 행의 통화별 상세, 알림 템플릿 편집과 미리보기 창을 실제 응답 모양의 표본으로 열어 고칠 수 있습니다.

#### 갱신 실패 알림

- 환율 갱신 실패 알림을 **여러 수단으로 동시에** 받을 수 있습니다. 사이트에 설치된 알림 수단이 모두 줄로 나열되어 원하는 만큼 켜고 저장합니다.
  - 문자 같은 수단을 제공하는 확장을 설치하면 그 수단도 어느 확장이 제공하는지와 함께 나타납니다.
  - 켠 수단에 문구가 없으면 발송되지 않는다고 그 자리에서 알리고, 켠 수단의 문구는 한 목록에 함께 보입니다.
  - 메일 본문은 언어 탭마다 그 언어의 서식 편집기로 고칩니다.
- 환율 갱신 실패 알림에 담기는 설정 화면 링크는 사이트 주소로 만듭니다. 백그라운드 작업에서 보내도 올바른 주소가 들어갑니다.
- 알림 템플릿 편집 창에서 고른 역할·회원을 이름 칩으로 보여 하나씩 뺄 수 있고, 수신자 규칙 삭제 단추는 화면 읽기 프로그램에 이름으로 읽히며, 변수 설명은 화면 언어로 나옵니다.
