## [1.0.0] - 2026-10-27

### Added

- 관리자 메뉴 「팝업 관리」에서 공지·프로모션 팝업을 등록·수정·복사·삭제하고, 목록의 행 메뉴로 한 건씩 노출·비노출을 바꾸며, [순서 변경] 창으로 사용자 화면에 넘겨 보이는 순서를 정합니다.
- 내용 유형은 이미지형(PC·모바일 이미지 — 칸마다 권장 비율을 안내하고, 올린 PC 이미지의 비율이 표시 방식과 다르면 여백이 생긴다고 미리 알립니다. 언어별 대체 텍스트, 링크·새 창)과 직접 작성형(에디터 플러그인이 있으면 그 에디터, 없으면 기본 입력창)입니다. 직접 작성형 본문은 저장할 때 허용되지 않는 태그·속성을 지우며, 지우고 나면 내용이 남지 않는 본문은 안내와 함께 저장하지 않습니다. 언어팩을 꺼서 지원하지 않게 된 언어의 번역이 들어 있는 팝업도 그대로 수정할 수 있고, 그 번역은 지워지지 않습니다.
- 노출 기간(상시/기간 지정 — 시작·종료에 자동 노출·종료), 노출 페이지(전체/경로 지정 — `/shop` 은 하위 경로 포함, `/` 는 홈만), 노출 대상(전체/비회원만/회원만), 노출 기기(전체/PC/모바일)를 정합니다. 상태는 노출중·예약·종료·비활성으로 보입니다.
- 환경설정에서 모든 팝업에 똑같이 적용되는 표시 방식(PC 위치·크기, 모바일 화면 중앙/하단 시트, 배경 어둡게·배경 클릭 닫기, 자동 넘김·간격, 「오늘 하루」·「N일간」 보지 않기·닫기만)을 정하고 미리 봅니다.
- 사용자 템플릿을 고치지 않고 공통 확장점 `user_global_overlay` 에 팝업 레이어를 붙입니다. 여러 팝업은 한 레이어 안에서 이전·다음·위치 표시·일시정지로 넘겨 보고(위치 점·숫자와 일시정지는 팝업 본문 아래쪽 가운데에 겹친 반투명 캡슐에, 이전·다음은 본문 양옆에 겹쳐 보입니다 — 팝업이 많으면 점 대신 「4 / 14」처럼 숫자로 보입니다), 마우스나 손가락으로 끌어 가로로 넘길 수도 있습니다(끌다 놓으면 링크로 이동하지 않고, 움직임 줄이기 설정이면 미끄러짐 없이 바뀝니다). 팝업 창은 아래쪽 「보지 않기」·「닫기」 띠를 끌어 옮길 수 있고(단추 위에서 눌러 끌어도 닫히지 않습니다), 사이트 상단 헤더와 쿠키 동의 배너를 피해 그 사이에 놓입니다. 모바일 하단 시트는 옮기지 않고 단추로 닫습니다. ESC·←→·포커스 가둠·스크린리더를 지원합니다. GDPR 쿠키 동의 배너를 가리지 않고, 검색엔진 봇에는 출력하지 않습니다.
- 「보지 않기」 기록 쿠키를 필수 기능 쿠키로 GDPR 플러그인의 필수 저장 목록에 등록합니다(GDPR 플러그인이 설치돼 있을 때).
- 권한(조회 / 등록·수정 / 삭제), 활동 로그(일괄 작업은 건마다), 저장하지 않은 임시 이미지 자동 정리(매일, 이미지 저장·조회·행 생성 실패 시 새 파일 정리 시도와 실패 대장 재정리), 동시 수정 충돌 비교를 제공합니다.
- 코어 7.2.0 이상이 필요합니다(`g7_version >=7.2.0`).

- 열린 사용자 화면의 예약 시작·종료 경계와 탭 복귀에서 공개 목록을 갱신합니다. 숨긴 탭에서는 타이머를 해제하며 닫기·보지 않기 기록을 유지합니다.
