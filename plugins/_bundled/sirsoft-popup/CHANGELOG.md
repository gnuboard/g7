## [1.0.0] - 2026-10-27

### Added

- 관리자 메뉴 「팝업 관리」에서 공지·프로모션 팝업을 등록·수정·복사·삭제하고, 목록의 행 메뉴로 한 건씩 노출·비노출을 바꾸며, [순서 변경] 창으로 사용자 화면에 넘겨 보이는 순서를 정합니다. 목록 위 「지금 노출 중」 요약의 팝업을 누르면 그 팝업 수정 화면으로 바로 갑니다(요약은 처음 8개 — 휴대폰은 한 줄 3개 — 만 보이고 나머지는 「N개 더 보기」로 펼칩니다). 이미지가 없거나 올리는 중이라 저장할 수 없으면 저장 단추 위에 그 이유를 보입니다. 등록·수정과 표시 방식 화면의 미리보기는 「실제 크기로 보기」로 줄이지 않은 크기를 큰 창에서 확인할 수 있습니다(방금 입력한 본문까지, 화면보다 크면 팝업 위치로 옮겨 엽니다).
- 내용 유형은 이미지형(PC·모바일 이미지 — 칸마다 권장 비율을 안내하고, 올린 PC 이미지의 비율이 표시 방식과 다르면 여백이 생긴다고 미리 알립니다. 언어별 대체 텍스트, 링크·새 창 — 대체 텍스트를 비운 링크 팝업은 「팝업 링크 열기」로 읽히고, 관리용 제목은 사용자 화면에 나가지 않습니다)과 직접 작성형(에디터 플러그인이 있으면 그 에디터, 없으면 기본 입력창 — 미리보기는 입력하는 대로 바로 바뀝니다)입니다. 직접 작성형 본문은 저장할 때 허용되지 않는 태그·속성을 지우며, 지우고 나면 내용이 남지 않는 본문은 안내(「English 본문에 표시할 내용이 없습니다」처럼 언어 이름으로)와 함께 저장하지 않습니다. 언어팩을 꺼서 지원하지 않게 된 언어의 번역이 들어 있는 팝업도 그대로 수정할 수 있고, 그 번역은 지워지지 않습니다.
- 이미지형 팝업 이미지 위에 글 상자를 놓을 수 있습니다. 등록·수정 화면에서 상자를 끌어 옮기고 오른쪽 손잡이로 폭을 바꾸며(고른 상자는 화살표로 1%, Shift+화살표로 5% 이동), 글자 크기·색·굵게·정렬·반투명 바탕·그림자와 앞·뒤 순서를 정합니다(기기마다 10개까지). 위치와 글자 크기는 이미지에 붙어 PC·휴대폰에서 이미지와 함께 커지고 작아지고, 글은 언어별로 쓰며 비운 언어는 기본 언어 글로 보입니다. 모바일 이미지를 따로 올리면 휴대폰 배치를 따로 둘 수 있습니다(처음엔 PC 배치를 복사). 상자를 눌러도 이미지 링크로 이동하고, 상자 위에서 밀어도 장이 넘어갑니다. 어느 언어든 글이 이미지 아래로 넘치거나 이미지를 다른 비율로 바꾸면 편집기에서 알려 주고, 작은 휴대폰에서 보일 예상 글자 크기와 바탕을 깐 상자의 글자·바탕 대비(낮으면 경고)를 보여 주고, 투명 이미지 뒤에 비칠 라이트·다크 모드 바탕으로 바꿔 미리 볼 수 있으며, 저장 오류는 「PC 글 상자 2」처럼 어느 상자인지 알려 주고 그 상자를 표시합니다(바탕 색·바탕 진하기 같은 칸 이름까지 「PC 글 상자 1 바탕 색」처럼 알립니다). 넘친 글은 이미지 경계에서 잘리고, 오래된 브라우저에서는 글 상자 없이 이미지만 보입니다.
- 노출 기간(상시/기간 지정 — 시작·종료에 자동 노출·종료), 노출 페이지(전체/경로 지정 — `/shop` 은 하위 경로 포함, `/` 는 홈만), 노출 대상(전체/비회원만/회원만), 노출 기기(전체/PC/모바일)를 정합니다. 상태는 노출중·예약·종료·비활성으로 보입니다.
- 환경설정에서 모든 팝업에 똑같이 적용되는 표시 방식(PC 위치·크기, 모바일 화면 중앙/하단 시트, 배경 어둡게·배경 클릭 닫기, 자동 넘김·간격, 「오늘 하루」·「N일간」 보지 않기·닫기만)을 정하고 미리 봅니다.
- 사용자 템플릿을 고치지 않고 공통 확장점 `user_global_overlay` 에 팝업 레이어를 붙입니다. 여러 팝업은 한 레이어 안에서 이전·다음·위치 표시·일시정지로 넘겨 보고(위치 점·숫자와 일시정지는 팝업 본문 아래쪽 가운데에 겹친 반투명 캡슐에, 이전·다음은 본문 양옆에 겹쳐 보입니다 — 팝업이 많으면 점 대신 「4 / 14」처럼 숫자로 보입니다), 마우스나 손가락으로 끌어 가로로 넘길 수도 있습니다(끌다 놓으면 링크로 이동하지 않고, 움직임 줄이기 설정이면 미끄러짐 없이 바뀝니다). 팝업 창은 아래쪽 「보지 않기」·「닫기」 띠를 끌어 옮길 수 있고(단추 위에서 눌러 끌어도 닫히지 않습니다), 사이트 상단 헤더와 쿠키 동의 배너를 피해 그 사이에 놓입니다. 모바일 하단 시트는 옮기지 않고 단추로 닫습니다. 여러 팝업이 함께 보이면 「보지 않기」 단추가 「모두 오늘 하루 보지 않기」처럼 묶음 전체에 적용됨을 밝힙니다. ESC·←→·포커스 가둠·스크린리더를 지원합니다. GDPR 쿠키 동의 배너를 가리지 않고, 검색엔진 봇에는 출력하지 않습니다.
- 「보지 않기」 기록 쿠키를 필수 기능 쿠키로 GDPR 플러그인의 필수 저장 목록에 등록합니다(GDPR 플러그인이 설치돼 있을 때).
- 권한(조회 / 등록·수정 / 삭제), 활동 로그(일괄 작업은 건마다), 저장하지 않은 임시 이미지 자동 정리(매일, 이미지 저장·조회·행 생성 실패 시 새 파일 정리 시도와 실패 대장 재정리), 동시 수정 충돌 비교를 제공합니다. 저장 전 임시 이미지는 올린 관리자만 지울 수 있고, 임시 업로드 묶음 키는 UUID 형식만 받습니다.
- 코어 7.2.0 이상이 필요합니다(`g7_version >=7.2.0`).

- 열린 사용자 화면의 예약 시작·종료 경계와 탭 복귀에서 공개 목록을 갱신합니다. 숨긴 탭에서는 타이머를 해제하며 닫기·보지 않기 기록을 유지합니다.
- 하위 폴더에 설치한 사이트(`https://도메인/g7/` 처럼)에서 팝업 링크를 새 탭이나 가운데 단추로 열어도 그 사이트 안 주소로 이동하고, 팝업 이미지(등록, 수정 화면 미리보기와 글 상자 편집기 포함)도 그 사이트 안 주소로 불러옵니다. 바깥 주소(`https://…`)는 그대로입니다.
- 팝업 이미지를 브라우저가 다시 확인할 때 바뀌지 않았으면 다시 내려받지 않습니다(「변경 없음」 응답). 캐시와 형식 판정 헤더는 사이트의 다른 첨부 이미지와 같습니다.
- 서버가 PHP 설정 읽기(`ini_get`)나 파일 목록 함수(`glob`)를 막아 둔 호스팅에서도 팝업 이미지 업로드와 매일 임시 이미지 정리가 오류 없이 동작합니다. 이때 업로드 한도는 플러그인 설정 값을 따릅니다.

### Fixed

- 「플러그인 보기」 권한만 있는 운영자가 이 플러그인 설정 화면에 들어가지 못하던 문제를 고쳤습니다(「레이아웃 접근 권한이 없습니다」). 이제 읽기 전용 안내와 함께 설정을 볼 수 있고, 저장·변경 단추는 잠깁니다(저장은 계속 「플러그인 수정」 권한이 필요합니다). (#434)
