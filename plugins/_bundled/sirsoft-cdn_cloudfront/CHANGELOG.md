# Changelog

이 플러그인의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.1] - 2026-11-27

### Changed

- 설정 화면의 폭별 클래스를 바뀐 클래스만 덧붙이는 방식(`class-merge`, 코어 7.2.1)으로 바꿨습니다. 화면 모양은 같고, 코어 7.2.1 이상이 필요합니다.
- 코어 최소 버전을 7.2.1 로 올렸습니다 — 화면 폭별 덧붙이기 클래스(class-merge)가 코어 7.2.1 기능입니다.

## [1.0.0] - 2026-11-20

### Added

- CloudFront CDN 플러그인 최초 릴리즈. 공개 이미지 썸네일과 공개 자산을 Amazon S3 에 저장하고 CloudFront 주소로 내보냅니다.
- 썸네일이 지워지면 CDN 캐시를 자동으로 무효화합니다. 실패한 무효화는 대기열에 남겨 간격을 늘려 가며 다시 보냅니다(최대 5회).
- 재시도 상한에 닿아 멈춘 무효화가 있으면 정기 작업 출력에 경고를 남깁니다. 영어 문구는 건수에 따라 단수, 복수 형태를 고릅니다.
- 플러그인 설정 화면에서 CDN 주소와 무효화 자격을 저장하고, 연결 시험과 무효화 대기 현황을 확인합니다. 화면 폭에 따른 바깥 여백·칸 배치·현황 열 수는 엔진 responsive 구간 값이 폭과 무관한 클래스(`cdncf-settings--md`·`--lg`, `cdncf-field-row--wide`, `cdncf-stat-grid--wide`)를 붙여 정합니다.
- 켜진 채로 바로 제거해도 먼저 비활성화를 거쳐 CDN 디스크 정의를 지우고 큐 워커에 재시작 신호가 가므로, 상주 워커가 지워진 플러그인의 CDN 주소로 썸네일을 계속 내지 않습니다. 디스크 정리는 비활성화 때 한 번만 하고 제거 단계에서 따로 하지 않습니다.
- 기본 제공 언어는 한국어와 영어이고, 일본어는 번들 언어팩으로 제공합니다.
- 코어 7.2.0 이상이 필요합니다(`g7_version >=7.2.0`).
