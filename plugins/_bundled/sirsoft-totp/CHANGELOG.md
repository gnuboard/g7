## [1.0.0] - 2026-09-17

### Added

- **인증 앱으로 로그인 2단계 인증을 받을 수 있습니다.** Google Authenticator·Authy·1Password 등
  표준 인증 앱이 만드는 6자리 코드로 로그인을 마칩니다. 종전에는 2단계 인증을 켜면 인증번호가
  이메일로만 왔고, 메일이 늦거나 막히면 로그인도 함께 막혔습니다.
- **등록 화면에서 QR 코드와 수동 입력 키를 함께 제공합니다.** 카메라를 쓸 수 없는 환경에서도
  키를 직접 옮겨 적어 등록할 수 있습니다.
- **백업 코드 10개를 발급합니다.** 휴대폰을 잃어버려도 백업 코드로 로그인할 수 있습니다.
  한 번 쓴 코드는 사라지며, 언제든 새로 발급해 이전 코드를 모두 무효로 만들 수 있습니다.
  발급 화면에서 「전체 복사」로 열 개를 한 번에 가져갈 수 있습니다 — 이 코드는 그 자리에서만
  보이므로, 옮겨 적다 놓치면 휴대폰을 잃었을 때 로그인할 길이 사라집니다.
- **인증 앱을 등록하지 않은 회원은 종전처럼 이메일로 인증번호를 받습니다.** 등록하지 않았다는
  이유로 로그인이 막히지 않습니다. 이 동작은 플러그인 설정에서 끌 수 있으며, 끄면 등록을
  마칠 때까지 로그인이 차단됩니다.
- **관리자가 회원의 인증 앱 등록을 해제할 수 있습니다.** 휴대폰과 백업 코드를 모두 잃은 회원을
  구제하는 경로이며, 전용 권한(인증 앱 운영자)을 가진 관리자만 할 수 있습니다. 회원 상세 화면의
  「인증 앱」 탭에서 해제하며, 관리자 화면에 들어갈 수 없는 상황을 위해 서버에서 실행하는
  `totp:reset` 명령도 제공합니다.
- **강제 해제는 활동 로그에 남습니다.** 누가 누구의 인증 앱 등록을 언제 풀었는지, 그때의 접속
  IP 와 함께 기록됩니다. 코드 확인 없이 남의 2단계 인증을 푸는 경로이므로 추적할 수 없으면
  이 경로 자체가 권한 상승 수단이 됩니다.
- **인증 앱 목록에 표시될 사이트 이름을 설정할 수 있습니다.** 비워 두면 사이트 이름을 씁니다.

### Fixed

- **등록 화면의 QR 코드가 보이지 않던 문제를 고쳤습니다.** 코드 입력란과 수동 입력 키는 뜨는데
  QR 자리만 빈 사각형으로 남았습니다. 이제 카메라로 바로 읽을 수 있습니다.
- **등록 화면을 「플러그인 관리 → 설정」에서 엽니다.** 종전에는 관리자 메뉴에 「인증 앱 등록」이
  따로 서 있었으나, 이 화면은 플러그인 환경설정이므로 다른 플러그인과 같은 자리로 옮겼습니다.
  좌측 메뉴에서는 사라지고, 플러그인 관리 화면의 ⋮ → 설정으로 들어갑니다.

### Security

- 같은 코드를 두 번 쓸 수 없습니다. 어깨너머로 본 코드가 30초 동안 재사용되는 경로를 막습니다.
- 시크릿은 암호화해 저장하고 백업 코드는 해시로만 보관합니다. 데이터베이스만으로는 코드를
  만들 수 없습니다. 발급된 평문은 화면에 한 번만 보여 주고 다시 조회되지 않습니다.
- 회원이 탈퇴하거나 삭제되면 인증 앱 등록 정보를 함께 파기합니다.
