# Changelog

이 프로젝트의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [0.3.0] - 2026-11-20

### Added

- 템플릿이 자기 설정 화면을 공급하는 가장 작은 예제를 추가했습니다 — 화면 레이아웃(`settings/template_settings.g7.html`), 화면 부품(`src/settings/TemplateSettingsScreen.tsx`, 파비콘 1칸·업로더·저장 결과·확인 창), 묶음 빌드(`vite.settings.config.ts`), 부품 매니페스트(`components.settings.json`). 어느 관리자 템플릿이 켜져 있든 이 화면이 뜹니다. 업로더는 저장 신호의 결과로 실패 수(`{ failedCount, message }`)를 돌려주고, 화면 레이아웃은 올리기가 하나라도 실패하면 저장을 보내지 않고 실패 문구를 남깁니다.
- 템플릿 환경설정 예제(브랜딩 섹션의 파비콘 1칸)를 추가했습니다 — `config/settings/defaults.json` 선언의 최소 예입니다.
- 이 템플릿의 스타일시트(`dist/css/components.css`)를 싣습니다. 지금은 Hello 모듈 메모 카드 대체본의 모양만 담습니다.
- 확장 CSS 덮기 파일 예시를 넣었습니다. 템플릿이 확장 CSS 를 고치지 않고 확장 화면 모양을 바꾸는 최소 사례로, Hello 모듈 메모 목록(`/memos`)의 쪽 제목 색을 바꿉니다.
  - `template.json` 의 `extension_css_overrides` 에 대상 확장과 버전 범위(`^0.3`)를 적습니다. 모듈이 꺼져 있거나 버전이 맞지 않으면 실리지 않고 모듈 원래 모양으로 그려집니다.
  - 코어 7.2.0 이상에서 적용됩니다.
- 다크 모드 방식 선언(`features.color_scheme`)을 넣었습니다. 이 템플릿은 다크 모드가 없다고 코어에 알리므로, 확장 화면은 이 템플릿에서 늘 밝은 색으로 그려집니다(코어 7.2.0 이상).
- 이미지(`Img`)에 `thumbPreset`(코어 이미지 썸네일 규격)과 기본 지연 로딩·비동기 디코딩을 추가했습니다.

### Changed

- 첫 화면에 필요한 템플릿 설정을 페이지에 함께 실어 보내도록 template.json 에 expose 선언 예시를 더했습니다.
- 메모 카드 대체본이 Hello 모듈 0.3 판을 대상으로 합니다. 모듈 0.2 판에서는 대체본 대신 모듈 원래 카드가 그려집니다.
- 메모 카드 대체본의 `accent` 속성이 CSS 색 값(예: `#f59e0b`)을 받습니다. 종전에는 Tailwind 클래스 이름을 받았습니다.
- 사이트를 문서 루트 하위 폴더(예: `https://example.com/g7/`)에 설치하는 배치를 지원합니다 — 화면의 링크와 이미지 주소가 설치 폴더 안을 가리킵니다.
- 코어 7.2.0 이상이 필요합니다(`g7_version >=7.2.0`).
- 화면 폭 분기를 Tailwind 반응형 접두 대신 엔진 responsive 로 바꿨습니다(화면 변화 없음).

### Fixed

- 메모 카드 대체본의 왼쪽 강조선과 제목 서식이 화면에 나오지 않던 문제를 고쳤습니다. 서식이 이 템플릿에 없는 Tailwind 클래스로 적혀 있었고, 이제 이 템플릿 스타일시트로 그립니다.
- 화면 편집기로 지정한 이미지가 깨져 보이던 문제를 수정했습니다. 이미지 주소 자리에 알 수 없는 값이 저장된 사이트에서도 이제 그림이 정상 표시되며, 주소를 해석할 수 없으면 이미지 속성을 붙이지 않습니다.

- 「잠시 이용이 어려워요(503)」 화면이 필요한 모듈·플러그인 목록을 보여 주지 않던 문제를 고쳤습니다. 이제 서버가 넘긴 미충족 목록과 항목마다 사유(미설치·꺼짐·버전 미달 설치 → 요구)를 보여 줍니다(사유 표시는 코어 7.1.4 이상).

## [0.2.3] - 2026-10-23

### Added

- 템플릿 초기화(`initTemplate`)를 추가했습니다. 템플릿 핸들러 등록 자리가 생겨, 이 템플릿을 바탕으로 만드는 템플릿이 작성 규정대로 핸들러를 등록할 수 있습니다.

### Changed

- 링크(A)가 주소 구독·같은 사이트 링크 판정·새 창 `rel` 규칙을 코어 함수로 처리합니다. 새 창 링크의 `rel` 에 이미 적은 값은 남기고 빠진 `noopener`·`noreferrer` 만 덧붙입니다. 코어 7.1.2 이하에서는 종전 방식으로 대신합니다.

## [0.2.2] - 2026-10-22

### Fixed

- 같은 화면에서 쿼리만 바꾼 뒤 목록 문맥 유지(`mergeQuery`) 링크를 가운데 클릭·Ctrl+클릭·「새 탭에서 열기」하거나 주소를 복사하면 바꾸기 전 쿼리로 열리던 문제를 고쳤습니다. 이제 쿼리가 바뀌면 그 링크도 새 주소로 다시 그려집니다(보통 클릭은 전에도 새 쿼리로 이동했습니다). 코어 7.1.2 이상에서 적용됩니다.

## [0.2.1] - 2026-10-21

### Added

- 링크(A) 컴포넌트가 가운데 클릭·Ctrl+클릭·우클릭 「새 탭에서 열기」를 막지 않고, 레이아웃 클릭 동작이 없는 사이트 안 링크는 보통 클릭 때 화면 전체를 다시 부르지 않고 옮겨 갑니다. 끄기(`disabled` — 주소를 빼고 화면 낭독기에 비활성으로 알림)와 목록 문맥 유지(`mergeQuery` — 현재 주소의 쿼리를 링크 주소에 합침) 속성을 받습니다. 보통 클릭 판정은 코어 7.1.1 의 링크 이동 처리를 씁니다.
- 예제 링크 컴포넌트(A)가 새 창(target="_blank") 링크에 rel 「noopener noreferrer」를 합쳐 붙입니다 — 이미 준 rel 값은 그대로 둡니다.

### Changed

- 코어 최소 요구 버전을 7.1.1 로 올렸습니다. 화면 이동 링크(가운데 클릭·Ctrl+클릭·「새 탭에서 열기」)가 코어 7.1.1 의 링크 이동 처리를 쓰므로, 코어를 먼저 올린 뒤 이 판으로 올려야 합니다.
- 홈과 오류 화면(401·403·404·500)의 「홈으로」를 링크로 바꿔 새 탭에서 열 수 있습니다.

### Fixed

- 홈 메모 카드의 제목과 내용에 띄어쓰기 없는 긴 글이 칸을 넘치지 않도록 줄바꿈 표시 규칙을 지정했습니다(이 예시 템플릿은 스타일시트를 싣지 않으므로, 스타일시트를 붙여 쓸 때 적용됩니다). (#143 @glitter-gim 님께서 제보해주셨습니다.)
- 다크 모드에서 환영 카드·메모 카드 글자가 어두운 바탕에 묻히던 문제를 고쳤습니다. 오류 페이지의 상태 숫자 대비도 높였습니다.

## [0.2.0] - 2026-10-10

### Added

- 확장 아이콘을 동봉했습니다. 관리자 확장 관리 화면과 설치 마법사에 표시됩니다.
- 모든 레이아웃을 `.g7.html` 마크업 형식으로도 제공합니다 (홈·베이스 레이아웃 + 에러 6종). HTML 에 가까운
  문법으로 화면을 작성하는 방법을 보여 주는 예시이며, 기존 JSON 레이아웃도 그대로 함께 들어 있어
  두 표기를 나란히 비교할 수 있습니다.
- Hello 모듈이 제공하는 `MemoCard` 를 이 템플릿의 서식으로 갈아끼운 예시를 추가했습니다.
  템플릿이 확장 컴포넌트를 대체하는 최소 사례입니다 — 대체해도 레이아웃은 고치지 않습니다.

### Changed

- 코어 최소 요구 버전을 7.1.0 으로 상향 — 화면 마크업 형식(`.g7.html`)을 읽는 기능이 이 코어부터 제공됩니다.
- gnuboard7-hello_module 최소 버전을 0.2.0 으로 상향 — 이 템플릿이 갈아끼우는 `MemoCard` 가 그 버전부터 제공됩니다.
- 설치 시 `.g7.html` 이 있으면 그것을 우선 사용합니다. 짝이 되는 JSON 과 결과가 완전히 같으므로
  화면 동작은 달라지지 않으며, JSON 만 쓰던 환경에서도 종전과 동일하게 설치됩니다.
- 컴포넌트 자동 등록 코드를 제거했습니다. 템플릿 컴포넌트는 코어가 `components.json` 을 읽어
  등록하므로 템플릿이 스스로 등록할 필요가 없습니다. 종전 코드는 존재하지 않는 방식을 호출해
  아무 일도 하지 않으면서, 이 샘플을 참고하는 개발자에게 잘못된 방법을 알려 주고 있었습니다.

### Fixed

- 이 템플릿을 켠 사이트에서 없는 주소를 열면 오류 화면 대신 「페이지 로딩 실패」와 프로그램 내부 기록(스택)이 그대로 보이던 문제를 수정했습니다. 오류 화면 6종의 이름이 템플릿 설정이 찾는 이름(`errors/404` 등)과 달라 찾지 못하고 있었습니다.
- 어두운 화면 모드에서 오류 화면(401·403·404·500·503·점검)의 글자와 단추가 배경에 묻히지 않도록 색을 맞췄습니다.

## [0.1.1] - 2026-09-06

### Added

- 아이콘(Font Awesome)을 템플릿에 함께 담아 외부 CDN 없이 동작합니다.
- 개발자와 AI 에이전트를 위한 문서를 추가했습니다. 확장 폴더의 `AGENTS.md`(설계 의도·확장점·수정 시 확인할 것)와 `README.md`(도입·운영 안내), `docs/`(상세 문서)로 구성됩니다.
- 확장 문서에 「레이아웃 편집기 스펙」 항목을 추가했습니다. 이 확장이 레이아웃 편집기에 무엇을 선언했는지와, 화면 요소나 데이터를 추가할 때 편집기 쪽에서 함께 해야 할 일을 담습니다.
- 문서의 제품 표기를 「그누보드7」로 통일했습니다.

### Fixed

- 설정 파일이 존재하지 않는 스타일 파일을 선언해 검색엔진용 화면이 없는 주소를 참조하던 문제를 수정했습니다.

### Changed

- 확장 문서(README · AGENTS.md · docs/README.md)의 제목에 「그누보드7」과 확장 유형을 함께 표기했습니다. 제목만 보고도 그누보드7의 어떤 종류 확장인지 알 수 있습니다.
